## 3. M2: نتائج القياس (للمراجعة، **غير معتمدة**)

**طريقة القياس:** لكل لوحة، يُحسب موضع x للفاصلة العشرية في كل صف عبر `Range.getBoundingClientRect()`. يُحسب التشتّت = أكبر موضع − أصغر موضع. **النجاح:** تشتّت ≤ 0.75px.
**المصفوفة:** 3 خطوط × مع/بدون سالب × مع/بدون رمز الريال × RTL/LTR. تشمل البيانات `−1,250.00` و`0.00` و`1,250,000.00` و`−47.50`.

| الخيار | الخط | RTL | LTR |
|---|---|---|---|
| **A** الحالي: `text-end` | Plex Mono (جدولي) | **✕ 72.3px** | ✓ 0px |
| | Plex Sans Arabic (جدولي) | **✕ 63.3px** | ✓ 0px |
| | خط النظام (أرقام نسبية) | **✕ 64.9px** | ✕ 3.5px |
| **B** محاذاة فيزيائية لليمين | Plex Mono | ✓ 0px | ✓ 0px |
| | Plex Sans Arabic | ✓ 0px | ✓ 0px |
| | خط النظام (أرقام نسبية) | ✕ 3.5px | ✕ 3.5px |
| **C** عمودان: صحيح \| كسر | الثلاثة | ✓ 0px | ✓ 0px |

**الخلاصة:**

- A يبعثر الفاصلة في RTL دائماً، وهو سلوك v3 الحالي.
- B يكفي بشرط أرقام جدولية، وكلا خطَّي أَوْج (Plex Mono وPlex Sans Arabic) جدوليان.
- C هو الوحيد الصامد مع أي خط، لكنه أعقد في التنفيذ والنسخ واللصق وقارئ الشاشة.

**المقترح للمراجعة:** B مع إلزام `tabular-nums` في رمز الخط الرقمي. القرار للمالك.

> **ملاحظة صدق:** أول نسخة من خيار «الأرقام النسبية» كانت تستعمل Plex Sans Arabic. هذا الخط جدولي افتراضياً (عرض «1111» = «0000» = 38.4px)، فلم يكن الاختبار يقيس شيئاً. استُبدل بخط النظام، وهو نسبي فعلاً (26.0 مقابل 40.4px). كذلك كان مسار الكسر في C بوحدة `ch`، فاختلّ صف الإجمالي العريض 2.3px، وصُحّح إلى `em`.

## 4. طبقة الهوية (M10 مقترح)

| الطبقة | المحتوى | قابلة للتغيير من الهوية؟ |
|---|---|---|
| L0 قيم أولية | سلالم اللون والخطوط والزوايا والظلال | نعم (مصدر القيم) |
| L1 دلالي (v3) | أسماء `--awj-*` | **لا** — الأسماء مجمّدة |
| L2 سمة (v3) | Default · Ink · Core (13 رمزاً للقشرة) | لا |
| L3 وضع العمل (v3) | Ledger · Floor · Studio | لا |
| **L4 حزمة هوية** | قيم لقائمة مسموحة فقط: الإجراء، brand-soft، state، focus، سطح المكتب، سطح المحصّلة، الخطوط، الزوايا، shell-* | **نعم** |

**مدقّق العقد** (`contract()` في المختبر) يقيس قيم الرموز المحسوبة في الوضعين الفاتح والداكن. يرفض الحزمة إن غيّرت رمزاً مقفلاً، أو أسقطت أياً من 13 زوج تباين WCAG 2.2 AA.

| الحزمة | الحكم | رموز مسموحة تغيّرت | رموز مقفلة تغيّرت | فحوص فاشلة |
|---|---|---|---|---|
| v3 الأساسي | ✓ مقبولة | 0 | — | 0 |
| نحاس (Tajawal، زوايا حادة) | ✓ مقبولة | 28 | — | 0 |
| فيروز (Alexandria، زوايا لينة) | ✓ مقبولة | 29 | — | 0 |
| غير صالحة (عمداً) | **✕ مرفوضة** | 3 | `--awj-status-negative-fg` (أخضر) | action-fg/action 2.0، focus-ring 1.23، negative/paper 3.21 |

إضافة إلى العقد، مرّت الحزمتان المقبولتان بفحص axe كامل على الشاشات الأربع في الوضعين (16 تهيئة، صفر مخالفات).

## 5. نموذج التنقل (مقاس بالاختبار)

| فئة النافذة | العرض | التنقل | الألواح | الأوراق |
|---|---|---|---|---|
| ضيقة | < 600 | شريط سفلي: الرئيسية، بحث، **إنشاء**، الوارد، القائمة | لوح واحد؛ الجداول بطاقات، وسطور الفاتورة بطاقات | ورقة سفلية |

| واسعة | ≥ 1200 | شريط جانبي كامل بالمجموعات | قائمة + معاينة | — |

الاختبار يتحقق أن نمطاً واحداً فقط ظاهر في كل فئة، للأجهزة 390 و834 و1194 و1366.

**مكمّلات المسار:**

- لوحة الأوامر Ctrl K. تحصر البحث ببادئة: `ع`/`c` للعملاء، `م`/`p` للمنتجات، `>` للإجراءات.
- تسلسلات G: GS مبيعات، GP مشتريات، GI مخزون، GF وردية.
- `?` يعرض الاختصارات.
- J/K للتنقل بين صفوف المخزون.

**اختبارات التفاعل الـ 28:**

- **الغلاف:**
  - نمط التنقل لكل فئة نافذة.
  - قائمة المجموعة وورقة القائمة.
- **لوحة الأوامر:**
  - Ctrl K والبادئات الأربع.
  - Enter وEsc.
- **الاختصارات:** G+S/P/I/F و`?`.
- **فاتورة المبيعات:**
  - الإجماليات أعداد صحيحة ومشتقة من السطور.
  - تحديثها عند التعديل.
- **الإدخال:**
  - أرقام عربية-هندية `٢٫٥` → 2500 بالمللي.
  - تغيير صنف السطر يُبقي التركيز على محدّد الصنف نفسه.
  - بعد محاولة ترحيل فاشلة، كتابة `1.5` تبقى 1.5 (لا 15).
  - تغيير الصنف يمسح سعراً غير صالح سابقاً فيتفق العرض والإجماليات والتحقق.
- **مستند بلا بنود قابلة للفوترة:** لا يُرحَّل، وملخص الأخطاء يقود إلى «إضافة بند».
- **القيد التوضيحي:**
  - المبيعات: متوازن ويساوي الإجمالي، بالحسابات الصحيحة.
  - المشتريات: متوازن ويساوي الإجمالي، بالحسابات الصحيحة.
- **ملخص الأخطاء:**
  - يُركَّز عليه.
  - رابطه يركّز الحقل.
- **الفترة المقفلة:** تمنع الترحيل بالنقر وبـ Ctrl Enter.
- **حارس المغادرة:** البقاء، والمغادرة، وCtrl S، و«المغادرة دون حفظ» تعيد آخر مسودة محفوظة لا النموذج الأولي.
- **المخزون:**
  - المعاينة مقسومة في ≥ 1200، وورقة دونها.
  - J/K.
  - سحب صلاحية التكلفة يحذف القيم من الصفحة (لا إخفاء).
- **عقد Field:** خطأ عند المغادرة، وملخص عند الإرسال، ومسح بعد النجاح.
- **حوار الخطر:**
  - حبس التركيز بـ Tab وShift+Tab، والإغلاق بـ Esc.
  - الإلغاء أو Esc يعيد التركيز إلى عنصر موصول (زر «المزيد» أو زر الفتح).
- **الحالات:** هيكل التحميل، الفراغ، إعادة المحاولة.
- **الكثافة:** المضغوطة أقصر من المتوازنة.
