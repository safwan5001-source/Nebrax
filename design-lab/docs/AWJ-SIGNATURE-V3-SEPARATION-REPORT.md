1. **#2099 — عكس لا إعادة كتابة للتاريخ.** الـcommit `b200cd31` يعكس `b1e7abb1` و`fd3add85` (عملا V3). فرق شجرة الملفات مقابل `29a65efc` (آخر حالة معتمدة لـ Phase 1) = **0 سطر**. لا force-push، والتاريخ كله باقٍ للرجوع.

   - `index.html` (المستكشف) و`signature.js` (طبقة الاتجاهين وبيانات العرض) و`signature.css` (حِزم الرموز).
   - `foundation/` نسخة من `tokens.css` و`foundation.css` و`foundation.js` كما كانت عند `b1e7abb1` (مُتحقَّق بـ`cmp`). هي أقل اعتمادية لازمة: V3 يحمّل هذه الملفات الثلاثة وحدها.
   - `previews/` (8 صور webp) و`checks.json` (ملخص الاختبارات) و`README.md` (التشغيل والمعاينة).
   - `.gitignore` يستبعد `out/`، حيث تُكتب اللقطات الكاملة عند `--shots`.
3. **تعديل وظيفي واحد صغير** (لا يمسّ الهوية): وضع `#app` في `index.html`، يخفي أدوات المختبر ويعرض التطبيق وحده بملء الشاشة. سببه أن المعاينة على الآيفون عبر Artifact لا تمرّر معاملات الرابط، والـhash يمرّ. الوضع `?embed=1` باقٍ كما هو.
4. **مسارات نسبية:** `../foundation/` صارت `foundation/`، وإطارا المقارنة يستعملان المستند نفسه (`'?' + params`)، فيعمل المستكشف من `file://` أو خادم محلي أو Artifact.
