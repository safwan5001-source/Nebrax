# AWJ Signature V3 — تحسين أيقونات التنقل

> **الحالة:** للمراجعة البصرية. لا دمج ولا نشر. هوية نَسَق ولِوان وألوانها وتوكنزها والشعار بلا تغيير.
> **التاريخ:** 2026-11-13

## 1. المشكلة المؤكدة

في `foundation/foundation.js` كان `NAV` يعرّف أيقونة واحدة لكل **مجموعة**، والشريط الجانبي (`shell()`) وقائمة الجوال (`navsheet`) وورقة المجموعة على اللوحي (`group`) ترسم أيقونة المجموعة نفسها **لكل عناصرها**: عربة التسوق لكل مستندات المبيعات، الشاحنة لكل المشتريات، الصندوق لكل عمليات المخزون، وهكذا في كل المجموعات.

## 2. التغييرات

| الملف | التغيير |
|---|---|
| `foundation/foundation.js` | عنصر `NAV` صار `[labelKey, route, icon]`: الثالث أيقونة العنصر الدلالية، وأيقونة المجموعة باقية (يستعملها الشريط المصغّر على اللوحي). دالة واحدة `navIcon`/`navIc` ترسم الأيقونة في الأسطح الثلاثة. العنصر بلا أيقونة أو باسم غير موجود **يرث أيقونة مجموعته**، فإدخالات `EXT.nav` القديمة والمسارات تبقى صالحة. `sheet()` يقبل صنفاً اختيارياً، والورقتان تحملان `sheet-nav`. عند فتح القائمة يُمرَّر العنصر الحالي إلى مجال الرؤية. `NAV` و`navIcon` مكشوفان في خطاف الاختبار `__fx`. |
| `nav-icons.js` (جديد، **مولَّد**) | قاموس الأيقونات المركزي: 26 أيقونة من Lucide (lucide-react 0.460.0، ترخيص ISC مضمَّن في رأس الملف). نصّ SVG فقط، **بلا مكتبة تشغيل جديدة**. |
| `tools/gen-nav-icons.mjs` (جديد) | يولّد `nav-icons.js` من `web/node_modules/lucide-react` الموجودة أصلاً، ويفشل إن لم يُستخرج كل عنصر رسومي في الأيقونة. |
| `foundation/foundation.css` | أنماط ورقتَي التنقل فقط (`.sheet-nav` و`.navlist`)، فلا تتأثر أوراق الإنشاء والإشعارات والفرع. |
| `signature.js` | سطر واحد: أيقونة «لوحة التحكم» في `EXT.nav`. |
| `index.html` | تحميل `nav-icons.js` قبل الأساس. |
| `tools/signature-nav-previews.mjs` و`tools/nav-previews-webp.py` (جديدان) | لقطات قبل/بعد ومقارناتها. |
| `design-lab/scripts/signature.mjs` | **الملف الوحيد خارج `design-lab/signature/`**: هو مشغّل اختبارات V3 نفسه، وأُضيفت إليه ثلاثة اختبارات Regression. |

**ما لم يتغيّر:** `signature.css` و`foundation/tokens.css` (مُتحقَّق بـ`git diff`)، ألوان نَسَق ولِوان، الشعار، أيقونات المجموعات في الشريط المصغّر، شريط التنقل السفلي، الصلاحيات، `web/` والخلفية. لوحة الأوامر خارج النطاق.

## 4. قائمة الجوال

| البند | قبل | بعد |
|---|---|---|
| ارتفاع الصف | 44px + فاصل 6px = 50px | 44px + 2px = 46px؛ **هدف اللمس ≥ 44px** محفوظ ومُختبَر |
| الفصل بين المجموعات | عنوان صغير فقط | خط شعري بين المجموعات + مسافة أوضح |
| العنصر النشط | خلفية فقط | خلفية + شريط بداية + أيقونة بلون الإجراء الأساسي (`--awj-action-primary`، توكن قائم) |
| الإخفاء تحت الرأس | التمرير بالتركيز قد يضع العنصر تحت الرأس اللاصق | `scroll-padding` بقدر الرأس، والعنصر الحالي يُمرَّر إلى الرؤية عند الفتح |
| آخر عنصر | — | مسافة سفلية تشمل `safe-area-inset-bottom` |

تباين المؤشر (شريط وأيقونة) مقابل خلفية الصف المحدد، المعيار WCAG 1.4.11 ≥ 3:1:

| | فاتح | داكن |
|---|---|---|
| نَسَق | 7.31:1 | 7.01:1 |
| لِوان | 6.43:1 | 5.81:1 |

## 7. المخاطر

| الخطر | التقدير |

| مزج عائلتين: أيقونات المجموعات في الشريط المصغّر من مجموعة الأساس الخاصة، وأيقونات العناصر من Lucide | منخفض: الشبكة 24px والسماكة 1.7 والحواف المستديرة واحدة. توحيد أيقونات المجموعات قرار منفصل لم يُنفَّذ |
