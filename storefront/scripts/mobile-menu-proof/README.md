# برهان القائمة المشتركة على الجوال

هذه الأداة تُركّب **MobileMenu وMobileNavItem وRegionPreferences الإنتاجية**، مع CSS الفعلي المبني من `src/app/globals.css` عبر Tailwind/PostCSS، وترجمات AR/EN الحقيقية، وStoreProvider الفعلي.

## حدود الأداة

- بيانات التصنيفات والأسواق والروابط اصطناعية لمتجرين A وB، بمعرّفات متصادمة عمدًا، وعملتين SAR وUSD وسطحين لونيين مختلفين.
- الترويسة وشريط العروض وشريط التنقل السفلي **إطار اختبار اصطناعي** يحاكي طبقات الإنتاج `z-40 / z-45`؛ ليست الصور لمتاجر منشورة أو تصويرًا لكل tenant حيّ.
- يحاكي Next Link/Image/navigation. `useCountrySwitch` بديل بلا كتابة أو شبكة؛ لا تُرسل إعدادات لغة أو بلد ولا تُمسّ سلة أو طلبات أو دفع.
- تُحظر الطلبات الخارجية في Chromium. تُخدم الأعلام الموجودة في `public/flags` من HTTP محلي مؤقت يُغلق عند نهاية الاختبار.
- سيناريوهات القائمة الطويلة تختبر `prefers-reduced-motion: reduce` وتحاكي Safe Area بـ20px أعلى، 34px أسفل و16px لكل جانب عبر استبدال `env(...)` في نسخة CSS للاختبار فقط. **لا تُعدّ هذه شهادة اختبار iPhone/Safari فعلي.**
- لا تضيف الأداة أي route أو ملف عام إلى التطبيق، ولا تغيّر viewport metadata أو backend أو قاعدة بيانات أو إعدادات المتاجر.

## التشغيل على نسخة After

من `storefront/`، بعد `pnpm install --frozen-lockfile` باستخدام إصدار packageManager المثبّت:

```bash
pnpm exec playwright install chromium
node scripts/mobile-menu-proof/prove.mjs after /tmp/awj-nav-after
```

الأداة تختبر 40 حالة: متجران × AR/EN × عروض 320/390/430/768/1023 × قائمة قصيرة/طويلة. تتحقق من:

- حافة الفتح واتجاه النص والمحاذاة المنطقية، مساحة خارجية قابلة للنقر، صفوف لا تقل عن 44px، عدم overflow أفقي.
- ارتفاع `dvh` مستقل عن تقدير الترويسة، footer داخل viewport، safe-area padding، scroll lock والتنقل داخل قائمة طويلة.
- استمرار ألوان المتجر والعملات والروابط وأعلام Wholesale منفصلة.
- روابط إضافية، accordion، `noopener noreferrer`، مستويين متداخلين، الرجوع بدون لوحة فارغة، inert للوحات غير النشطة.
- الإغلاق بالزر وبالخارج وEscape، إعادة التركيز للزر، إلغاء scroll lock وإعادة الفتح من القائمة الرئيسية.
- نافذة اللغة المتداخلة: Escape يغلقها وحدها من دون إرسال إعدادات.
- اختبار دوران 390×844 إلى 844×390 وحصر التركيز داخل modal في سيناريوهات القائمة الطويلة.
- `elementFromPoint` على أعلى وأسفل المساحة الخارجية يثبت أن scrim يستقبل النقر بدل شريط العروض أو التنقل السفلي.

تكتب الأداة `results.json` وCSS وحزمة المتصفح وصور PNG في المجلد المعطى. أي فشل يرجع exit code غير صفري. يُفضّل حفظ stdout/stderr إلى ملف، ولا يُعتبر وجود صورة نجاحًا للاختبارات.

## إعادة إنتاج Before

خط الأساس هو `3f6215fbdca6568bfe417ae8487303d5ec5ccf9d`. استخدم worktree منفصلًا لهذا الـSHA، وانسخ إليه **مجلد أداة الإثبات هذا فقط** ثم ثبّت اعتماديات `storefront/` وشغّل:

```bash
node scripts/mobile-menu-proof/prove.mjs before /tmp/awj-nav-before
```

لا تشغّل وضع Before على مصدر After ثم تسمِّ النتائج خط أساس. الصور المسلّمة التُقطت قبل تعديل المكوّن الإنتاجي بالفعل؛ حزمة وCSS ذلك الالتقاط محفوظتان في حزمة الأدلة المحلية.

## سياسة الشرائط أثناء فتح القائمة

القائمة modal مستقلة من أعلى viewport؛ شريط العروض والترويسة وbottom nav يبقون **خلف scrim وغير قابلين للتفاعل** إلى أن تُغلق. لا يُعتمد على جمع ارتفاعات preset غير مطابقة للترويسة الفعلية، ولا تُعدّل إعدادات sticky أو تصميم أي متجر.

## متبقٍ للمراجعة قبل النشر

اختبار Safari/VoiceOver وجهاز iPhone فعلي، وقراءة صفحات tenants حقيقية بإعداداتها المنشورة. عزل بيانات الخلفية موروث ولم يُعدّل أو يُثبت حيًّا بهذه الأداة؛ الإثبات هنا لعزل عرض المكوّن وبيانات السياق المحلية.
