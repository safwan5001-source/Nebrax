**فُحص أيضاً:** كثافة النظرة العامة، حالات التحميل/الفراغ، حلقات التركيز مرئية، عرض
المبلغ برمز الريال الرسمي، عرض الأرقام بخط Mono.

**أخطاء الكونسول:** لا أخطاء من مكوّنات Phase 2. الوحيدة الملاحظة هي إجهاضات جلب RSC
المسبق لروابط الشريط الجانبي (`?_rsc=… net::ERR_ABORTED`) — سلوك إطار Next.js عبر التطبيق
كله، غير متعلّق بهذا الطور.

**الوضع النصي (light/dark):** يعتمد `darkMode: 'class'` عبر next-themes؛ كل الألوان من
CSS variables/tokens، بلا أي hex خام في مكوّنات Phase 2.
