# فحص بصري — POS Loss Prevention Phase 1

## الجلسة المحلية

أُجري الفحص على واجهة التطوير المحلية بحساب مالك تجريبي جديد، ضمن اتجاه العربية RTL والوضع الفاتح وعلى سطح مكتب بعرض 884 بكسل.

| المسار | النتيجة | ملاحظات |
| --- | --- | --- |
| `/dashboard` | ناجح | الشريط الجانبي وواجهة Nebrax الأصلية ظاهران بلا أخطاء متصفح. |
| `/pos/audit` | ناجح جزئياً | عنوان **الرقابة والتدقيق**، التبويبات الستة، بطاقات الملخص، وفلاتر العمليات الحساسة متسقة مع النظام التصميمي، متجاوبة، وتستخدم ألفاظاً محايدة. |
| `/pos/audit` مع مستأجر جديد | حالة حماية متوقعة | عرضت الواجهة رسالة أن القدرة غير مفعّلة للمؤسسة مع إجراء إعادة المحاولة؛ سببه عدم تفعيل تطبيق POS في بيانات حساب الفحص الجديد وليس خطأ عرض. |

لا توجد أخطاء في Console خلال التنقل والتسجيل. سيُستكمل الفحص بحالة POS مفعّلة وLTR/Dark/Mobile قبل فتح PR.

## تحقق الحالة المفعّلة واللغات والأوضاع

بعد تفعيل `sales.pos` محلياً للحساب التجريبي فقط، أصبحت قراءة `/pos/audit` ناجحة وعرضت الحالة الفارغة الصحيحة بدلاً من رسالة القدرة غير المفعّلة. تم فحص شاشة سطح المكتب بالإنجليزية LTR وبالوضع الداكن؛ بقيت بنية الشريط الجانبي، ترتيب التبويبات، المقاييس، وعناصر التصدير والفلاتر مقروءة ومتسقة، ولم تظهر أخطاء Console.

| المتغير | الحالة | الدليل |
| --- | --- | --- |
| Arabic RTL + Light | ناجح | لقطة `localhost_2026-08-27_23-07-14_3933.webp` تعرض تنسيق RTL وبطاقات الملخص والحالة الفارغة. |
| English LTR + Light | ناجح | لقطة `localhost_2026-08-27_23-07-27_7499.webp` تعرض التسميات واتجاه LTR السليم. |
| English LTR + Dark | ناجح | لقطة `localhost_2026-08-27_23-07-39_3419.webp` تؤكد تبايناً واضحاً وعناصر UI متماسكة. |

| Mobile 390×844 + English LTR + Dark | ناجح | لقطة `pos-audit-mobile-dark-en.png` تؤكد تكديس بطاقات الملخص، بقاء أدوات الإجراء قابلة للمس، وانضغاط تبويبات المساحة أفقياً بلا خروج عناصر من العرض. |

## الخلاصة البصرية

تظهر مساحة الرقابة كتوسعة مباشرة لواجهة Nebrax الحالية: لا ألوان خام أو ظلال ثقيلة أو واجهة منفصلة، وتبقى حالة عدم وجود بيانات واضحة مع أيقونة ونص، وليست معتمدة على اللون. تحقق الفحص في العربية RTL الفاتح، والإنجليزية LTR الفاتح والداكن، وفي لقطة محمولة فعلية بعرض 390 بكسل. لم يظهر في Console أي خطأ في المسارات المفحوصة.
