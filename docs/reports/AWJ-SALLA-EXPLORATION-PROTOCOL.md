# AWJ — بروتوكول ربط Claude Code بـ Chrome واستكشاف صانع تطبيقات سلة

> **الحالة:** مسودة تعليمات — **لم يُختبر أي اتصال بعد.** كل ما يرد تحت «معايير النجاح» يُعدّ غير محقَّق حتى تُسجَّل نتيجته فعلياً في §5.
> **المصدر:** التوثيق الرسمي `code.claude.com/docs/en/chrome` (قُرئ بتاريخ إعداد هذا الملف). الإعدادات تتغيّر؛ عند أي تعارض يُقدَّم التوثيق الحي.
> **القيد:** قراءة وملاحظة فقط. لا حفظ، لا نشر، لا تغيير إعدادات في حساب سلة، لا كلمات مرور، لا كوكيز، لا نسخ أصول أو شعارات.

---

## 1) لماذا هذا المسار (وليس الجلسة السحابية)

| المسار | الحكم | السبب |
|---|---|---|
| جلسة Claude Code السحابية (claude.ai/code) | غير صالح | حاوية بعيدة لا ترى متصفحك؛ وصلت إلى `s.salla.sa` فتحوّلت إلى `/auth` (صفحة الدخول) |
| Playwright مع كوكيز مُصدَّرة | **مرفوض** | يتطلب مشاركة جلسة الدخول |
| **Claude Code محلي + إضافة Claude in Chrome** | **المعتمد** | تدخل أنت بنفسك، وClaude يشارك حالة الدخول داخل متصفحك فقط ويتوقف عند صفحات الدخول والـ CAPTCHA |
| لقطات/فيديو منك | احتياطي | يعمل دائماً، لكن بلا تفاعل حي |

## 2) المتطلبات (من التوثيق الرسمي)

- **Google Chrome أو Edge** (Brave/Arc/Vivaldi/Opera تُكتشف أيضاً). **غير مدعوم داخل WSL.**
- **إضافة Claude in Chrome بإصدار 1.0.36 أو أحدث** من متجر Chrome.
- **Claude Code محلي** (نسخة حديثة؛ `claude --version`).
- **خطة Anthropic مباشرة** (Pro/Max/Team/Enterprise). الدخول بـ `/login`؛ إن استُخدم مفتاح API أو `claude setup-token` يبقى الربط **مطفأً** حتى مع `--chrome`. لا يعمل عبر Bedrock/Vertex/Foundry.
- **تطابق الحساب والمؤسسة:** الإضافة وClaude Code يجب أن يكونا على نفس حساب claude.ai ونفس المؤسسة. عند الاختلاف تظهر «Browser extension is not connected». للمقارنة: `/status` (صف Organization) ثم تسجيل الخروج والدخول في إعدادات الإضافة بالمؤسسة الصحيحة.
- الاتصال بـ `bridge.claudeusercontent.com` يجب ألا يُحجب (جدار ناري/Proxy مؤسسي).

## 3) خطوات الإعداد (على جهازك)

1. ثبّت الإضافة وسجّل الدخول فيها بنفس حساب Claude Code.
2. افتح مجلد نسخة مستودع أَوْج المحلية، وشغّل:
   ```bash
   cd path/to/Nebrax
   git fetch && git checkout docs/app-builder-easy-mode-research   # بعد أن أدفعه لك، أو انسخ هذا الملف يدوياً
   claude --chrome
   ```
   > لا تضع `CLAUDE_CODE_ENABLE_CFC` في إعدادات المشروع: يتجاهلها Claude Code عمداً ويحذّر. الطريقة الصحيحة `--chrome` أو `/chrome`.
3. في أول مرة تظهر نافذة تعريف؛ اضغط Enter. أول تفعيل يثبّت ملف Native Messaging؛ **أعد تشغيل Chrome** إن لم تُكتشف الإضافة.
4. شغّل `/chrome` وتأكد أن اللوحة تُظهر **Status: Enabled** و**Extension: Installed**.
5. من إعدادات الإضافة، **قيّد المواقع المسموحة** على `s.salla.sa` و`help.salla.sa` فقط (أو اسمح لكل موقع عند الطلب ولا تضغط «Allow all»).
6. **سجّل دخولك إلى سلة بنفسك** في تبويب Chrome. عند أي صفحة دخول أو CAPTCHA يتوقف Claude ويطلب منك التدخل.

## 4) اختبار الاتصال — ثلاث درجات قبل أي استكشاف

| # | الاختبار | الأمر المقترح | نجاح يعني |
|---|---|---|---|
| T1 | الأدوات ظاهرة | `/mcp` ← `claude-in-chrome` ← **View tools** | قائمة أدوات المتصفح معروضة (أسجّلها حرفياً) |
| T2 | قراءة صفحة عامة | «افتح `help.salla.sa` وأخبرني بعنوان الصفحة وأول ثلاثة عناوين فيها» | محتوى فعلي لا العنوان والرابط فقط |
| T3 | قراءة الصفحة المحمية | «افتح `s.salla.sa/channel/mobile` (أنا مسجّل الدخول) وصف ما تراه دون أي نقر» | يصف المحرر الحقيقي، لا صفحة `/auth` |

> **هذا هو الفرق عن محاولتك السابقة:** هناك قرأ Claude العنوان والرابط فقط. T3 هو الاختبار الحاسم، وإن فشل نتوقف ونستعمل المسار الاحتياطي.
> **لا يُعتبر الربط ناجحاً إلا بنجاح T1–T3 مسجَّلة في §5.**

### أعطال شائعة (من التوثيق)

| العرَض | العلاج |
|---|---|
| Extension «Not detected» | تأكد أنها مفعّلة في `chrome://extensions`، `claude --version`، Chrome يعمل، `/chrome` ← **Reconnect extension**، ثم أعد تشغيل Chrome وClaude Code |
| «Receiving end does not exist» / انقطاع بعد خمول | `/chrome` ← **Reconnect extension** |
| الأوامر لا تستجيب | نافذة JavaScript (alert/confirm) تحجب الصفحة؛ أغلقها يدوياً |
| «No browsers are connected» | Chrome مفتوح؟ نفس الحساب/المؤسسة؟ الشبكة تصل لـ `bridge.claudeusercontent.com`؟ |

## 6) قواعد السلامة أثناء الاستكشاف

**ممنوع منعاً باتاً:**
- الضغط على أي زر يحفظ أو ينشر أو يرسل أو يحذف أو يطلب بناء تطبيق (مثل «حفظ»، «نشر»، «إنشاء/طلب التطبيق»، «تقديم للمتاجر»).
- تغيير أي مفتاح تبديل أو حقل أو لون أو ترتيب قسم **حتى لو كان تغييراً مؤقتاً غير محفوظ** (قد يُحفظ تلقائياً في بعض المحررات؛ لا نفترض العكس).
- تصفّح صفحات الفوترة والاشتراكات وبيانات العملاء والطلبات؛ المطلوب محرر التطبيق فقط.
- طلب كلمة مرور أو رمز تحقق أو ملف كوكيز أو توكن.
- تسجيل GIF دون مراجعتك (التسجيل يلتقط بيانات حسابك المعروضة).

**مسموح:** التنقل بين تبويبات ومعاينات وقوائم **للقراءة**، فتح الأقسام لعرض خياراتها دون تعديل، لقطات الشاشة، قراءة النصوص والتسميات، وملاحظة الحالات الفارغة وحالات الخطأ التي تظهر دون تحفيزها بتغيير.

**إذا لم يتضح أن إجراءً غير مُغيِّر:** أسألك قبل تنفيذه.

## 7) قائمة الاستكشاف (ما يُوثَّق ولماذا)

لكل بند: **ما رأيته فعلاً (دليل)** ← مفصولاً عن **ما يثبته توثيق سلة** ← مفصولاً عن **اقتراح AWJ**.

| المحور | ما نلتقطه |
|---|---|
| A. البداية | شاشة إنشاء التطبيق: هل يبدأ بقالب جاهز؟ كم خطوة؟ ما الذي يتولّد تلقائياً؟ |
| B. هيكل المحرر | توزيع المساحات: قائمة الصفحات/الأقسام، المعاينة، لوحة الإعدادات؛ حجم كل منها |
| C. الأقسام | مكتبة «إضافة قسم»: الأسماء والتصنيفات؛ لكل قسم ما يُضبط (نص/صورة/رابط/عدد/ترتيب) |
| D. إدارة الأقسام | إضافة، ترتيب (سحب أم أزرار؟)، إخفاء، تكرار، حذف؛ رسائل التأكيد |
| E. الإعدادات العامة | الشريط العلوي، التبويبات السفلية، الألوان، الخطوط، الوضع الداكن، الشعار، الترحيب، شريط الإعلانات |
| F. الصفحات والتنقل | الرئيسية، الفئات، السلة، الطلبات، الحساب؛ ما قابل للتخصيص وما ثابت |
| G. المعاينة والحفظ والنشر | الفرق بين التعديل المباشر والمعاينة والحفظ والنشر؛ مؤشرات الحالة؛ تحذير فقدان التعديلات |
| H. اللغة والاتجاه | سلوك RTL والعربية؛ ثنائية اللغة |
| I. الحالات | الفارغة، تحميل، أخطاء، حدود (مثل أقصى عدد أقسام) |
| J. الرسائل الإرشادية | نصوص المساعدة، الأسماء المستعملة للتاجر غير التقني |

**مكان حفظ الأدلة:**
- ملاحظات نصية: `docs/reports/evidence/salla/` (نص فقط، بلا صور).
- اللقطات الخام: خارج المستودع (مجلد محلي غير متتبَّع) لأنها قد تحوي بيانات تاجر وأصولاً محمية؛ التقارير تصفها بالكلمات.
- كل ملاحظة تحمل: الوقت، الصفحة/الرابط، وعبارة «ما رأيت» حرفياً.

## 8) المسار الاحتياطي (إن فشل T3)

1. تسجيل شاشة (أو لقطات متتابعة مرقّمة) لرحلة كاملة: إنشاء ← تعديل قسم ← تبويبات ← معاينة.
2. أختبر قدرتي الفعلية على قراءة الفيديو عند وصوله، ولا أدّعي تحليله قبل الاختبار؛ البديل لقطات متتابعة محددة بالزمن أو إطارات مستخرجة.
3. وثائق `help.salla.sa` العامة تُقرأ دون دخول.
