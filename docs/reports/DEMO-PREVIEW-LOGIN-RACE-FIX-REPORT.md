## 2. التعليق

> **P2 — Prevent demo entry during an in-flight real login** (`demo-login-button.tsx:34`)
> على طلب `/login` بطيء: يُرسل المستخدم بيانات حقيقية ثم يضغط الزر التجريبي (ما زال مفعَّلاً). تُنشأ المعاينة أولاً، وحين يكتمل `login()` المعلّق يمسح علم المعاينة ويخزّن التوكن والمستخدم الحقيقيين، فينتهي المستخدم على المستأجر الحقيقي بعد أن اختار المعاينة صراحةً. المطلوب: تعطيل الدخول التجريبي أثناء `isSubmitting` أو إلغاء/تجاهل الدخول المعلّق قبل التفعيل.

**التقييم: صحيح، والعكس أيضاً صحيح.** الأثر الفعلي كما وصفه Codex: `login()` ينفّذ `clearSessionPreferences()` (يمسح علم `demo`) ثم `setToken` و`persistUser`. وفحص `isDemo()` داخل `api()` يسبق `fetch`، فالطلب الذي أُرسل قبل المعاينة يكتمل ويكتب الجلسة الحقيقية. والاتجاه المعاكس: بعد ضغط المعاينة وقبل اكتمال الانتقال (ترجمة `/dashboard` في dev تستغرق ثواني) كان يمكن إرسال النموذج الحقيقي (زر أو Enter).

## 3. الإصلاح

`login()` و`logout()` و`api()` **لم تُعدَّل** (إلغاء طلب معلّق داخل `login()` تغيير في المصادقة خارج النطاق). المعالجة في الصفحة والمكوّن:

| الطبقة | ما يفعله |
|---|---|
| 1 — منع | `DemoLoginButton` يقبل `disabled` و`onStart`؛ الصفحة تمرّر `disabled={isSubmitting \|\| demoStarted}`. الزر المعطَّل لا يبدأ معاينة ولا يستدعي `onStart` ولا يمسح الجلسة |
| 2 — قفل معاكس | `onStart` يضبط `demoStartedRef` (متزامن) و`demoStarted` (حالة): زر الدخول الحقيقي يُعطَّل، و`onSubmit` يعود فوراً إن بدأت المعاينة (يغطي Enter الذي يتجاوز تعطيل الزر) |
| 3 — شبكة أمان للتسابق | بعد `await login()`: إن كانت المعاينة قد بدأت أثناء الطلب (الفجوة بين ضغطتين قبل تحديث الواجهة) يُستدعى `startDemoSession()` فيمسح التوكن الذي كتبه `login()` للتوّ ويعيد تفعيل المعاينة، **ولا** ينتقل إلى `/dashboard` أو `/me` الحقيقيين. وفشل الطلب المتأخر لا يُظهر رسالة خطأ فوق المعاينة |
| مسار تنظيف واحد | `web/src/lib/demo-session.ts#startDemoSession` = `clearToken()` + `clearSessionPreferences()` + `enableDemo()` + `notifyAuthSessionChanged()`؛ يستعمله الزر ومعالج الاكتمال المتأخر (لا نسختان). تنظيف token وuser والفرع النشط قبل التفعيل محفوظ |

شرط `NEXT_PUBLIC_DEMO_PREVIEW=true` لظهور الزر لم يتغيّر.

**قيد معروف:** التوكن الحقيقي الذي كتبه `login()` ثم مُسح محلياً يبقى صالحاً في الخادم حتى انتهائه (لا استدعاء Logout API بقرارك). وطلب `/login` المعلّق نفسه لا يُلغى على الشبكة، فيُنشئ الخادم جلسة لا يستعملها العميل.

**الملفات:** `web/src/lib/demo-session.ts` (جديد) · `web/src/components/auth/demo-login-button.tsx` · `web/src/app/login/page.tsx` · الاختبارات و`web/e2e/demo-preview-login.spec.ts`. لا Laravel ولا API.
