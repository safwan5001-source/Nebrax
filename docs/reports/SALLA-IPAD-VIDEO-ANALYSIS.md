## 2) ما تغيّر عن فيديو الجوال: التوزيع والمعاينة والإعدادات

### 2.1 توزيع المحرر (الاختلاف الأهم)

| البند | فيديو الجوال | فيديو الآيباد | الدليل |
|---|---|---|---|
| المعاينة | **صفحة منفصلة** كاملة (يُنتقل إليها) | **لوحة دائمة** بجانب الإعدادات، تبقى ظاهرة أثناء كل تحرير | [مشاهَد] |
| الأقسام | شريط جانبي أيقوني + لوحة | **ثلاث مناطق**: شريط أيقونات (≈5%) ← لوحة إعدادات (≈32%) ← معاينة (≈63%) | [مشاهَد] |
| التنقل داخل اللوحة | قائمة ثم محرر | **drill-down بنفس اللوحة**: «أنت الآن تخصّص: X» وسهم رجوع، والمعاينة لا تتحرك | [مشاهَد] |
| زر الحفظ | أسفل كل شاشة | **ثابت أسفل اللوحة**، يبهت أثناء التحميل. لا مؤشر «تغييرات غير محفوظة» | [مشاهَد]/[مستنتَج] |
| شريط العنوان | غير موثّق | «تخصيص التطبيق (اسم القالب)» + «خروج» أحمر. **لا تراجع/إعادة ولا حفظ ولا نشر ولا مبدّل جهاز/اتجاه** | [مشاهَد] |

**الخلاصة:** سلة تنقل المعاينة إلى صفحة مستقلة على الشاشة الضيقة وتثبّتها على الواسعة؛ أي أن **التقليص المتجاوب يغيّر مكان المعاينة**، لا شكلها فقط.

### 2.2 المعاينة

| الحقيقة | الدليل |
|---|---|
| المعاينة **تطبيق iOS حقيقي مبثوث** عبر خدمة خارجية (**Appetize**)، لا تقريب ويب. كانت «مستضافة خارجياً» في الجوال [مستنتَج]؛ صارت الآن مؤكدة | [مشاهَد] 1.5، 4.0 |
| إطار الجهاز **iPhone بجزيرة ديناميكية** حتى على آيباد؛ حجم ثابت؛ لا اختيار جهاز ولا RTL/LTR ولا سطح مكتب | [مشاهَد] |
| زر **«تحديث المعاينة»** تحت الإطار، معطّل أثناء الإقلاع. **مطابق للتوثيق الرسمي:** تُرى التعديلات بعد الحفظ ثم التحديث اليدوي | [مشاهَد] + [رسمي] |
| دورة حياة الجلسة: `Launching app…` ← شاشة سوداء ← بيضاء بمؤشر ← التطبيق. بعد التحديث تظهر أيضاً **`Tap to Start`** | [مشاهَد] 12.5 |
| المعاينة **لا تنتقل إلى الشاشة قيد التحرير**: عند فتح «صفحة المنتج» أو «التبويبات» أو «التصنيفات» تبقى على الرئيسية | [مشاهَد] 6.0–10.0 |
| **لا تحديد بالنقر على المعاينة** (لم يظهر أي ضغط عليها) | [مستنتَج] |
| عند ~8.5–10.0 تظهر المعاينة **معتّمة/رمادية**؛ السبب غير معروف (جلسة خاملة؟ تحميل؟) | [غير مؤكَّد] |

### 2.3 الإعدادات والوظائف

| البند | ما ظهر | هل ظهر في الجوال؟ |
|---|---|---|
| **قالبان جاهزان** للمتجر: «تصميم مخصّص للتطبيق» (مفعّل) و«منيو»، كلاهما بوسم `Native code`، وفوائد، «اعرف المزيد»، زر «تعيين كافتراضي» / «تخصيص» | **جديد** (كان بند «تغيير القالب» غير مصوَّر) |
| **زر «نشر» منفصل** في لوحة التاجر (خارج المحرر)، معطّل، بجانبه (i) | **جديد** (لم يظهر في أي لقطة) |
| **حاجز تجاري عند المدخل:** باقة بيسك، ترقية، تجربة مجانية، سعر سنوي/شهري، وعد 72 ساعة | **جديد** |
| **اختصارات سياقية** من المنشئ إلى وحدات المتجر (جدول مقاسات، المنتجات، الولاء) | **جديد** |
| **خيارات التصميم حسب نوع القسم** (إعدادات القالب المخصص): حافة الإطار لقائمة العناصر/البانر/نص وصورة، عدد العناصر في الصف (3)، ألوان التصنيف المحدد وغير المحدد، شريط بحث أعلى التصنيفات | **جزئي** — الجديد: **«حواف الإطار»** وأنها على مستوى النوع لا القسم |
| **«رفع خط خاص»** ضمن قائمة الخطوط، مع «خط سلة الافتراضي الجديد» وخطوط مسمّاة (أمازون، أبل، دبي…) | **جديد** (ظهر خط واحد فقط) |
| **أشكال مؤشر الانتقال:** نقاط / نقاط بعنصر ممتد / أرقام (مع معاينة سلايدر) | **جديد** (ظهرت قيمة واحدة) |
| **«رسالة التقييم»:** لافتة «ستظهر رسالة افتراضية عند ترك الحقول فارغة» + الحقلان إلزاميان **عند التفعيل فقط** | **جديد** (كان مفهوماً أنهما إلزاميان دائماً) |
| **التبويبات السفلية:** صفوف بعضها بأيقونة إخفاء، وصفا «الاشعارات» و«الأمنيات» معتّمان؛ **«السلة» بلا زر إخفاء** | **جزئي** [مستنتَج]: السلة تبويب لا يُخفى |
| **قائمة عناصر:** رابط «رابط تصنيف» + قائمة تصنيفات المتجر الفعلية؛ شارة «الأساسية ✓» للغة؛ مقاس مطلوب 1200×1200؛ حذف وإخفاء وطي وسحب لكل «صورة #N» | **جزئي** |
| **عنوان فرعي** للصف داخل المحرر («منتجات ثابتة — الأكثر مبيعاً») | **جديد** (القائمة نفسها تعرض النوع فقط، فيتعذر التمييز بين صفّي «صور متحركة») |
| **المساعد العائم** بنص دوّار: «كيف أساعدك؟» / «الدعم الفني؟» / «أنشئ كوبون؟» | **جديد** |
| الشريط الإعلاني: ما زال **مقفلاً بالباقة** (إشعار أحمر ثم صفحة فارغة) | موافق |

### 2.4 ملاحظات UX (مشاهَدة)

- **جيد:** لوحة سياق ثابتة بجانب المعاينة؛ drill-down بسيط مع رجوع؛ ملء الحقول الفارغة بقيمة افتراضية معلنة؛ معاينة بياناتها الحقيقية (شعار «نبراس مارت»، تصنيفاته).
- **ضعيف:** المعاينة لا تتبع سياق التحرير؛ لا مؤشر حفظ؛ لا تراجع/إعادة؛ شريط الأيقونات بلا نص (التلميح يظهر عند اللمس مع الانتقال معاً، فلا اكتشاف قبل الضغط)؛ إشعار الحجب التجاري يظهر فوق المعاينة ويترك صفحة شبه فارغة؛ عيوب RTL في قيم الألوان (`FA931B#`) كما في الجوال؛ حقول إلزامية (*) بلا قيمة ولا تحقق ظاهر.

## 3) المقارنة الثلاثية: فيديو الآيباد × فيديو الجوال × التوثيق الرسمي

## 4) المقارنة مع AWJ V1 وV2 والـRuntime

| البند | سلة (آيباد) | V2 اليوم | محرك AWJ / Flutter | الفجوة |
|---|---|---|---|---|
| معاينة | تطبيق حقيقي مبثوث، بطيئة، يدوية، لا تتبع السياق | **تقريب ويب** فورية، تتبع الصفحة، وتحديد بالنقر | لا يوجد مبثّ ولا Flutter Web | V2 **أسرع وأذكى لكن أقل أمانة**؛ فارق الأمانة معلن في «الفروق عن Runtime» |
| توزيع الجهاز اللوحي | ثلاث مناطق دائمة | عمودان + تبديل (1000–1199)، وتخطيط جوال < 1000 | — | انظر §5 |

| إعدادات على مستوى النوع | حافة الإطار، عدد العناصر في الصف | غير موجودة (الخصائص لكل قسم فقط) | الثيم يقرأ `colorPrimary` وحده | فجوة **عقد ثيم** (P0-1) |
| الخطوط | قائمة + رفع خط خاص | حقل خط (مقترَح) | لا خط مخصص | **Runtime + ترخيص + تغطية RTL** |
| مؤشر السلايدر | 3 أشكال | غير موجود | لا carousel أصلاً | **Runtime** |
| تبويبات سفلية | قائمة، ألوان، إخفاء | «الطلبات/الحساب… (مقترح)» | `navigate` يقبل `home`/`cart` فقط، لا تبويبات | **Runtime** |
| نشر | زر مستقل بجانب القوالب | حوار فحص النشر داخل المحرر | نشر بصلاحية `apps_builder.publish` | AWJ أقوى في الفحص والعزل |

| قفل بالباقة | إشعار أحمر + صفحة فارغة | لا حالة «مقفل بالباقة» | `PlanGate` موجود للمستأجر لا للمكوّنات | فجوة صغيرة |

## 5) فحص V2 على مقاسات الآيباد (قراءة فقط، بلا تعديل)

الاختبار: Chromium مع لمس، من دون تغيير أي ملف. العيّنة: 1194×834 و1366×1024 (أفقي)، و834×1194 و744×1133 (عمودي). بلا أخطاء كونسول، وبلا تمرير أفقي.

| القياس | النتيجة | القراءة |
|---|---|---|
| تخطيط 1194×834 و1366×1024 | عمودان: معاينة (إطار جوال 390) + لوحة تحرير. المتنقّل (الأقسام) مخفي خلف تبديل | يعمل؛ وإطار الجوال محاط بفراغ واسع. سلة تستغل العرض بثلاث مناطق |
| تخطيط 834×1194 و744×1133 | **تخطيط الجوال**: المعاينة بعرض الشاشة كاملاً (**834px لا 390**) وأوراق سفلية؛ ومبدّل الجهاز غير ظاهر | **عيب بصري:** المعاينة تُشوَّه عن عرض جوال حقيقي وقيمة «جوال/تابلت» مفقودة. هذا هو نطاق iPad العمودي كله |

| المحتوى | شارة «يحتاج قراراً» تظهر مرتين في فحص القسم | سليم كدلالة |

## 6) ما بقي غير مؤكَّد (يحتاج تصويراً إضافياً)

| # | المطلوب | لماذا |
|---|---|---|
| 1 | ضغط **«حفظ التغييرات»**: النتيجة، ثم تحديث المعاينة | لم يظهر |
| 2 | ضغط **«نشر»** وسبب تعطيله ومعنى (i) | رأيناه معطّلاً فقط |

| 7 | **سطح المكتب** (متصفح) | الآيباد لا يثبت سلوكه |
| 8 | آيباد **عمودي** | الفيديو أفقي فقط |

## 7) توصيات لتحسين V2 (للمراجعة — لم تُنفَّذ)

مرتبة بالأثر مقابل الكلفة. كل توصية تذكر دليلها وحالة الدعم الفعلية في المحرك.

| # | التوصية | الدليل | الحالة | ملاحظة |
|---|---|---|---|---|
| **1** | **عنوان فرعي مشتق لكل صف:** أظهر في قائمة الأقسام وصفاً مشتقاً من الخصائص («منتجات — الأكثر مبيعاً»، «ترحيب — أوج») | سلة تعرضه داخل المحرر فقط فتعجز القائمة عن التمييز بين صفّين من النوع نفسه (§2.3) | **جاهز** (لا يحتاج مكاناً في AppSchema) | **حل مؤقت** لقرار «اسم القسم» المعلّق |
| **2** | **تصحيح تخطيط الآيباد العمودي (744–999):** إطار جوال 390 مركزي مع إبقاء مبدّل الجهاز، بدل معاينة بعرض الشاشة | §5 | تصميم/CSS | يزيل التشويه |
| **3** | **رفع أهداف اللمس إلى 44px** على الشاشات ذات `pointer: coarse` فقط | §5 | تصميم/CSS | تراجع/إعادة/المزيد أولاً |
| **4** | **مستوى «خيارات التصميم حسب النوع»** (حافة الإطار، عدد العناصر في الصف) فوق خصائص القسم، في لوحة الهوية | §2.3 | **مقترح** (يحتاج عقد ثيم/توكنز، P0-1، وRuntime) | لا يُفعَّل قبل القرار |
| **5** | **افتراضيات معلنة بدل حقول إلزامية فارغة:** «سيظهر النص الافتراضي إن تُرك فارغاً» | رسالة التقييم | **جاهز** (واجهة فقط) | يعالج عيب الحقول الإلزامية |
| **6** | **حالة «معاينة قديمة/تُحمَّل» صريحة** في المواصفة للمعاينة الحقيقية المستقبلية، مع آخر مزامنة | دورة Appetize وغياب مؤشر الحفظ | مواصفة | لا تلزم في النموذج الحالي |
| **7** | **لوحة مثبّتة على الأجهزة اللوحية الأفقية:** عرض المتنقّل والمحرر معاً (ثلاث مناطق) بدل التبديل | §2.1، §5 | تصميم | يقارب سلة دون نسخ هويتها |
| **8** | **اختيار القالب عند الإنشاء:** شاشة بقالبين (عام، مطعم/توصيل مثلاً) = مستندات AppSchema أولية | §2.3 | **مقترح** (استراتيجية القوالب قرار #4) | لا قوالب في المحرك اليوم |
| **9** | **إخفاء إجراء الحذف/الإخفاء للمكوّنات الأساسية** (مثل السلة) وإعلان السبب | عدم قابلية إخفاء «السلة» | مشتق من سجل المكوّنات | يوافق قاعدة الإلزامية |
| **10** | **حالة «مقفل بالباقة»** كحالة خامسة للقسم، لا إشعار يُترك معه فراغ | الشريط الإعلاني | **مقترح** (يحتاج حدود باقة للمكوّنات) | أولوية منخفضة |
| **11** | **اختصارات سياقية** من المنشئ إلى وحدات المتجر (المنتجات، الفئات) | بطاقات سلة | جاهز كروابط | يعزز تكامل الـERP |
| **12** | **مسألة الخطوط:** لا «رفع خط خاص» الآن | سلة تتيحه؛ AWJ لا يدعم خطاً مخصصاً | **مؤجَّل** (ترخيص، تغطية RTL، حجم الحزمة) | |

**ما أوصي بعدم فعله:** نسخ فكرة البث الحقيقي (Appetize) الآن: كلفتها وتبعيتها الخارجية ولا تتبعها للسياق تُضعف الحجة. نموذج V2 (معاينة فورية متتبِّعة) **أفضل تجربةً** ويبقى الحل الأمين للفروق عبر «الفروق عن Runtime».

**ما يبقى صحيحاً دون تغيير:** معاينة كنقطة دخول، وتحديد بالنقر، وفصل الصفحات عن الأقسام، وحفظ/تراجع/إعادة، ووضعان بمسودة واحدة. الأدلة الجديدة **تؤكّد** هذه القرارات (سلة نفسها لا تقدّم الأربعة).
