## التشغيل
افتح `index.html` في أي متصفح حديث (لا خادم ولا بناء). يعمل دون اتصال؛ خط IBM Plex يُحمَّل من الإنترنت إن توفّر وإلا يُستعمل خط النظام. رمز الريال `U+20C1` بخطه الرسمي مضمَّن.

## ما الجديد عن V1
| V1 | V2 |
|---|---|

| تحرير من القائمة | **الضغط على العنصر داخل المعاينة يحرّره** + شريط عائم (أعلى/أسفل/إخفاء/تكرار/حذف) |
| تخطيطات غير منظّمة | سطح ≥1100: ثلاثة أعمدة · 1000–1099: عمودان · آيباد عمودي: إطار جهاز + أوراق سفلية · جوال: معاينة مسطّحة + أوراق |
| الصفحات والأقسام ممزوجة | **الصفحات منفصلة عن الأقسام** + شاشة المنتج الأصلية عرض فقط |
| وضع متقدم قراءة فقط | **تحرير جزئي** يُثبت سلامة البيانات ذهاباً وعودة |
| لا حالة فشل حفظ | غير محفوظ ← جارٍ ← محفوظ ← **فشل ← إعادة محاولة** |
| لا جهاز/اتجاه | جوال 390 · جوال صغير 360 · تابلت 768 (تقريب) + RTL/LTR |
| — | قسم مقترح **اختياري** يُسقط عند النشر (سلوك المحرك الفعلي) |

## ما أُضيف بعد مراجعة فيديو الآيباد
1. **عنوان فرعي مشتق** لكل صف («منتجاتنا · منتجات حيّة»، «بنر ← السلة») وترتيب `1/2` للأقسام المتكررة النوع. عرض فقط: لا يُخزَّن ولا يظهر في المخطط الناتج.
2. **آيباد عمودي (≥700×700):** المعاينة في إطار جوال 390 مع مبدّل الجهاز وتراجع/إعادة؛ الجوال الحقيقي يبقى مسطّحاً.
3. **أهداف لمس 44px** على أجهزة اللمس فقط (`pointer: coarse`)؛ سطح المكتب بالمؤشر الدقيق بكثافته نفسها.
4. **آيباد أفقي ≥1100:** المستكشف والمعاينة والمفتش معاً. من 1000 إلى 1099 عمودان (المستكشف والمفتش يتناوبان).
5. **افتراضيات معلنة** («الافتراضي — إن تُرك فارغاً: …») بدل صمت الحقل الفارغ؛ واسم القسم الفارغ يعود لاسم النوع.
6. **شاشة اختيار القالب عند الإنشاء:** ثلاثة قوالب من أقسام جاهزة فقط (تصوّر؛ استراتيجية القوالب قرار مفتوح).
