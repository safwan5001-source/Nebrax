# تقرير فصل صفحة عرض المنتج عن صفحة تعديل المنتج

**التاريخ:** 2026-09-30  
**المستودع:** `safwan5001-source/Nebrax`

## الملخص

تم فصل مسار عرض المنتج عن مسار تعديله. أصبحت صفحة `/products/:id` للعرض فقط، بينما أصبحت صفحة `/products/:id/edit` مخصصة لمساحة التعديل `ProductWorkspace` فقط. تم تحديث زر **تعديل** في قائمة المنتجات ليستخدم المسار الجديد، مع إبقاء زر **عرض** على مسار الملف.

لم يتم تغيير API أو قاعدة البيانات أو منطق المخزون أو الأسعار أو الصلاحيات. لم يتم تنفيذ Merge أو Deploy.

## السبب الجذري

كان سببا التداخل مرتبطين مباشرةً:

1. رابطا **عرض** و**تعديل** في `web/src/app/(app)/products/page.tsx` كانا يوجهان إلى نفس المسار `/products/:id`.
2. صفحة `web/src/app/(app)/products/[id]/page.tsx` كانت تعرض واجهة ملف المنتج للقراءة، ثم تركّب داخل تبويب معلومات المنتج:

   ```tsx
   <ProductWorkspace mode="edit" product={product} ... />
   ```

   لذلك ظهر نموذج التعديل أسفل بطاقات ومعلومات العرض في الصفحة نفسها، وهو ما يطابق السلوك الظاهر في لقطة الشاشة.

الحل المحدود هو إبقاء مسار الملف للعرض، وإضافة route مستقل للتحرير. الصفحة المشتركة تستنتج وضعها من `usePathname()`؛ وهذا يحافظ على توقيع Next.js الصحيح لملف route `page.tsx` ويمنع تمرير props مخصصة إلى route page.

## ما لم يتغير

- لا تغييرات على API أو عقود الطلبات والاستجابات.
- لا تغييرات على قاعدة البيانات أو migrations.
- لا تغييرات على منطق المخزون أو الأسعار أو الضرائب.
- لا تغييرات على الصلاحيات أو حواجز الوصول.
- لا إعادة هيكلة واسعة؛ تم الحفاظ على `ProductWorkspace` كما هو وإعادة استخدامه في route التحرير.

## فحص الجوال والديسكتوب وRTL

- **الجوال:** رابط العرض ورابط التعديل أصبحا مسارين مستقلين قبل أي اختلاف في التخطيط responsive؛ لا يمكن أن يركبا الواجهتين معًا بسبب عرض الشاشة.
- **الديسكتوب:** زر التعديل في القائمة وزر التعديل داخل ملف المنتج يوجهان إلى `/products/:id/edit`، ومسار الملف لا يركب مساحة العمل.
- **RTL:** لم تتغير direction أو spacing أو مكونات الواجهة الحالية؛ روابط الأكشن تستخدم نفس مكونات `Button` و`Link` الموجودة، كما بقيت اختبارات قائمة المنتجات الخاصة بسلوك RTL ومعرّفات SKU/barcode ناجحة.
- التحقق تم بالكود والاختبارات وبناء الإنتاج. لم يتم تشغيل جلسة Browser/E2E خاصة بصفحة المنتج لأن بيئة API/المصادقة الحية ليست جزءًا من هذا التغيير؛ هذه نقطة متبقية موضحة أدناه.
