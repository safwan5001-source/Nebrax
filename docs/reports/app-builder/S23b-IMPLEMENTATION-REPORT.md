# S23b — وصولية المفتش: ربط التسميات وأسماء الأزرار (UX-03)

**النطاق:** واجهة فقط (`inspector.tsx` + رسائل ar/en). لا API ولا هجرة ولا مفتاح مخطط. غير محجوبة بقرار AD.

## العيوب الفعلية التي وُجدت
- كل `<label>` في خصائص المكوّن ومعاملات الإجراء وبحث/ترتيب الربط بلا `htmlFor`، فلا يُقرأ اسم الحقل لقارئ الشاشة ولا يركّز النقر على التسمية الحقل.
- `aria-label="remove"` جامد بالإنجليزية في زر حذف عنصر القائمة وزر حذف شرط الظهور، بلا ترقيم يميّز العناصر.
- زر «+» بلا اسم؛ حقول عناصر القائمة وحقول شروط الظهور (الإشارة/المقارنة/القيمة) بلا اسم.
- ملاحظة: لم تُوجد نصوص عربية جامدة في `canvas.tsx` ولا الشجرة/الإطار/المؤشرات (فحص آلي بالنمط).

## الإصلاح
- `useId` لكل صف خاصية/معامل؛ `<label htmlFor>` لكل تحكم مفرد. قائمة النصوص (عدة تحكمات) = `role="group"` + `aria-labelledby` على تسمية نصية.
- أسماء مترجمة ومرقّمة: `fieldA11y.itemName/removeItem/addItem` و`visibility.leaf.signal/operator/value/remove` و`binding.sortDirectionLabel` (ar/en).

## الاختبارات
- `inspector-a11y.test.tsx` (4): كُتب أحمر أولاً. يستعمل رسائل ar/en الحقيقية ويتحقق بـ`getByLabelText`/`getByRole('group'|'button', {name})`: ربط التسمية بالتحكم، معاملات الإجراء، أسماء فريدة مترجمة للحذف/الإضافة/العناصر، وأن أسماء الأزرار عربية في الواجهة العربية.
