# S05e — هجرة المؤشرات الحيّة (Dry-run افتراضي) + تقييم جلسات المعاينة بعد الأرشفة

**الحالة:** منفَّذة كأداة **معاينة**. لا هجرة فعلية نُفِّذت، ولا بوابة فُتحت (`APP_BUILDER_LIVE_POINTER_ENABLED=false` باقٍ). أي تشغيل فعلي أو تفعيل يحتاج **موافقة جديدة**.

## الأمر
`php artisan app-builder:backfill-live-pointers [--tenant=<uuid>] [--apply]`
- **افتراضياً معاينة بلا كتابة**: JSON-lines لكل مستأجر + ملخص أعداد. الحالات: `would_create` · `already_pointed` · `no_mobile_channel` · `no_published_versions` · `not_renderable`؛ مع `notes` (`multiple_apps`).
- المعاينة تحسب «ما كان سيُكتب» = أحدث نسخة منشورة عبر تطبيقات المستأجر **غير المؤرشفة** (ما يخدمه السلوك المؤقت اليوم)، بشرط أن يرندرها جيل معروف.
- `--apply` **يُرفض (exit 2)** ما دامت البوابة مغلقة، ويكتب عبر `BuilderLivePointerService::promote` (قفل + تدقيق ثابت سببه `backfill`، بلا فاعل بشري)، وidempotent (له مؤشر ⇒ يُتخطّى). اختبار يثبت: لا كتابة في المعاينة، رفض `--apply` والبوابة مغلقة، التكرار آمن، العزل بين المستأجرين، وكل حالة تُبلَّغ بصدق. ثلاث طفرات (تجاهل الأرشفة، الكتابة في المعاينة، تجاوز حارس البوابة) تُفشل اختباراً.
- **مخاطرة معلنة:** مستأجر بعدة تطبيقات (`multiple_apps`): المؤشر يثبّت تطبيقاً واحداً بينما السلوك القديم قد يمرّ لجهاز أقدم بنسخة تطبيق آخر عند عدم توافق الأحدث. ينبغي مراجعة هذه الصفوف يدوياً قبل أي تطبيق.

## تقييم جلسات المعاينة بعد الأرشفة (توثيق لا توسيع)
- حارس الأرشفة يمنع **إصدار** جلسات/مراجع معاينة جديدة (بما فيها QR) ويرفض **استهلاك** مرجع صدر قبل الأرشفة (S05d).
- جلسة معاينة **قائمة** وقت الأرشفة تبقى صالحة حتى انتهاء مدتها: TTL ثابت 15 دقيقة (سقف 60)، وهي لقطة مسودة غير قابلة للتعديل بلا وصول إلى `commerce/v1` (قراءة فقط، لا بيانات حيّة ولا كتابة) فلا تسريب ولا أثر مالي.
- الخطر المتبقي منخفض ومحدود زمنياً؛ **لم أضف إبطالاً جماعياً** (توسيع نطاق). إن أردته فهو شريحة صغيرة: إبطال جلسات التطبيق عند الأرشفة داخل نفس المعاملة.
