# S09d — محرر الغلاف في الوضع السهل: التبويبات السفلية والشريط العلوي (AD-04)

**القرار:** AD-04 معتمد. واجهة فقط فوق عقد S09a المدموج؛ **لا API ولا هجرة ولا مفتاح مخطط جديد**.

## ما نُفِّذ
- تبويب جديد «الغلاف» في لوحة البنية (الوضع السهل): 
  - **التبويبات السفلية:** تفعيل (تبويب للصفحة الرئيسية)، عنوان (≤24) وأيقونة (قائمة مغلقة 10) وإخفاء لكل تبويب، تحريك أعلى/أسفل وحذف بأزرار مسمّاة بالصفحة، إضافة تبويب لصفحة بلا تبويب؛ عدّاد الظاهرة والحد 5 معلن ومعطّل عنده.
  - **الشريط العلوي:** عنوان (≤40) وزر سلة بعدّاد.
  - ملاحظة صريحة: يتطلب إصدار التطبيق 1.1.0+ (والأقدم يبقى على نسخته السابقة — تقرير التوافق يعرض ذلك أيضاً).
- دوال المخطط النقية (`addNavTab`, `updateNavTab`, `removeNavTab`, `moveNavTab`, `setNavTabs`, `setAppBar`, `visibleTabCount`) تفرض الحدود وترفض (null) ما يخالفها، وتحذف المفتاح الفارغ (لا `tabs: []` ولا `appBar: {}` — يرفضهما المحلل، مراجعة Codex على S09a).
- **حذف صفحة يحذف تبويبها** (وإلا صار `tab_page_missing` حاجباً للنشر).
- التعديل المرفوض لا يلوّث سجل التراجع ولا يعلّم المسودة «غير محفوظة».

## الاختبارات
- vitest: دوال المخطط (10)، اللوحة (7 بما فيها axe وتعريب كامل وصلاحيات)، وصفحة المحرر (تدفق: تفعيل ← عنوان شريط ← حفظ ⇒ `PUT` يحمل `navigation.tabs/appBar`). حزمة app-builder + lib: 1194/1194. حارس مفاتيح الوضع السهل يغطي المفاتيح الجديدة.
- Playwright: مجموعة الوضع السهل 22/22 (اختبار السحب بلوحة المفاتيح تعثّر مرة تحت حمل المجموعة الكاملة ونجح منفرداً مرتين وعلى `main` النظيف — توقيت لا انحدار).

## الحدود
- لا معاينة للشريط/التبويبات في كانفس المحرر بعد (تظهر في التطبيق 1.1.0). ترتيب التبويبات بأزرار لا بالسحب. عنوان التبويب الافتراضي = اسم الصفحة المعروض.
- ربط تبويب بصفحة `cart`/`home` يتطلب أن تكون الصفحة معلنة في المخطط.
