# S21a — الوضع السهل V2: القشرة (الويب)

**الأساس:** مبنية فوق S02 (#1827). التصميم المرجعي: مواصفة V2 (`docs/reports/AWJ-EASY-MODE-V2-SPEC.md` على الفرع `docs/app-builder-easy-mode-v2`). **لا محرك موازٍ، لا مفتاح مخطط جديد، لا API/هجرة.**

## ما نُفِّذ
- **مبدّل «سهل/متقدم»** في رأس المحرر: يبدّل العرض فقط؛ المسودة واحدة ولا شيء يُمسح (محمي باختبار: تعديل غير محفوظ يبقى عبر التبديلين). التفضيل في localStorage لكل مستخدم/تطبيق (تفضيل على الخادم = قرار مفتوح للمالك). **الافتراضي سهل.**
- **قائمة أقسام الصفحة** (`EasySectionsPanel`): أقسام = أبناء جذر الصفحة المباشرون، **مستقلة عن الصفحات**؛ عنوان فرعي مشتق وترتيب `n/m` للنوع المكرّر (عرض فقط)، نقل أعلى/أسفل، تكرار (معرّفات جديدة لكل عقدة — لا تكرار معرّف أبداً)، حذف مع **تراجع فوري داخل القائمة**، تعطيل كامل بلا صلاحية `manage`.
- **كتالوج أقسام صادق** (`EasyCatalogDialog` + `EASY_CATALOG`): بحث + تصنيفات + شارة حالة (**جاهز / جاهز بقيود / مقترح**). الأقسام الجاهزة تُبنى من مكوّنات السجل الحالي فقط (نص، زر، قائمة منتجات، محتويات السلة، ملخص السلة، صورة، بنر)؛ **المقترحة (سلايدر، شبكة منتجات، تصنيفات، فيديو، آراء، طلباتي، حساب) معطّلة بسببها ولا تُضاف أبداً.** الإضافة بعد القسم المحدد وتحديده.
- **مفتش الوضع السهل:** يخفي الربط وشرط الظهور وإضافة الأبناء (قيمها تبقى في المسودة ويعرضها المتقدم — مواصفة §8).
- دالتان نقيتان جديدتان في `lib/app-builder.ts` (`insertChildAfter`, `cloneWithFreshIds`) + `easy/editor-mode.ts`.

## معايرة الخادم
بُنيت كل الأقسام الجاهزة (7) في مخطط واحد وفُحصت بخط الخادم الفعلي (المحلل + حدود الحفظ + فاحصة العقد S02 + `CompatibilityResolver`): **0 مخالفات، متوافق**.
