# S23c — فحص axe فعلي وإصلاح المخالفات (UX-03)

**القرار:** اعتماد `axe-core` و`jest-axe` **كتبعيتَي تطوير فقط** (`devDependencies`، لا تدخل بناء الإنتاج). لا API ولا هجرة. يكمل S23b (التسميات) بالقياس الفعلي.

## ما نُفِّذ
- فحوص axe: (1) vitest/jsdom على مساحة العمل كاملة في الوضعين السهل والمتقدم + المفتش بكل محرراته (خصائص/قائمة/إجراء/ربط/ظهور)؛ (2) **متصفح حقيقي (Playwright) بحقن `axe-core` يشمل `color-contrast`** الذي لا يحسبه jsdom، على سطح المكتب 1440 والجوال 390، للوضع السهل وبعقدة محددة وللمتقدم.
- المخالفات التي كشفها الفحص وأُصلحت (كلها حقيقية):

| القاعدة | الموضع | الإصلاح |
|---|---|---|
| `select-name` | قوائم نوع الإجراء/إضافة عنصر/مصدر البيانات/ربط الحقول/وضع الظهور/الاتجاه | `aria-label` مترجم |
| `landmark-unique` | ثلاث `<aside>` بلا اسم | أسماء: الصفحات والطبقات / لوحة الخصائص / المعاينة |
| `nested-interactive` | عقدة الكانفس `role="button"` تضم عقداً مثلها | `role="group"` مُسمّى بنوعه + `aria-current` للمحدد (Enter/Space كما هما) |
| `aria-required-children` | شجرة الطبقات: منطقة dnd-kit الحيّة وأزرار الترتيب خارج `treeitem` | `accessibility.container=document.body` + نقل الأزرار داخل `treeitem` (مع حماية Enter/Space الخاصين بها) |
| `color-contrast` (serious) | نص muted على `primary-soft` في الصف المحدد وشارة «الرئيسية» | `text-primary` في الحالة المحددة |
| `page-has-heading-one` | لا `h1` | اسم التطبيق صار `h1` |
| `heading-order` | عنوان المفتش `h3` بلا `h2` | `h2` |

## الاختبارات
- vitest: +3 (axe على المساحة بوضعيها، وعلى المفتش بكل محرراته) — حزمة app-builder 320/320؛ حُدِّثت 3 اختبارات كانفس لمحدد `role="button"` إلى `tabindex`.
- Playwright: +2 (1440 و390) بكل قواعد axe شاملة التباين: **0 مخالفات**؛ مجموعة الوضع السهل كاملة 22/22.
- tsc: العدد نفسه قبل وبعد (126 خطأ قديماً في ملفات أخرى، لا جديد).

## الحدود المعلنة
- التباين فُحص في **الثيم الفاتح** فقط؛ الداكن غير مفحوص بعد.
- فحص axe لا يغني عن مراجعة قارئ شاشة فعلية؛ وصولية Flutter خارج النطاق (S25).
- مواصفات e2e تُشغَّل محلياً (ليست في بوابة CI)؛ بوابة CI تغطي فحص jsdom.
- معيار القبول الأصلي لـUX-03 («axe بلا مخالفات حرجة») متحقق بالنطاق أعلاه؛ **UX-03 مغلقة** بهذا القيد.
