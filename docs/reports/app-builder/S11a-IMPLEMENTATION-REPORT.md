# S11a — عقد التصنيفات والبحث + الجيل Runtime 1.2.0 (خادم فقط)

**الحالة:** منفَّذة (الخادم والعقد المشترك). **Flutter لا يعلن 1.2.0 بعد** (S11b) ولا الويب (S11c): لا جهاز يرسل `X-Runtime-Version: 1.2.0` الآن، فلا يتأثر أي جهاز أو مستأجر قائم. لا هجرة، لا تغيير في أي API قائم.

## ما أُضيف (كله إضافي)
| العنصر | التفصيل |
|---|---|
| الجيل | `CapabilityManifest::v120()` تراكمي فوق 1.1.0؛ يضيف `CategoryList` و`openCategory` و`openSearch` والمورد `commerce.categories`. `RuntimeGenerations::current()` = [1.0.0, 1.1.0, 1.2.0]. |
| تجميد | الجيلان 1.0.0 و1.1.0 لم يتغيرا (الثوابت `COMPONENTS/ACTIONS/DATA_RESOURCES` للجيل 1.0.0 كما هي؛ الإضافات في ثوابت `*_V120` منفصلة) — اختبار يثبت أنهما لا يعرفان شيئاً منها. |
| المكوّن | `CategoryList` (شكل قائمة `listShape`، يربط `commerce.categories`، نفس خاصيتَي `layout`/`columns` الاختياريتين لـ`ProductList`). |
| الإجراءان | `openCategory {categoryId}` (يُحلّ عادةً `$item.id`) و`openSearch` (بلا معاملات). |
| العقد المشترك | `registry-identifiers.v1.json` يحمل أقسام `components_v120`/`actions_v120` (الأساس 1.0.0 كما هو لـDart والويب حتى S11b/c). |

## سلوك التوافق (اختبارات)
- مخطط التصنيفات/البحث: **يُرندَر على 1.2.0 ويُرفض على 1.0.0/1.1.0** (لا إسقاط صامت).
- `CategoryList` الاختياري: يُسقَط ويُعلَن بالمعرّف في تقرير التوافق على الأجيال الأقدم، ولا يُسقَط على 1.2.0.
- النشر مقبول (جيل يعرضه)؛ والتقديم: جهاز 1.2.0 يأخذ نسخة التصنيفات، والأقدم (وبلا ترويسة) يأخذ **النسخة الأقدم التي يعرضها** لا نسخة لا يفهمها.
- التقرير الاستشاري للمسودة يسمّي 1.2.0 حدّاً أدنى.
- فاحصة العقد: `openCategory` بلا `categoryId` ⇒ `missing_action_param`؛ `layout` خارج التعداد ⇒ `prop_enum_invalid`.

## الاختبارات
`RuntimeGeneration120CategoriesSearchTest` (7) + تحديث اختبارات التكافؤ الستة القائمة (سجل المكوّنات/الإجراءات/`registries`/العقد المشترك/تقرير التوافق/عدد الأجيال)؛ حزمة App Builder/Compat/Archive/Experience (489) خضراء. طفرتان (حذف `CategoryList` من 1.2.0، تسريبه إلى 1.1.0 المجمَّد) تُفشلان اختبارات.
