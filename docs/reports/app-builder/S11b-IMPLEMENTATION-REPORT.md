# S11b — التصنيفات والبحث على الجهاز (Flutter) + إعلان الجيل 1.2.0

**الحالة:** منفَّذة فوق S11a (عقد الخادم). **الجهاز الآن يعلن 1.2.0** (`CapabilityManifest.current`)، فتبدأ الأجهزة المبنية بهذا الإصدار بطلب `X-Runtime-Version: 1.2.0` وتتلقى تجارب التصنيفات؛ الأجهزة المثبَّتة سابقاً لا تتأثر (جيلها المعلن ثابت في بنائها). لا تغيير في الخادم أو API.

## ما بُني
| البند | التفصيل |
|---|---|
| الجيل | `RuntimeCapabilities.*V120` (إضافات منفصلة، الجيل 1.0.0 المجمَّد لم يُلمس) + `CapabilityManifest.current` = 1.2.0 تراكمي + `CapabilityManifest.generation(platform, '1.0.0'/'1.1.0'/'1.2.0')` لأرشيف التوافق. |
| الإجراءان | `openCategory {categoryId}` و`openSearch` (decode + dispatcher + `RuntimeActionHandler` + معاينة: «يحتاج بيانات حيّة» بصدق). |
| `CategoryList` | نفس تخطيط `ProductList` (أفقي/شبكة/عمودي S10a) بعد أن يحلّ الربط `$item.*`؛ `HomeScreen`/`PageScreen` يجلبان `commerce.categories` مع المنتجات. |
| شاشة التصنيف | `GET products?category_id=` (24/صفحة) + عنوان التصنيف بأقصى جهد + «عرض المزيد» حين يقول الخادم `hasMore` فقط؛ حالات تحميل/فراغ/خطأ+إعادة؛ حارس ردّ قديم/تفكيك. |
| شاشة البحث | حقل بحث، حدّ أدنى حرفان، قصّ إلى 120، تأجيل 350ms، ردّ قديم لا يكتب فوق الأحدث، مؤقّت يُلغى مع التفكيك. |
| النتائج | `ProductResults`: صفوف كسولة (`ListView.builder`، عمودان بـ`Expanded`) تحتمل مقياس النص؛ البطاقة هي `ProductCard` نفسها بإجراء `openProduct`. |
| التنقل | `RuntimePage.category/search` + معرّف التصنيف في السجل (الرجوع يستعيد **المعرّف السابق**). |

## توافق الجهاز مع الخادم (اكتشاف أثناء العمل)
حلّال التوافق في Dart لم يكن يفحص أن المكوّن مسموح له بربط المورد (مؤجَّل منذ APP-BUILDER-17)، فبعد تفعيل `commerce.categories` كان `ProductList` المربوط بالتصنيفات يُرندَر على الجهاز بينما يرفضه الخادم. أُضيف الفحص (`CompatibilityResolver.bindableResources`) والقائمة نفسها في العقد المشترك `registry-identifiers.v1.json` (`bindableResources`) يختبرها الخادم وDart معاً. أرشيف CPT-05 (مشترك PHP/Dart): صفوف 1.2.0 لكل وثيقة + وثيقة جديدة `v1-2-categories.json` (1.0.0/1.1.0 ترفضها، 1.2.0 تقبلها).

## الاختبارات
- Dart: 19 اختباراً جديداً (الإجراءان، الحالة، `CategoryList` المربوط والنقر، الشاشتان بكل الحالات) + اختبارات العقد المشترك (V120، `bindableResources`، الجيل التراكمي، عدم تسرّب إلى 1.0.0/1.1.0) + أرشيف 1.2.0؛ 586 اختباراً خضراء و`flutter analyze` نظيف. أربع طفرات (حدّ البحث، `category_id` مفقود، فحص الربط، استعادة معرّف التصنيف) تُفشل كلٌّ منها اختباراً.
- PHP: اختبارات العقد/الأرشيف/الحلّال (154) خضراء.
