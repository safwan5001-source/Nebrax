# CPT-05 — «أرشيف نسخ»: النسخ المنشورة تبقى صالحة بعد كل ميزة (AD-02)

**الأساس:** S05b (أجيال Runtime). **لا كود إنتاج يتغيّر** — اختبارات وعقد مشترك فقط.

## ما نُفِّذ
- `contracts/app-builder/archive/` — وثائق نسخ **مجمَّدة** مشتركة بين PHP وDart (لا تُعدَّل وثيقة قائمة؛ يُضاف ملف جديد لكل شكل جديد) + `index.v1.json` بالنتيجة المتوقعة لكل جيل Runtime: `minimal`، الإثبات المتكامل القائم (منتجات + سلة + `binding.collect`)، `legacy-theme` (نُشرت قبل S04b: `primaryColor` + متغيرات `--*`)، `optional-dropped` (قسم اختياري مربوط بمورد لا يفعّله هذا الـRuntime — يُسقَط ولا يفشل).
- **PHP** `PublishedVersionArchiveTest`: كل وثيقة تمرّ `AppSchemaParser` للأبد؛ نتيجة التوافق وما يُسقَط **لا تتغيّر**؛ **ولا يكسر جيلٌ أحدث نسخةً كانت تُعرض على جيل أقدم** (يُختبر مع جيل اصطناعي لاحق).
- **Dart** `version_archive_test.dart`: التحليل والحسم التوافقي بالنتيجة المسجَّلة نفسها.
- **اختبار طفرة:** جيل لاحق اصطناعي بلا مكوّن `Section` ⇒ الاختبار يلتقط «انحدار توافق» ويسمّي الوثيقة.

## كيف يُستعمل
يُشغَّل مع كل شريحة تمسّ المخطط/المحلل/المحلل التوافقي/الأجيال؛ عند إضافة جيل Runtime حقيقي: أضف manifest الجيل إلى `RuntimeGenerations::current()` وإلى `manifestFor` في اختبار Dart، وأضف توقعات الجيل الجديد إلى الفهرس دون تعديل التوقعات القديمة.
