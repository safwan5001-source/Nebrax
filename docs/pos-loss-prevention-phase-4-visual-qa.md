**فُحص أيضاً:** حالة التحميل عبر بيانات المعاينة المعبأة، حلقات التركيز على التبويب والإجراءات، عرض المبلغ بخط Mono، وRTL/LTR لاتجاه الشريط والتبويبات.

**أخطاء الكونسول:** لا أخطاء من مكوّنات Phase 4. الملاحظة الوحيدة 404 لمورد ثابت غير متعلق بهذه الشاشات، إضافةً إلى إجهاضات جلب RSC المسبق لروابط الشريط (`?_rsc=…`) — سلوك إطار Next.js عبر التطبيق كله.

**الوضع النصي (light/dark):** يعتمد `darkMode: 'class'` عبر next-themes؛ الألوان من CSS variables/tokens.

**حدود المعاينة:** هذه اللقطات تُظهر عقد الواجهة وترجماته وتخطيطه. مصدر الحقيقة التشغيلي يبقى خادم Laravel؛ اختبارات Feature تغطي العزل وRBAC والكشف والبوابات.
