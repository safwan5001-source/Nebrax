## 3. جودة الصور المضمّنة في SVG (البند 8)
- **الـSVG أغلفة نقطية** (PNG مضمّن Base64) لا مسارات متجهة — حجم 50–80KB لكل أيقونة (≈ +33% مقابل PNG نفسه) بلا أي ميزة جودة. لذلك تستعمل المكوّنات PNG/`sm` فقط، وبقيت ملفات SVG محفوظة حرفياً للتسليم.
- **الأحجام الصغيرة:** ≥ 40px ممتاز · 32px جيد · **24px لا يصلح** (تضيع أرقام 91/95 وتفاصيل البراميل والمحطة). التوصية: ≥ 32px عاماً و≥ 40px حيث تُقرأ الأرقام. لا تُستعمل في شريط التنقل بحجم 20px.
- **الخلفية الداكنة دون لوح:** العناصر الكحلية (براميل، عدّاد، جركن، محطة، شاحنة) تقارب لون الخلفية (< 3:1) وتظهر **هالات فاتحة** على الحواف من استخراج JPEG (أثر الحزمة الأصلية). لا يمكن إصلاحها دون تعديل الرسم، فاللوح هو المعالجة المعتمدة.
- **قيد معلن:** مصدر الأصول JPEG مسطّح؛ لتوافق متجه حقيقي (تلوين ديناميكي/طباعة) يلزم تتبّع يدوي للمسارات — خارج النطاق (مذكور في README الحزمة).
