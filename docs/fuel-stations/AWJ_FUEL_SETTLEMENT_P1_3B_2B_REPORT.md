> **الحالة:** PR مستقل مبني على 2a، **بلا دمج تلقائي**. **غير موصول بأي مسار إنتاجي** (يحرسه اختبار ساكن): لا الإغلاق ولا المهمة ولا نقطة نهاية تستدعيه. يُختبر على بيانات اختبار معزولة فقط. **لا نشر، لا تفعيل لمستأجر، لا مساس بـdominah، بوابة التسوية مغلقة.** لا اعتماد ضريبي: T-1..T-6 وD4 غير محسومة، ولذلك المحرك **يرفض** إصدار أي فاتورة ما لم يُعلَن التفصيل `per_nozzle` صراحةً (شرط نشر ثالث).

## 2) القيود الناتجة (مثبتة بأرقام في `FuelShiftSettlementPostingTest`)
وردية بفوهة واحدة، عدّاد 20 لتراً، لا بيع ERP، سعر 2.30/لتر شامل ضريبة 15%، العميل = العميل النقدي للمحطة، الفاتورة آجلة:

| # | المستند | مدين | دائن | المبلغ (هللة) | الخدمة |
|---|---|---|---|---|---|
| J1 | فاتورة التسوية (فوهة واحدة) | 1130 العملاء | 4110 الإيراد | 4000 (صافٍ) | `InvoiceService::post` → `LedgerService` |
|  |  | 1130 العملاء | 2120 ضريبة المخرجات | 600 | نفسه (مجموع المدين 4600 = مجموع الدائن 4600) |
| J2 | تكلفة البضاعة | 5110 تكلفة البضاعة | 1140 المخزون | = `cogs_minor` المثبّتة على البيع (متوسط المجمّع وقت الترحيل) | `postFuelCogs` عبر `LedgerService` |
| — | حركة مخزون | خروج 20,000 مل بتاريخ الفاتورة | | | `InventoryService::applyIssue` (+ سجل تشغيلي `fuel-sale:{id}`) |

مع بيع ERP 1 لتر مسبق في الوردية: الباقي 19,000 مل ⇒ فاتورة 4370 (19 × 2.30)، والرأس يحمل `erp_milliliters = 1000`. **لا سند قبض ولا تخصيص** (J3/J4 = 2c) فالذمة 1130 مفتوحة بقدر الفاتورة. لا قيد للفروق.

## 3) الضمانات ودليلها
| الضمانة | الدليل |
|---|---|
| **ذرّية بصفر أثر** | اختبار فشل J2 بعد إدراج الرأس والسطر والبيع والفاتورة ⇒ عدّ 13 جدولاً قبل/بعد متطابق (لا رأس ولا فاتورة ولا قيد ولا ICV ولا حركة) |
| **لا ترحيل مكرر** | إعادة ⇒ `replayed` بلا أي أثر؛ على PostgreSQL 5 عمليات متزامنة ⇒ ترحيل واحد + 4 إعادات، رأس واحد وبيع واحد وفاتورة واحدة |
| **ترتيب الأقفال بلا جمود** | المحطة (NO KEY UPDATE) ← الوردية ← الفوهات/المضخات/الخزانات + **كل الترقيم (بيع وفاتورة)** ← المِرساة ← إعادة التقييم ← الترحيل. اختبار PostgreSQL: المحرك مقابل بيع ERP حيّ على الفوهة نفسها، 3 تكرارات بلا جمود. (الترقيم بعد المِرساة كان يعاكس ترتيب ERP «ترقيم ثم ترحيل»؛ لذلك الترحيل مقسوم مرحلتين) |
| **لا ترحيل على لقطة قديمة** | إعادة التقييم تحت المِرساة وبصمة تُقارَن؛ اختلاف ⇒ تراجع كامل وحجب `STATE_CHANGED`. (تاريخ المجمّع المفتوح يُدرَج بعد المقارنة كي لا يغيّر الحالة بنفسه — عيب وجدتُه بالاختبار وأصلحته) |
| **فترة مقفلة** | تُفحص على تاريخ التوريد؛ مقفلة ⇒ حجب بلا أي كتابة؛ بعد الفتح تُرحَّل بالتاريخ الأصلي (لا تاريخ بديل) |
| **حجب السطر لا الوردية** | حدث تكلفة داخل نافذة التعرّض ⇒ الرأس `withheld`، السطر `withheld_cost_pool_changed` بقيمة معلّقة، صف تاريخ مفتوح، **بلا فاتورة ولا قيد ولا مخزون** |
| **ERP لا يُحسب مرتين** | بعد الترحيل نفس التقييم يعطي الباقي نفسه (بيع التسوية `source = settlement` مستبعد من ERP) |
| **التواريخ الأربعة** | التوريد = تاريخ الفاتورة = تاريخ القيد؛ لحظة الإصدار من الفاتورة (`FuelShiftSettlementDates`) |
| **مسار البيع المباشر لم يتغيّر** | إضافات فقط في `FuelSaleService`؛ اختبارات البيع الحالية ضمن المجموعة الكاملة |
| **عدم الربط الإنتاجي** | اختبار ساكن: لا ملف في `app/` يذكر المحرك غير ملفه |

## 4) قرارات صغيرة اتُّخذت (غير مالية/ضريبية جديدة) — للتأكيد
1. **الفاعل** (`created_by`/`finalized_by`/تفويض نطاق المحطة) = مستخدم يمرّره المستدعي؛ في 2d سيكون من أغلق الوردية (`triggered_by_user_id`) وإلا فشل مغلق. لا مستخدم نظامي جديد.
2. **السعر** يُحسم عند لحظة **إغلاق** الوردية لا وقت الترحيل (تغيّر سعر بعد الإغلاق لا يُعطّل وردية سبقته؛ تغيّره أثناء الوردية يبقى `price_changed`).
3. **لا شرط تشغيل الفوهة/المضخة/الخزان الآن** للتسوية (الوقود وُزِّع في الماضي)؛ يبقى شرط انتماء الفوهة للمحطة والفرع.
4. **`settled_invoice_total_minor`** يُكتب في الرأس الثابت من القيمة المتوقعة ثم يُتحقق أنه يطابق مجموع الفواتير الفعلي وإلا تراجع (`INVOICE_TOTAL_MISMATCH`).
5. انحراف عن صف الخطة: لا `fuel_sales.settlement_line_id` (انظر هجرة 2a).

## 5) ما لا يفعله / مفتوح
لا سندات ولا تخصيص ولا فروق (2c)، لا توصيل بالمهمة (2d)، لا مانع إقفال (2e-1)، لا حسم محجوب (P1-3c)، لا أثر على ZATCA الإرسال (معطّل). **ما لا يمكن إثباته هنا:** صحة التجميع لكل فوهة ضريبياً (T-1)، مهلة الإصدار/التوريد (T-2)، تصحيح فاتورة تسوية لمستأجر ZATCA مفعَّل (D4) — كلها شروط قبل أي تفعيل. أداء N فوهات (8) لم يُقَس بعد (شرط قبل الدمج النهائي: يُضاف في 2d).
