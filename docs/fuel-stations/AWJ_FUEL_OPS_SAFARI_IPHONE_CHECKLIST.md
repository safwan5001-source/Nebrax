# قائمة اختبار تطبيق «محطات أَوْج» على Safari في آيفون حقيقي

> للمالك/QA قبل أي تفعيل. **بيانات اختبارية فقط** — مؤسسة/محطة تجريبية؛ لا تُجرَّب عمليات على محطة نبراس الفعلية ولا يُفتح `FUEL_SHIFT_CASH_RECEIPTS_ENABLED` على الإنتاج. الأرقام يجب أن تكون 0–9 في الواجهتين العربية والإنجليزية.
> المرجع: PR #2013 (UI-2) و#2023 (ملخص النقد D1/D2/D5).

**التجهيز:** آيفون بـiOS حديث · Safari (ليس Chrome) · وضع عمودي ثم أفقي · مرة بالعربية وأخرى بالإنجليزية · مرة بالمظهر الفاتح وأخرى الداكن · مستخدم بائع (بلا `fuel.sale.view`) ومستخدم مشرف.

| # | الفحص | المتوقع | ✔/✘ |
|---|---|---|---|
| 1 | فتح `/fuel-stations/ops` من Safari وتسجيل الدخول | الصفحة كاملة بلا تجاوز أفقي؛ الشريط السفلي لا يغطي المحتوى | |
| 2 | لوحة المفاتيح: حقل العهدة/القراءة | لا تكبير تلقائي للصفحة (حقول ≥16px)، والحقل يبقى ظاهراً فوق لوحة المفاتيح | |
| 3 | الحافة السفلية (home indicator) والحاجز العلوي | الزر الأساسي والشريط لا يختبئان خلفهما (`safe-area`) | |
| 4 | شريط العنوان يتقلص/يظهر أثناء التمرير | لا قفزات تخطيط؛ الزر الأساسي لا يُحجب (`dvh`) | |
| 5 | الأرقام في كل الشاشات بالعربية | 0–9 فقط، بلا أرقام هندية؛ الاتجاه RTL سليم والأرقام LTR | |
| 6 | فتح وردية بعهدة، ثم **إعادة تحميل** الصفحة أثناء الإدخال | لا وردية مكررة؛ المسودة المحلية معلَّمة بوضوح | |
| 7 | قطع الاتصال (وضع الطيران) أثناء حفظ قراءة | رسالة «قد يكون الإجراء نفذ — تحقق من حالة الوردية»؛ لا إعادة إرسال تلقائية | |
| 8 | قراءات العدادات والخزانات + شاشة المراجعة | لا حفظ قبل المراجعة؛ لا تقبل إغلاقاً أقل من الافتتاح | |
| 9 | ملخص النقد في تفاصيل الوردية (بائع بلا صلاحية المبيعات) | «غير متاح لصلاحيتك» لنقد المبيعات والفرق؛ لا رقم مخترع ولا صفر | |
| 10 | ملخص النقد (مشرف) والوردية المغلقة | «أرقام مجمّدة»؛ المتوقع الكامل أو «غير مكتمل» بأسبابه؛ الفرق «غير نهائي» لا يُسمّى زيادة/عجز | |
| 11 | التبديل بين المحطات / مستخدم مقيَّد بمحطة | لا تظهر بيانات محطة خارج النطاق؛ رابط مباشر لوردية محطة أخرى ⇒ غير موجود | |
| 12 | الروابط داخل التطبيق فقط | لا رابط يفتح صفحات إدارة ERP من حساب البائع | |
| 13 | زر الرجوع في Safari وسحب الحافة (swipe back) | يعود لشاشة صحيحة دون فقدان حالة خطرة (لا إرسال مزدوج) | |
| 14 | القراءة الصوتية VoiceOver لقسم ملخص النقد | العناوين والقيم تُقرأ بالترتيب؛ لا نص مخفي مربك | |
| 15 | الوضع الداكن والفاتح | تباين مقروء للأرقام والتحذيرات | |

**إقرار تحصيل الوردية («المبيعات والتحصيل» في شاشة التسليم)** — يُختبر فقط على مؤسسة تجريبية بعد فتح `FUEL_SHIFT_COLLECTION_DECLARATION_ENABLED` هناك (مستقلة عن بوابة نقد المبيعات؛ تبقى تلك مغلقة):

| # | الفحص | المتوقع | ✔/✘ |
|---|---|---|---|
| 16 | قسم «المبيعات والتحصيل» على الجوال (عمودي/أفقي، عربي/إنجليزي) | لا تجاوز أفقي؛ حقل لكل طريقة دفع مفعّلة؛ لوحة الأرقام العشرية تظهر؛ لا تكبير تلقائي | |
| 17 | تعطيل طريقة دفع من إعدادات المحطة (جهاز آخر) ثم العودة لتبويب Safari | القائمة تتحدث تلقائياً وتظهر رسالة «تغيّرت طرق الدفع»؛ ما كُتب للطرق المتبقية لا يضيع | |
| 18 | بائع بلا `fuel.sale.view` | اللترات ظاهرة؛ «قيمة المبيعات: تظهر للمشرف»؛ لا سعر ولا فرق؛ الحفظ يعمل | |
| 19 | عداد ناقص أو قراءة إغلاق أقل من الافتتاح | «غير متاحة — لا يُعتمد مبلغ غير موثوق» وسبب صريح؛ لا فرق نهائي | |
| 20 | انقطاع الاتصال أثناء «حفظ توزيع التحصيل» ثم إعادة المحاولة | لا نسختان؛ الرسالة «قد تكون تمت — تحقق»؛ الإعادة بالمفتاح نفسه تعيد الأثر الأول | |
| 21 | VoiceOver على القسم | كل حقل باسم طريقة الدفع ونوعها؛ الفرق يُقرأ مع «زيادة/عجز/مطابق» | |
| 22 | محاولة التسليم بلا حفظ التوزيع، ثم بعد تعديل مبلغ دون حفظ | الزر «مراجعة وتسليم» معطّل مع سبب مقروء (يُحفظ أولاً)؛ يُفتح بعد الحفظ | |
| 23 | تفعيل طريقة دفع جديدة من إعدادات المحطة بعد الحفظ | يُحجب التسليم برسالة «تغيّرت طرق الدفع»؛ يُفتح بعد إدخال مبلغها وحفظ التوزيع | |
| 24 | مشرف (يملك `fuel.sale.view`): فرق غير صفري | خانة الملاحظة تصير «سبب الفرق (إلزامي)» ولا يُفتح التسليم بدونها؛ البائع بلا الصلاحية لا يُطلب منه سبب ولا يرى فرقاً | |

**مراجعة المشرف واعتماد الوردية (`/fuel-stations/ops/shifts/{id}/review`)** — مؤسسة تجريبية، بوابة الإقرار مفتوحة هناك فقط:

| # | الفحص | المتوقع | ✔/✘ |
|---|---|---|---|
| 25 | فتح شاشة المراجعة لوردية مغلقة بفرق (عربي/إنجليزي، عمودي/أفقي) | لا تجاوز أفقي؛ بطاقة «ما الفرق بين القسمين؟» ثم المطابقة التشغيلية ثم ملخص نقد الدرج بمبالغ منفصلة؛ الشريط السفلي لا يغطي المحتوى | |
| 26 | مشرف: «اعتماد الوردية» قبل أي مراجعة | معطّل مع سبب لكل مراجعة ناقصة؛ لا يُفتح بالنقر | |
| 27 | مراجعة فرق التحصيل ثم فرق نقد الدرج (ملاحظة ≥ 3 أحرف) | تتحول الصفوف إلى «روجع»؛ لوحة المفاتيح لا تغطي الحوار ولا تكبّر الصفحة؛ بعد الثانية يُفتح الاعتماد | |
| 28 | الاعتماد بإقرار صريح | «اعتُمدت وأُقفلت»؛ تختفي كل الإجراءات؛ السجل يعرض الأحداث بتواريخها | |
| 29 | مشرف فتح الوردية بنفسه (سياسة اعتماد من مشرف آخر) | سبب واضح ولا اعتماد | |
| 30 | مستخدم بلا صلاحية الاعتماد/المراجعة | يرى الأرقام والأسباب ولا زراً فعالاً | |
| 31 | قطع الشبكة أثناء الاعتماد ثم «تحقق من الحالة» | لا إعادة إرسال تلقائية؛ يُحسم بالقراءة | |

**مركز المساعدة وAWJ Smart Guide (`/fuel-stations/ops/help`، الجولات التفاعلية)** — لا يحتاج بوابة ولا بيانات؛ يُختبر على جهاز حقيقي بحساب موظف جديد (أو بعد مسح مفتاح التخزين `awj.station-guide.v1.*`). **لم يُختبر على Safari/iPhone حقيقي بعد** (الاختبار الآلي Chromium بمقاس آيفون فقط):

| # | الفحص | المتوقع | ✔/✘ |
|---|---|---|---|
| 32 | أول دخول بحساب جديد على الرئيسية | تبدأ الجولة الترحيبية تلقائياً بعد نحو ثانية؛ بطاقة وسطية بخلفية معتمة؛ لا تُحجب الصفحة | |
| 33 | الخطوة 2 («محطتك») وما بعدها | الـSpotlight فوق العنصر الحقيقي تماماً؛ البطاقة سفلية/علوية بجانب العنصر لا فوقه؛ البطاقة فوق التنقل السفلي لا خلفه؛ لا تجاوز أفقي | |
| 34 | خطوة «التنقل» (شريط سفلي) | البطاقة في الأعلى؛ لا تتداخل مع منطقة الـhome indicator ولا مع notch | |
| 35 | أثناء الجولة: اضغط زر الشاشة الحقيقي (مثلاً «الورديات») | يعمل فوراً؛ تتوقف الجولة وتُحفظ «بدأتها ولم تكتمل»؛ لا طلب غير GET من الجولة | |

| 37 | «المساعدة ← الجولات التفاعلية ← إعادة الجولة» | ينتقل إلى الشاشة ويبدأ؛ «متابعة» لجولة غير مكتملة تستأنف من خطوتها | |
| 38 | زر «؟» على شاشات الورديات/المنتجات/الخزانات/التسليم | «ابدأ جولة هذه الشاشة» تظهر في الورقة؛ جولة التسليم تظهر فقط لمن يملك `fuel.shift.close` وتبدأ من شاشة التسليم نفسها | |
| 39 | بائع بلا صلاحية الاستلام: جولة الخزانات | 3 خطوات بلا «استلام الوقود»؛ مع `fuel.delivery.view` تصير 4 | |
| 40 | عربي RTL وإنجليزي LTR (عمودي/أفقي) | اتجاه الأسهم وأزرار «التالي/السابق» صحيح؛ النص بلا قص؛ أرقام الخطوات لاتينية | |
| 41 | Dark Mode | تباين مقروء للبطاقة والتعتيم واللون البرتقالي | |
| 42 | إعدادات إمكانية الوصول: «تقليل الحركة» | لا انتقالات ولا تمرير ناعم للـSpotlight والبطاقة | |
| 43 | VoiceOver | ينتقل التركيز إلى البطاقة عند كل خطوة ويقرأ «الخطوة x من y: العنوان» ثم الوصف؛ Esc/زر «تخطي» يغلق؛ يمكن الوصول إلى الزر الحقيقي بالتنقل | |
| 44 | تبديل الموظف على جهاز مشترك | الموظف الثاني يرى جولته الترحيبية ولا يرث تقدم الأول | |

**ما لا يُختبر على الإنتاج:** تحصيل نقدي أو تسليم خزنة أو إغلاق وردية على محطة نبراس. اختبارها على مؤسسة تجريبية بعد فتح البوابة هناك فقط وبقرار تفعيل منسّق.

**تسجيل النتيجة:** لقطة شاشة لكل ✘ مع طراز الآيفون وإصدار iOS وإصدار الـbuild.
