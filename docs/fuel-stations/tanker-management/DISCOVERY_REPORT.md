# تقرير الاكتشاف التقني — قالب بانتظار Claude Code
**الحالة:** NOT STARTED / غير منفذ  
**النطاق:** مستودع AWJ ERP + تطبيق المحطات + الوحدات المالية والمخزنية الحالية.

## ما يجب فحصه بالأدلة
1. البنية الحالية ومسارات الملفات المرتبطة بالمحطات والصهاريج والعملاء والمبيعات والتحصيلات.
2. نماذج البيانات والعلاقات القائمة.
3. خدمات API القابلة لإعادة الاستخدام ومسارات تشغيل التطبيق.
4. دورة الورديات وعدادات الفوهات والمخزون.
5. ربط العملاء بأصحاب الصهاريج وتاريخ صلاحية الإسناد.
6. تصنيف الفواتير والقبض ومنع ازدواج المخزون والقيود.
7. صلاحيات RBAC وعزل tenant/branch/warehouse.
8. جاهزية واجهة iPhone وRTL.
9. قائمة فجوات P0/P1/P2 مع أثر كل فجوة.
10. خطة تنفيذ PRs منفصلة وخطة ترحيل واختبارات/rollback.

## تعليمات
- لكل نتيجة: مسار ملف + دليل سطر/اختبار أو وصف واضح لعدم العثور.
- فصل «موجود ومثبت» عن «اقتراح جديد» و«قرار أعمال مفتوح».
- قراءة فقط في مرحلة الاكتشاف؛ لا برمجة ولا migrations ولا نشر.
- لا تعتبر هذه الصفحة تقريرًا فعليًا قبل تنفيذ الفحص وإرفاق أدلته.
