# تقرير الاكتشاف التقني — قالب بانتظار Claude Code
**الحالة:** NOT STARTED / غير منفذ  
**النطاق:** مستودع AWJ ERP + تطبيق المحطات + الوحدات المالية والمخزنية الحالية.

## ما يجب فحصه بالأدلة
1. البنية الحالية ومسارات الملفات المرتبطة بالمحطات والصهاريج والعملاء والمبيعات والتحصيلات.
2. نماذج البيانات والعلاقات القائمة.
3. خدمات API القابلة لإعادة الاستخدام ومسارات تشغيل التطبيق.
4. دورة الورديات وعدادات الفوهات والمخزون.
5. ربط العملاء بأصحاب الصهاريج وتاريخ صلاحية الإسناد.
6. تصنيف الفواتير والقبض ومنع ازدواج المخزون والقيود.
7. صلاحيات RBAC وعزل tenant/branch/warehouse.
8. جاهزية واجهة iPhone وRTL.
9. قائمة فجوات P0/P1/P2 مع أثر كل فجوة.
10. خطة تنفيذ PRs منفصلة وخطة ترحيل واختبارات/rollback.

## تعليمات
- لكل نتيجة: مسار ملف + دليل سطر/اختبار أو وصف واضح لعدم العثور.
- فصل «موجود ومثبت» عن «اقتراح جديد» و«قرار أعمال مفتوح».
- قراءة فقط في مرحلة الاكتشاف؛ لا برمجة ولا migrations ولا نشر.
- لا تعتبر هذه الصفحة تقريرًا فعليًا قبل تنفيذ الفحص وإرفاق أدلته.

## فحص مُلزم: إعداد المنتج «تتبّع المخزون»
- أظهرت لقطة واجهة إنشاء/تعديل المنتج في AWJ خيار **«تتبّع المخزون»** (checkbox). وجوده في الواجهة مثبت، أما سلوكه الفعلي في كل مسارات البيع والتعبئة فلم يُتحقق منه بعد.
- حدد مكان تخزين الإعداد ومواضع استهلاكه في أوامر المبيعات والفواتير والمخزون ومحطات الوقود.
- اختبر منطقيًا مسار منتج ديزل واحد متتبع للمخزون: (أ) تعبئة صهريج تخصم من خزان المحطة مرة واحدة، (ب) إصدار فاتورة رسمية للشركة عن كمية سبق صرفها لا تخصم المخزون مجددًا، (ج) البيع المباشر يستمر بالخصم المعتاد.
- لا تفترض أن إلغاء خيار التتبع أو إنشاء صنف ديزل آخر غير مخزني حل مقبول؛ قدم البدائل وفق الكود الحالي وأثرها المحاسبي.
- لا تنفذ تغييرات على المنتج أو قاعدة البيانات خلال الفحص.

## فحص إضافي مُلزم: العمليات اليدوية وتطبيق المحطات
- أثبتت متطلبات التشغيل أن الكميات والقراءات التراكمية تُدخل **يدويًا**، ولا يوجد اشتراط ربط أجهزة المضخات حاليًا.
- افحص إن كان التطبيق يتيح تسجيل تعبئة فردية لصاحب صهريج خلال الوردية وعدة تعبئات لصاحب واحد، وكيف تربط بسند مستقل وحركة مخزون واحدة.
- افحص إمكانية حفظ **رقم السند الورقي** وصورة أو ملف مرفق من كاميرا iPhone/الملفات، مع سجل تدقيق للإرفاق اللاحق.
- افحص كيفية إدخال قراءات البداية والنهاية يدويًا **لكل فوهة** ومطابقة فرق العداد بمجموع التعبئات عند إغلاق الوردية.
- لا تعتبر نماذج الواجهة التوضيحية المنجزة في المحادثة وظائف منتجة موجودة في النظام قبل إثباتها من الشيفرة والاختبارات.
