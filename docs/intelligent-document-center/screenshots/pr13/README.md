# أدلة واجهة PR-13

> **الغرض:** لقطات محلية قابلة لإعادة الإنتاج للتحقق البصري من التغيير المحدود في صفحة عمليات مركز المستندات على المنصة. استُخدمت معاينة التطبيق فقط؛ لم يُستدعَ endpoint تصدير حقيقي ولم يُفعّل provider أو تخزين دائم أو worker.

| الملف | البيئة | نقاط التحقق المرئية |
|---|---|---|
| `platform-operations-ar-rtl-light-desktop.png` | عربية، RTL، سطح مكتب، وضع فاتح | رابط العودة يحمل اسماً برمجياً مترجماً، بطاقات الحالة تستخدم tokens دلالية، وحالة **شبكة المزود مقفلة** ظاهرة، مع صفَّي الاحتفاظ والاستخدام دون تجاوز أفقي. |
| `platform-operations-en-ltr-dark-mobile.png` | إنجليزية، LTR، جوال 390px، وضع داكن | رابط العودة المترجم ظاهر، ترتيب البطاقات أحادي العمود يستجيب للشاشة الصغيرة، عناصر form متاحة، وحالة **Provider network is locked** ظاهرة نصياً لا باللون وحده. |

اللقطتان نتاج اختبار Playwright يدوي مؤقت. يبقى اختبار E2E المنتج منفصلاً ولا يكتب لقطات أثناء تشغيل CI.
