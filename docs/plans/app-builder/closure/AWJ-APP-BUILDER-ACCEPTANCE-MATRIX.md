# AWJ App Builder — مصفوفة القبول

> **الحالة:** مصفوفة القبول المعتمدة أساساً للبرنامج. **V2 هو مرجع القبول التصميمي للوضع السهل** (لقطات V2 وسلوكها وفحوصها الـ185 خط أساس لا يُنزَل عنه). لا فجوة تُعدّ مغلقة إلا بتحقق **كل** ما في «تعريف الإغلاق». كل الصفوف **مفتوحة** الآن.
> **المراجع:** `AWJ-APP-BUILDER-MASTER-GAP-REGISTER.md` (المعرّفات والمعايير الموجزة) · `AWJ-APP-BUILDER-FULL-CLOSURE-ROADMAP.md` · `AWJ-APP-BUILDER-ARCHITECTURE-DECISIONS.md`.

## 1) تعريف الإغلاق (لكل فجوة)

تُغلَق الفجوة فقط إذا تحقق كل ما يلي، ويُسجَّل في عمود «الحالة·الدليل» بالسجل:
1. **المعايير:** كل معيار في صفها محقَّق ومُثبَت.
2. **الاختبارات:** كل فئة مدرجة في عمود الاختبارات نُفِّذت **وخضراء في CI** (رابط التشغيل مرفق).
3. **المسار الكامل:** سيناريو E2E المربوط بها يمرّ من المحرر إلى التطبيق (جهاز أو معاينة Runtime)، لا واجهة HTML أو كانفس وحدهما.
4. **البوابات العامة:** كل بوابة في §2 خضراء للشريحة.
5. **التوثيق:** تقرير تنفيذ الشريحة (`docs/reports/app-builder/Sxx-IMPLEMENTATION-REPORT.md`) مرتبط، وأثر الهجرة/API/التوافق موثَّق.
6. **الموافقة:** دمج أو نشر **فقط** بموافقتك الصريحة.

## 2) البوابات العامة (Global Gates) — تنطبق على كل PR

| البوابة | المحتوى | الدليل |

| **G10 التوثيق** | تقرير تنفيذ + تحديث السجل + أثر الهجرة/API + خطة تراجع | مراجعة |
| **G11 لا انحدار** | تشغيل **كامل** لـ`php artisan test` وvitest وflutter test (CI أخضر) قبل أي PR | سجل CI |
