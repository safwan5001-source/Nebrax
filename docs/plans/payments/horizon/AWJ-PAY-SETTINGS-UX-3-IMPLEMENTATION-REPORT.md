## التغييرات
**تبويب وسائل الدفع**
- مربع الشرح صار جملة واحدة: «اختر وسائل الدفع وأماكن ظهورها. التحصيل الفعلي يتطلب بوابة جاهزة.» + رابط مختصر لطرق الدفع النقدية والبنكية (بقي لأن السطر المنفصل حُذف).
- حُذف النص البرتقالي المتكرر أسفل كل وسيلة؛ الصف: الشعار + الاسم + الحالة + مفتاح «إظهار» + زر «إدارة».
- نصوص «إدارة الوسيلة» مختصرة (الوصف، سبب الحالة، خطوة التالي، ملاحظات البوابة، تلميحات أماكن الاستخدام) مع بقاء البوابة الافتراضية وأماكن الاستخدام والحفظ والتحذيرات.

**تبويب بوابات الدفع — لوحة «إدارة»**
- ستة أقسام قابلة للطي (رأس `h3 > button[aria-expanded]`): الحالة والاتصال · المفاتيح والتحقق · وسائل الدفع المدعومة · Webhooks والمزامنة · العمليات المالية · الأمان والسجل. الأول مفتوح افتراضياً، ولا يُركَّب محتوى المطويّ؛ تُعاد الحالة عند فتح اتصال آخر (`key`).
- كل أزرار الإجراءات كما هي (داخل أقسامها)، بنفس الصلاحيات و`availableActions`.
- «للقراءة فقط — لا تملك صلاحية إدارة البوابات» تظهر فقط عند غياب صلاحية الإدارة (كانت جملة دائمة في الوصف).
- عنوان Webhook: `code dir=ltr` مع `overflow-wrap:anywhere`، وزر النسخ تحته على الشاشات الصغيرة؛ جداول الحقول عمود واحد تحت `sm`.
- نصوص مختصرة؛ لا أسرار تُعرض، ومفتاح استقبال Webhook يبقى مرتبطاً بما يعيده الخادم.
