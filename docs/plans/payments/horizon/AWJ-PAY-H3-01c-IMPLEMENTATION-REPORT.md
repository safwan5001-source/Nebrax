# AWJ-PAY-H3-01c — ترحيل A5 لاستردادات البوابة المؤكَّدة

DATE: 2026-10-23 · ADR: `docs/decisions/ADR-0007-payments-h3-01-gateway-refund-and-a5-matrix.md` (accepted، §6/§6.1) · يعتمد على H3-01b

## القيد الناتج (القيد المحاسبي الجديد الوحيد)
عبر `LedgerService::post` حصراً بعد تأكيد المزوّد؛ الدوران يُحلّان وقت الترحيل بـ`AccountRoleResolver`. التاريخ = تاريخ لحظة التأكيد المحلي (Asia/Riyadh).

| الحالة | الحساب | مدين | دائن |
|---|---|---|---|
| **R1** استرداد كامل (1,150.00) | 1130 العملاء + الطرف | 1,150.00 | — |
| | 1170 مقاصة البوابة | — | 1,150.00 |
| **R2** جزئي أول (400.00) | 1130 + الطرف | 400.00 | — |
| | 1170 | — | 400.00 |
| **R3** جزئي ثانٍ (750.00) | 1130 + الطرف | 750.00 | — |
| | 1170 | — | 750.00 |
| **R4** بعد التسوية البنكية | القيد نفسه (1130 مدين / 1170 دائن) — يصير رصيد 1170 دائناً التزاماً للمزوّد حتى H3-02 | | |
| R5 فشل · R6 غير معروف · R7 تكرار · R8 تجاوز | **لا قيد** | | |
| **R9** فترة/سنة مقفلة | **لا قيد** — `confirmed` + `posting_status=blocked_period` والإثبات محفوظ، بلا إعادة تأريخ | | |
| **R10** إعادة ترحيل بعد فتح رسمي | القيد R1/R2/R3 نفسه بالتاريخ الأصلي (`payments.resolve_blocked` + سبب) | | |
| R11 عكس | غير مدعوم (لا مسار `reverse`) | | |

لا سطر على 4110/`tax_output` (عُكسا بقيد التصحيح التجاري S3)، ولا مساس بـZATCA/المخزون/`Invoice::paid_amount`.

**دورة العميل كاملةً (فاتورة 1,000 + ضريبة 150):** فاتورة (مدين 1130 1,150 / دائن 4110 1,000 + 2120 150) ← التقاط A1 (مدين 1170 / دائن 1130 1,150) ← إشعار دائن (مدين 4110 + tax_output / دائن 1130 1,150) ← **A5** (مدين 1130 1,150 / دائن 1170 1,150) ⇒ 1130 = 0 و1170 = 0 والإيراد والضريبة بلا ازدواج. تثبته الاختبارات برصيد الحسابات وميزان متوازن.

## ما أُضيف
`PaymentRefundPostingService` (process/repost/runPending) · حدث `PaymentRefundConfirmed` بعد الالتزام + مستمع `PostConfirmedPaymentRefund` + شبكة أمان `payments:post-refunds` (كل 5 دقائق) · هجرة حارس انتقالات `posting_status` (مُشغّل فقط) · تحذير `blocked_refunds` في جاهزية الإقفال المالي · حارس انتقالات الترحيل في النموذج.

## الاختبارات
`PaymentRefundPostingTest` (15، SQLite وPostgreSQL): R1 بتفاصيل السطور والطرف والفرع والتاريخ · R2/R3 · R4 بتسوية فعلية · R5/R6 بلا قيد · التكرار والمفتاح الفريد · R9 وإثبات محفوظ ولا إعادة ترحيل تلقائي · R10 بالتاريخ الأصلي وسجل القرار و`still_blocked` · الصلاحية والسبب · سنة مقفلة وتحذير الإقفال · فشل مغلق عند فقد تعيين الدور ثم ترحيل بعد استعادته · المستمع يرحّل تلقائياً · الإيقاف الطارئ لا يمنع ترحيل ما خرج · حراس القاعدة · لا كتابة مباشرة في الأستاذ (حارس ساكن) · عزل المستأجر. و`PaymentRefundPostgresTest` + ترحيل متزامن (6 عمليات ⇒ قيد واحد).
