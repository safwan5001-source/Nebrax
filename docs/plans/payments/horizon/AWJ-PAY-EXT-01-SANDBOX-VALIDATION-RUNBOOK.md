# EXT-01 — دليل تحقق تكامل Moyasar Sandbox

**الغرض:** تحويل «Integration validation: PENDING» إلى دليل قابل للتكرار. **Sandbox فقط** — لا Live، ولا مفاتيح في المحادثة أو PR أو السجلات أو لقطات الشاشة. الأمر `payments:sandbox-evidence` يرفض أي اتصال أو محاولة غير Sandbox.

## المتطلبات (على المالك)
1. حساب اختبار Moyasar ومفتاح سري `sk_test_…` وقابل للنشر `pk_test_…` وسرّ توقيع webhook.
2. تُدخل المفاتيح **بنفسك** في `/finance-settings/payments` (بطاقة التكاملات ← إضافة Moyasar ← Sandbox). لا ترسلها لأي أحد.
3. بطاقات اختبار Moyasar الرسمية (نجاح/رفض/3DS) من وثائقهم: https://docs.moyasar.com — لا تُنسخ أرقامها إلى المستودع.
4. تفعيل المدفوعات الإلكترونية لمستأجر الاختبار (ضابط المنصة `online_payments`) ونبض المجدول طازج (EXT-08).

## الخطوات
| # | الخطوة | الدليل المطلوب |
|---|---|---|
| 1 | في واجهة الاتصال: **تحقق** (verify) ثم **تفعيل** | `verified_at` مضبوط؛ حالة `active` |
| 2 | سجّل عنوان webhook الظاهر في الاتصال (`/api/payment-webhooks/moyasar/{webhookKey}`) في لوحة Moyasar Sandbox مع سرّ التوقيع | حدث تجريبي يصل ويظهر في سجل أحداث الاتصال |
| 3 | أنشئ فاتورة آجلة صغيرة ثم **طلب دفع** وافتح رابط الدفع | رابط `/pay/…` يعمل |
| 4 | ادفع ببطاقة **النجاح** | المحاولة `captured` وسند قبض مرحَّل (مدين 1170 / دائن 1130) |
| 5 | كرّر ببطاقة **الرفض** وببطاقة **3DS** (إتمام ثم إلغاء) | المحاولة `failed` / `captured` (3DS) دون قيد في الفاشلة |
| 6 | شغّل: `php artisan payments:sandbox-evidence <attempt_id> --tenant=<slug> --fetch` | JSON بلا أسرار: `checks` الأربعة `true` (دفعة مسجّلة · حدث موقَّع · الاستعلام يطابق · مرحَّلة بالأستاذ) |
| 7 | **استرداد جزئي** من `/payments/online` ← استردادات (يحتاج معتمِداً ثانياً) | الاسترداد `confirmed` ثم مرحَّل (مدين 1130 / دائن 1170)؛ أعد الأمر وتحقق `refunded_minor` ويطابق الاستعلام |
| 8 | **التسوية:** Sandbox لا يصرف مبالغ حقيقية؛ أدخل أرقام كشف Moyasar (إجمالي · عمولة · صافٍ) في «التسويات» | تسوية `posted` أو `unreconciled` مع فرق مفسَّر؛ ثم «التقارير ← مطابقة المقاصة» = مطابق |

## معيار النجاح (لإغلاق EXT-01 و PAY-H2-01 و تحقق H3-01)
دفعة Sandbox حقيقية (معرّف + حدث موقَّع + استعلام fetch) · حالة رفض · حالة 3DS · استرداد حقيقي · مخرج الأمر محفوظ في تقرير التحقق · مطابقة المقاصة «مطابق». يُسجَّل في الطابور: Provider/Environment/Decision/Credentials/Integration validation (الأخيرة تتحول إلى **PASSED** بتاريخ).

## ما يُرفق وما يُحجب
يُرفق: مخرج الأمر كما هو (معرّفات وحالات ومبالغ فقط). **لا يُرفق:** مفاتيح، أجسام webhook، بيانات بطاقة، لقطات تظهر المفاتيح.

## التراجع
أوقف الاتصال (`suspend`) أو ألغِ اعتماده (`revoke`) من الواجهة، وأطفئ ضابط المستأجر `online_payments`؛ لا تأثير على المستندات المرحَّلة (التصحيح بقيود عكسية فقط).

## خارج النطاق
Live (G-LIVE) · أي Deploy أو Production Migration (قرار مستقل منك) · ضريبة الرسوم (`tax_input`) تبقى مغلقة حتى EXT-05.
