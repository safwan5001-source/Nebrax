# PAY-H6-01 — Implementation Report

STATUS: **MERGED** (PR #1625، `e4f2976c5`؛ POST_MERGE_REVIEW: PASS — CI أخضر على main، run 39865103670؛ غير منشور) · DATE: 2026-10-22
القرار: **D-09 — الخيار 1 (اعتمده المالك):** مقاصة بطاقات POS **اختيارية لكل طريقة دفع، ومعطّلة افتراضياً لجميع المستأجرين**.

## Outcome

- `payment_methods.pos_clearing_gateway_id` (NULL = مطفأ): طريقة **بنكية** مربوطة باتصال مستحوذ نشط ⇒ سند قبض POS بها يُرحَّل **A12** عبر `PaymentService` القائم (لا مسار موازٍ)، والتسوية القائمة (`PaymentGatewaySettlementService`) تنقل 1170 إلى البنك + الرسوم.
- مرجع العملية الاختياري على الوسيلة: `approval_code` · `rrn` · `last4` ⇒ `payments.reference` (RRN وإلا رمز الموافقة) و`payments.payment_details` (JSON). لا PAN ولا CVV أبداً؛ لا أثر على أي قيد.
- إقفال الجلسة يميّز المقاصة: `clearing_amount` في المعاينة واللقطة (يُحجب مع العدّ الأعمى).
- **صفر تغيير** لأي مستأجر قائم، ولأي قيد تاريخي، ولطلب POS قديم (بصمة idempotency لا تتغير ما لم تُرسَل مراجع).

## Design

| القرار | السبب |
|---|---|
| الربط على الطريقة (`pos_clearing_gateway_id`) لا على الاتصال | سياسة لكل طريقة (D-09)؛ NULL افتراضي ⇒ لا ترحيل لأي مستأجر؛ اسم خاص بـPOS يميّزه عن `payment_gateways.payment_method_id` القائم (قناة الدفع الإلكتروني) |
| السند يلتقط اتصاله وقت الإنشاء (`payments.payment_gateway_id`) | تعديل/فك الربط لاحقاً لا يغيّر سنداً مرحَّلاً (مختبَر: سند + قيده بلا تغيير) |
| الطريقة البنكية فقط؛ اتصال المستأجر النشط فقط عند الربط؛ الربط القائم لا يُعاد فحصه عند تعديل حقول أخرى | لا ربط نقد؛ لا حجب تعديل الطريقة لأن اتصالها أُوقف |
| **اتصال مربوط غير نشط (موقوف/ملغى/محذوف) ⇒ رفض البيع قبل أي مستند (422)، لا عودة صامتة إلى A11** | العودة الصامتة تغيّر القيد الذي اختاره المالك؛ يختار الكاشير وسيلة أخرى أو يفك المالك الربط. قرار فشل مغلق لا قرار محاسبة جديد |
| `PUT payment-methods` بلا المفتاح يُبقي الربط؛ `null` يفكّه | توافق عميل قديم لا يرسل الحقل |
| الاتصال/الحساب/المقاصة لا تُقبل من العميل (`array:payment_method_id,amount,approval_code,rrn,last4`) | الخادم يشتقها من الوسيلة؛ تهريب `payment_gateway_id`/`clearing_account_id` ⇒ 422 |
| المراجع تدخل بصمة idempotency **فقط عند وجودها** | بيع قديم بلا مراجع يحتفظ ببصمته؛ المرجع المختلف بنفس المفتاح ⇒ 409 |
| FK بلا CASCADE؛ `hasFinancialReferences()` تشمل الطرق المربوطة | اتصال مربوط لا يُحذف؛ حذف المستأجر المتسلسل يمر (التحقق نهاية العبارة) |
| `down()` يرفض متى وُجد ربط أو لقطة مميِّزة | إسقاط العمود يمحو قرار توجيه محاسبي |
