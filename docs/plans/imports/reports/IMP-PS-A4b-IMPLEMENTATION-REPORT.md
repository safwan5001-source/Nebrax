### قرار تصميم يستحق مراجعة المالك
**`override` بمجموعة لا تساوي السطر ضمن التسامح:** الخطة تقول «verify-set يمنع تأكيد مجموعة لا تساوي السطر»، والخادم يسمح بها بـ`accept_difference` + سبب. نُفِّذ الجمع: **تُمنع** عند وجود `problems`، و**تُسمح** فقط بإقرار صريح (خانة) وسبب. إن أراد المالك المنع الصلب، تعديل سطر واحد في `line-detail.tsx` (`overrideBlock`).

### إصلاح متانة اكتُشف أثناء الاختبار
لقطة Playwright لصفحة كاملة تُصغّر النافذة لحظياً فتقلب `useIsDesktop` وتعيد تركيب لوحة السطر وتُضيع اختيار الوحدات ونتيجة التحقق. لأن تدوير هاتف عبر 768px يسبّب الشيء نفسه فعلياً، **رُفعت حالة العمل (`mode/unitKeys/verify/pair`) إلى المالك** فتبقى عبر إعادة التركيب (مغطّى باختبار e2e).
