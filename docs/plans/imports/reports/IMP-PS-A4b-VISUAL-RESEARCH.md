## 4. حالات التفاعل المقترحة (تسبق التنفيذ)

| الحالة | العرض |
|---|---|
| لا تشغيلة بعد | سطور الكشف من `GET /lines` (قراءة فقط) + زر «شغّل المطابقة» + شرح؛ لا أعمدة نتيجة. |
| تشغيلة جارية | الزر معطّل بحالة تحميل؛ 429 ⇒ رسالة انتظار. |
| تشغيلة مُعادة (`replayed`) | إشعار «لا تغيّر في الدفتر أو الكشف؛ هذه آخر تشغيلة نفسها». |
| `ledger_changed` | شريط تحذير: «الدفتر تغيّر منذ التشغيلة» + «شغّل مطابقة جديدة»؛ قرارات الكتابة تبقى متاحة لكن الخادم يرفض بـ`run_stale`. |
| سطر بلا قرار / بقرار / بقرار على تشغيلة أخرى | شارة «بلا قرار» / شارة الإجراء / شارة «يلزم إعادة الاعتماد». |
| قرار قيد الإرسال/فشل/إعادة | شارة «قيد الإرسال…»؛ فشل ⇒ أيقونة + «أعد المحاولة» يدوياً؛ 429 ⇒ «سنعيد تلقائياً بعد N ثانية». |
| `suspended` / `disabled` / بلا `reconcile` | قراءة فقط (بلا أزرار كتابة) / شاشة غير مفعّلة / عرض بلا إجراءات. |
| `reviewed` | شريط «مراجَعة» + (قراءة فقط للقرارات) + «إعادة فتح» بسبب إلزامي؛ `ledger_changed_since_review` تحذير. |
| `closed/voided/superseded` | قراءة فقط كاملة + لا إجراء دورة حياة (A4c). |
