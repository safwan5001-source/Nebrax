## ب) الفجوة مقابل «تصدير جميع أنواع المستندات والتقارير عبر Public API»
| الهدف | الوضع الحالي | الفجوة |
|---|---|---|
| بيانات المستند (JSON) | فواتير/عملاء/منتجات فقط في Public API | بقية الأنواع تتبع مسار P2 (عروض، مشتريات، سندات…) |
| CSV/XLSX للتقارير والقوائم | غير موجود للتقارير؛ موجود للمنتجات/المخزون داخلياً | غلاف Public فوق `SpreadsheetWriter` + قائمة بيضاء + سقف صفوف |
| PDF رسمي مطابق للقالب المثبت | يُرسم في المتصفح فقط | **قرار معماري**: محرك رسم خادمي (أو الاكتفاء بالبيانات + القالب) |
| XML ZATCA للفاتورة | مخزَّن في الفاتورة | كشفه للقراءة فقط عبر scope مستقل |

## ج) طريقة آمنة مقترحة (مرحلية، كل مرحلة قابلة للإيقاف)
1. **E0 — صفر محرك جديد:** `documents:read` لجلب بيانات المستند الكاملة (JSON) + معرّفات مراجعات القالب المثبتة + `zatca_xml` للفاتورة المرحَّلة (scope أضيق). تغطي أنواعاً تزداد مع P2.
2. **E1 — CSV/XLSX:** `exports:read` يعيد استخدام `SpreadsheetWriter` لقائمة بيضاء من التقارير والقوائم (مبيعات، مشتريات، مركز الذمم، كشف حساب…). صيغة عبر معامل `format=csv|xlsx`.
3. **E2 — PDF الرسمي:** يتطلب قراراً مسبقاً بأحد مسارين: (أ) إضافة خدمة رسم خادمية تعيد استعمال **نفس القالب المثبت** (`pdf_template_revision_id`) والخطوط؛ أو (ب) إبقاء PDF داخلياً في المتصفح وتسليم الوكيل البيانات + XML فقط. لا يُنفَّذ قبل اختبار تطابق بصري RTL مع ناتج الواجهة.

**ضوابط إلزامية لكل مرحلة:**
- توليد غير متزامن لما يكبر (`202` + `export_id`)، وتنزيل برابط **موقَّع قصير العمر** مربوط بالمستأجر وبالمفتاح؛ لا تخزين عام.
- نطاق المستأجر والفرع كما في بقية Public API، وscope مستقل لكل عائلة (مستندات / تقارير / مالي حساس مثل كشوف الأرصدة).
- قائمة بيضاء للتقارير والحقول، سقف صفوف وحجم، حد معدّل أشد، وتدقيق لكل تصدير (من/ماذا/متى) عبر `PublicApiRequestAudit`.
- حماية حقن الصيغ في CSV/XLSX (إبطال الخلايا التي تبدأ بـ `=` `+` `-` `@`).
- المستند **المسودة** يُصدَّر بعلامة «مسودة» ولا يُقدَّم كرسمي؛ الرسمي = مرحَّل + قالب مثبت.
- Idempotency على إنشاء مهمة التصدير، وWebhook اختياري عند الاكتمال (الـ Webhooks موجودة).
- لا تغيير في قواعد المحاسبة أو الصلاحيات الداخلية؛ scopes جديدة تُربط بصلاحيات RBAC القائمة (`reports.view`، `invoices.view`…).
