# AWJ ERP — Customer Accounts Settings UI (التقرير النهائي)

**الشريحة:** واجهة إعداد «حسابات العملاء» لقناة الويب (B2C) — واجهة فقط، بلا تغيير في الـ backend.
**الحالة:** جاهز لمراجعة ChatGPT. **لا دمج ولا نشر.**

## 1. ملخص التنفيذ

شاشة جديدة `/commerce/customer-accounts` (التجارة الإلكترونية ← القناة ← حسابات العملاء) تعرض القيمة **المحفوظة فعلاً**
وتغيّرها عبر الواجهة القائمة نفسها دون أي backend جديد:

- القراءة: `GET /api/commerce/channels/{id}/pricing-settings` → `customer_accounts_enabled` + `customer_accounts_deployment_enabled`.
- الكتابة: `PUT` على المسار نفسه بالحمولة `{ "customer_accounts_enabled": true|false }` فقط (لا `tenant_id`).

**السلوك**

| الجانب | القرار |
|---|---|
| المفتاح الأساسي | «السماح بإنشاء حسابات العملاء» + الوصف المطلوب حرفياً. |
| النموذج | مسودة: تحريك المفتاح لا يرسل شيئاً. شارة «تغييرات غير محفوظة» + «حفظ/تراجع». إعادة المفتاح لقيمته المحفوظة تمسح المسودة. |
| صدق النجاح | لا رسالة نجاح إلا بعد استجابة الخادم التي تعيد **القناة نفسها** و**القيمة المطلوبة**؛ غير ذلك = «لم يؤكّد الخادم». المفتاح مقفل أثناء الحفظ. |
| الحالة المعروضة | مشتقة من القيمة المحفوظة لا من المسودة: مفعّلة · غير مفعّلة · «مفعّلة في القناة — غير متاحة للمتسوقين» (القناة on والبوابة off). |
| مفعّلة | يشرح أن التسجيل وتسجيل الدخول متاحان (وإدارة العناوين ومتابعة الطلبات). |
| معطّلة | يشرح أن التسجيل الجديد ودخول العملاء غير متاحين وأن **الشراء كضيف يبقى متاحاً**. |
| بوابة النشر (409) | القناة off والبوابة مغلقة ⇒ المفتاح معطّل برسالة. إن ردّ الخادم 409 `customer_accounts_deployment_disabled` تظهر الرسالة، تُعاد قراءة الحالة الحقيقية، وتبقى القيمة المحفوظة كما هي. |
| الصلاحية | `commerce.channel_settings.manage` (مالك/مدير). بدونها: حالة «لا تملك صلاحية» **بلا أي طلب**. 403 عند القراءة/الحفظ تُعالج. |
| تعدد المتاجر | تُطبَّق على قناة **المتجر المحدد** في مساحة التجارة (`StoreGate`، المكوّن يُركَّب بـ`key={store.id}`): اسم المتجر واسم القناة ظاهران، ولا تنتقل مسودة بين متجرين. معرّف القناة يأتي حصراً من كتالوج المستأجر المحمَّل من الخادم؛ والخادم يعزل بـTenantScope (قناة مستأجر آخر = 404). متجر بلا قناة ⇒ شرح بلا طلب. |
| آخر تغيير | سطر من `recent_changes` (من/متى/بواسطة) للمفتاح نفسه. |
| الشريط الجانبي | عنصر «حسابات العملاء» ضمن مجموعة «القناة»، مشروط بالصلاحية وقدرة `commerce.storefront`. |

**قرار على الموضع:** لا يوجد في الشريط عنصر باسم «إعدادات المتجر»؛ وُضعت الشاشة في «القناة» وكُتب في ترويستها «التجارة الإلكترونية · إعدادات المتجر». نقلها إلى مجموعة أخرى تعديل سطر واحد في `nav.ts`.

**ما لم يُمسّ:** المخطط، القواعد المحاسبية، ضوابط الجملة (`wholesale_*`، قوائم الأسعار)، مفتاح النشر `COMMERCE_RETAIL_ACCOUNTS_ENABLED`/Railway، الدفع كضيف، لا تفعيل جماعي. لا ملف في `app/` أو `routes/` أو `database/`.
(ملف `wholesale/channel.ts` لم يُعدَّل؛ يُستورد منه `channelSettingsPath` فقط.)

**تغطية المطلوب**
- القناة المحددة والحالة المحفوظة: قراءة `ch-a` ثم `ch-b` عند تبديل المتجر، ولا تنتقل المسودة (وحدة + E2E).
- مفعّل/معطّل: نصوص الحالة والشرح بالعربية والإنجليزية.
- غير مصرّح: لا طلب إطلاقاً؛ 403 عند القراءة وعند الحفظ.
- 409: رسالة، إعادة قراءة، بقاء الحالة المحفوظة؛ وأيضاً منع التفعيل مسبقاً حين البوابة مغلقة.
- RTL/LTR: `dir` الصفحة (rtl/ltr)، وحارس مصدر يمنع الفئات الفيزيائية (`ml-/pl-/left-/text-left…`).
- الجوال: iPhone 390 — بلا تمرير أفقي (يُفحص في E2E)، أزرار الحفظ/التراجع مكدّسة بعرض كامل، صف المفتاح بارتفاع ≥ 44px (`min-h-11`).
- لقطات الشاشة مُراجَعة يدوياً (ar-unsaved، en-409) وتُنتَج عبر `CUSTOMER_ACCOUNTS_SHOTS=<dir>`.

## 5. المخاطر والمتبقي

1. **هذا لا يفتح الميزة للمتسوقين وحده.** يلزم أيضاً أن يعلن المتجر العام `customer_accounts` ويمرّ فحص جاهزية التفعيل `php artisan commerce:retail-accounts-readiness` (مذكور في CLAUDE.md؛ البوابة الأخيرة تخص حدّ IP المشترك وترجمة اللغات). أي تفعيل لمستأجر حي قرار منفصل.
2. النص أسفل المفتاح يصف الحالة **المحفوظة**؛ أثناء مسودة غير محفوظة يظهر بجوارها «تغييرات غير محفوظة» لكن لا جملة «ستسري بعد الحفظ». تحسين نصّي اختياري.
3. تعطيل القناة يوقف تسجيل ودخول عملاء حاليين فوراً (لا حذف حسابات/طلبات). النص التحذيري يظهر قبل الحفظ؛ لم أضف حوار تأكيد ثانياً لأن الحفظ نفسه خطوة تأكيد.
4. `e2e` يعتمد على اعتراض API (لا backend حي)؛ لم يُجرَّب ضد Railway.
5. ESLint غير مهيّأ في `web/` (خارج النطاق).
6. شارة «Issues» في لقطات dev: ضجيج `INVALID_KEY` قديم من `developer.events` ولا علاقة له بهذه الشريحة.
