## 1. ما بُني

شاشة `/commerce/store-operations` («تشغيل المتجر») لمتجر القناة المحدَّد (`StoreGate`، `commerce.channel_settings.manage` + قدرة المتجر)، فوق `GET|PUT commerce/channels/{id}/operations-settings`:

- **الإيقاف المؤقت:** مفتاح، استئناف تلقائي اختياري (`datetime-local` ← ISO UTC)، رسالة قصيرة (≤ 200، نص عادي). الاستئناف يمسح موعد الاستئناف القديم في الحفظ نفسه.
- **ساعات العمل:** محرر أسبوعي (الأحد..السبت، حتى 3 فترات لليوم و21 للأسبوع، «حتى نهاية اليوم» = 24:00، بلا فترات عابرة لمنتصف الليل) + سياسة ما خارج الساعات (`accept|block`). بلا فترات = مفتوح دائماً.
- **الحد الأدنى:** يُكتب **بالريال** ويُرسَل **بالهللات (عدد صحيح)** + النطاق (`all|delivery_only`).
- **الحفظ:** تغييرات فقط + `expected_version` إلزامي؛ تعارض النسخة ⇒ يُحدَّث العرض وتبقى مسودة المستخدم ويُطلب مراجعتها (لا كتابة فوق)؛ قفل إرسال مكرر؛ تحذير تغييرات غير محفوظة؛ تراجع.
- **البوابة D-H4-03:** `intake_controls_deployment_enabled=false` ⇒ إشعار «الإنفاذ غير مفعّل» ويُعطَّل الانتقال إلى حجب (إيقاف/`block`/حدّ أدنى جديد) مع السبب؛ الإبقاء على القائم والرجوع للافتراضي وضبط الساعات والرسالة مسموح — كما يفرض الخادم (409) تماماً.
- عنصر تنقل (`commerce.channel_settings.manage` + `commerce.storefront`) وبطاقة في مركز الإعدادات؛ ar/en.

## 2. ما لم يُفعل

لا مصدر حقيقة ثانٍ في المتصفح (القيم والنسخة وحالة البوابة من الخادم) · لا واجهة لمفاتيح القبول (`acceptance_*`) — API فقط منذ H1-3، تبقى خارج النطاق المعتمد · لا لافتة متجر عامة (واجهة لاحقة على كتلة `ordering`).
