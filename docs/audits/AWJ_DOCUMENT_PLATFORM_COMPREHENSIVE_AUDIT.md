## 0. الخلاصة التنفيذية

**الحكم:** منصة القوالب (التعريف، المراجعات، التعيينات، التجميد التاريخي، العزل) **سليمة ومحروسة باختبارات**. المشكلة ليست في القوالب بل في **طبقة الإخراج** (PDF / الطباعة / الحراري / المقاسات) وفي **تغطية المستندات**.

| # | النتيجة (مُقاسة بالدليل) | الأولوية |
|---|---|---|
| 1 | **PDF الفواتير والمستندات التجارية صورة نقطية غير مضغوطة**: 6.7 MB لفاتورة صفحة واحدة، 24.3 MB لأربع صفحات، **بلا طبقة نص** (لا بحث/نسخ). نفس المستند عبر طباعة Chromium = 42–92 KB بنص حقيقي. | **P0** |
| 2 | `@page { size: 80mm auto }` **غير صالح CSS**: Chromium يُسقط الإعلان ويرجع إلى A4 الأساسي. الإيصال الحراري عبر الطباعة المتصفحية لا يُبلّغ المتصفح بمقاس الرول. (لم يُختبر على طابعة حرارية حقيقية.) | **P0 مشروط** بتأكيد الجهاز |
| 3 | **صفحات يتيمة/شبه فارغة** في PDF متعدد الصفحات: 4 من 4 مستندات متعددة الصفحات انتهت بصفحة حبرها ≤ 0.3% (تذييل مقطوع). | P1 |
| 4 | **المعاينة ≠ PDF ≠ الطباعة**: هوامش 0 / 14mm / 10mm، وعدد الصفحات يختلف (4 مقابل 3) لنفس المستند. | P1 |
| 5 | **المقاس ليس خاصية قابلة للضبط**: لا A5 ولا A6 ولا مقاس مخصص في أي طبقة؛ Letter/Legal/A4-أفقي معلنة في السجل لكن **لا يمكن الوصول إليها** (الواجهة تأخذ `supportedPaper[0]` = A4 دائماً). | P1 |
| 6 | **أربع شاشات تطبع واجهة الشاشة نفسها** (`window.print()`): مصروف، سند قبض (صفحة `/receipt-vouchers`)، عهدة موظف، تقرير نقطة البيع — لا قالب ولا ترويسة ولا ختم، وأقسام مطوية تختفي. | P1 |
| 7 | **مستندات غير موجودة فعلياً**: سند تسليم/قائمة تعبئة/أمر بيع (معرّفة في السجل فقط)، تقرير إغلاق/تسليم وردية الوقود، قسيمة راتب، أذون مخزنية/جرد، قيد يومية، ملصقات باركود/أسعار. | P1 |
| 8 | **تغطية اختبارات الإخراج ضعيفة**: لا e2e للحراري، لا فحص لمحتوى PDF، لا WebKit؛ مواصفات e2e الحالية تقيس عرض الشاشة فقط. | P1 |
| 9 | **تكرار ودين تقني**: محرك PDF متجه كامل (`createInvoicePdf`، 596 سطراً) **غير موصول بأي شاشة**، و5 نسخ من محمّل الخط، و«الخط العريض» نفس ملف الخط العادي. | P2 |

**ما يعمل ويجب الحفاظ عليه:** تجميد المراجعات (print/pdf/thermal) للمستندات المرحّلة، أولوية التعيين (فرع ← مؤسسة)، عزل المستأجر، `documentExporter` كواجهة تبديل، سندات القبض/الصرف وكشوف الحساب والتقارير كـ PDF **متجه بنص حقيقي** (111–122 KB).

**التوصية المعمارية المختصرة:** لا محرك جديد الآن. (1) تثبيت المحرك الحالي (ضغط، صفحات يتيمة، هوامش موحدة، `@page` الحراري) — (2) عقد «ملف إخراج» إضافي (مقاس/اتجاه/هوامش) داخل تعريف المراجعة، **افتراضه A4 الحالي** — (3) ربط الشاشات الخام والمستندات الناقصة بالسجل — (4) سبايك مُقاس لاختيار طريق PDF ذي طبقة نص (وPDF/A-3 لـ ZATCA) قبل أي قرار محرك.

- عقد القوالب: مراجعات غير قابلة للتغيير، بصمة SHA-256، تعيين فرع←مؤسسة، تحقق الكتل/الخصائص خادمياً، عزل المستأجر، الصلاحيات (`invoices.view` / `company.manage`). **[A] 64 اختباراً.**

## 9. التوصيات المعمارية

1. **ملف إخراج Output Profile (إضافي):** `{ paper: PaperSizeId | {w,h}, orientation, margins_mm, mode: 'page'|'roll' }` داخل `definition` المراجعة. غيابه = A4 + هوامش اليوم. يُشتق منه `@page` وحجم PDF وصفحة الحراري من **مصدر واحد**. التحقق خادمياً في `PrintTemplateContract` (بديل: قائمة بيضاء). يُجمَّد مع المراجعة تلقائياً ⇒ لا مساس بالتاريخي.
2. **المقاس سياسة تُضبط لا تُفرض (قاعدة 6):** افتراض نوع مستند، تجاوز فرع، ثم المراجعة؛ لا إطار سياسات موازٍ (Build for Policy Readiness).
3. **تثبيت المحرك الحالي أولاً:** ضغط (`compress`/JPEG للصفحات)، التقطيع بوعي بالمحتوى الفعلي، `@page` صالح للحراري، هوامش موحدة معلنة، ثم **ميزانية حجم** و«لا صفحة فارغة» كاختبارات.
4. **الطباعة الحرارية:** اعتماد قرار بعد اختبار جهاز بين: (أ) رول السائق + هامش صفر، (ب) جسر الأجهزة (موجود لدرج النقد، لم يُوسَّع للإيصال)، (ج) PDF بارتفاع المحتوى (موجود وسليم). لا تُختار قبل القياس على طابعتين على الأقل.
5. **إزالة الطباعة الخام:** نقل المصروف/عهدة/تقرير POS/سند القبض الثاني إلى مستند مسجّل (أو إلى `/payments/[id]` للسند) بتثبيت اختياري.
6. **سد النواقص بحسب الأثر:** سند التسليم (السجل جاهز) ← تقرير إغلاق وردية الوقود (بناء خادمي كـ `FuelDeliveryDocumentBuilder`) ← قسيمة الراتب ← باقي المستندات.
7. **اختبارات الإخراج:** Playwright يولّد PDF/طباعة لعينات QA ويتحقق: حجم ≤ ميزانية، وجود نص، لا صفحة حبرها < عتبة، عدد الصفحات، عرض الحراري؛ + WebKit في CI عند توفره + قائمة اختبار جهاز يدوية.
8. **تنظيف:** توحيد محمّل الخط، حذف محرك الفاتورة المتجه الميت بعد مسح مستهلكين خارجيين، إصلاح الوثائق.
9. **قرار PDF بطبقة نص / PDF/A-3** عبر ADR مبني على سبايك (§10 Phase 4) ومنسَّق مع REM-24؛ **بلا مساس بـ ZATCA XML/QR/الهاش**.
