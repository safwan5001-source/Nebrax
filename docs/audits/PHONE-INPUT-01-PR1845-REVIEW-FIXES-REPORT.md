## 2. جرد مستهلكي API التسجيل والتوافق الرجعي

`POST /api/register` (`routes/api.php:254`، اسم المسار `auth.public-register`) هو **المستهلك الوحيد لـ`RegisterRequest`** (`AuthController::register`).

| المستهلك | يرسل `phone`؟ | الأثر |
|---|---|---|
| `web/src/app/register/page.tsx` | نعم، E.164 دائماً (`+966…` سابقاً، دولي الآن) | لا أثر |
| `tests/Feature/PlatformTenantManagementTest` | نعم، **`0500000000`** | كان سيفشل ← أُصلح؛ يمرّ دون تعديل |
| `InteractsWithApi::registerTenant` وعشرات الاختبارات (ZATCA/الخزينة/…) | لا | لا أثر |
| `TenantProvisioningE2ETest`، `TenantSubdomainAuthTest`، `TenantReferenceNumberTest`، `PublicRegistrationTenantHostnameTest`، `FlatStorefrontHostTest`، `ApiAuthTest` | لا | لا أثر (شُغِّلت ✓) |
| تسجيل العملاء/المشترين (`CustomerRegisterRequest`، `BuyerRegisterRequest`، `commerce_client.dart`، `storefront/`) | مسارات **مختلفة** وطلبات مختلفة | خارج النطاق، لم تُمَسّ |
| مستهلكو بيانات الجوال بعد التسجيل: `PlatformTenantService` (عرض جهة الاتصال)، `AccountSettingsController` (عرض) | قراءة فقط | لا يعتمدان على صيغة معيّنة |
| OpenAPI / مستندات المطور | لا يوثّقان تسجيل المستأجر | لا تحديث مطلوب |

**قرار التوافق (الخادم):**

- أرقام عربية/فارسية/عريضة ← **0–9 دائماً** (قاعدة الأرقام الإنجليزية تسري على كل ما يُحفظ)، وإزالة علامات الاتجاه.
- قيمة تبدأ بـ`+` ← مسافات/فواصل/أقواس تُزال ثم **شكل E.164 فقط** (`+` ثم 7–15 رقماً أولها 1–9)، وإلا 422.
- أي قيمة أخرى (محلية قديمة، أو `00…`) ← **تُقبل وتُخزَّن حرفياً** (`max:255` كما كانت). **لا نضيف `+966` ولا نخمّن دولة ولا نحوّل `00` إلى `+`** (`00` ليست بادئة دولية عالمية، ولا فائدة من تخمين لا نحتاجه).
- الواجهة هي من يرسل E.164 بعد تحقق الدولة، فلا يتأثر المسار الأساسي.

## 4. رموز الاتصال المشتركة

اختبارات `phone.test.ts` تحسب المفاتيح المشتركة من بيانات libphonenumber نفسها (12 مفتاحاً: `+1` (25 دولة/منطقة) و`+44` (4) و`+61` و`+590` (3) و`+7` و`+39` و`+47` و`+212` و`+262` و`+290` و`+358` و`+599` (2)) وتتحقق:

- **لكل مفتاح مشترك:** الدولة الرئيسية معرّفة، وحرف `+code` الجزئي يُبقي الدولة التي اختارها المستخدم (`preferred`) ويعود للرئيسية حين لا تفضيل.
- **كل دولة لها رقم مثال جوال (>200):** لصق → تفكيك → إعادة بناء يعيد **نفس E.164 حرفياً** ويبقى صالحاً (لا تغيير صامت للرقم في أي دولة).
- **NANP:** رقم كندي (416) يُلصق مع أمريكا مختارة ← كندا، والعكس؛ الرقم لا يتغيّر. رقم جزئي/وهمي (`+1555`) لا يقلب الدولة المختارة.
- **+44:** بيانات libphonenumber نفسها تُحسم مثال جزيرة مان إلى `GB` (نطاقات متداخلة)؛ **الرقم لا يتغيّر والدولة ضمن أصحاب المفتاح** — فارق عرض فقط من المكتبة، لا خطأ تحويل. (`JE` و`GG` تُحسمان صحيحاً.)
- **الاسترجاع:** `stateFromValue('+1416','CA')` يبقى كندا؛ `+14162345678` مع أمريكا مفضّلة ← كندا (الرقم يحسم)؛ إعادة تعيين قيمة خارجية جزئية لا تقلب الشقيقة المختارة.
- **التبديل:** US ↔ CA يُبقي E.164 نفسه، ولا يظهر تنبيه «أبقينا الرقم» (المفتاح لم يتغيّر).
- **البحث:** `+1` يضع الولايات المتحدة أولاً ثم الشقيقات، و`+7`→RU، `+44`→GB.
