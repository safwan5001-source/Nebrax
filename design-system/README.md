# نظام تصميم نبراس (Nibras Design System)

> المرجع الرسمي الوحيد لبناء واجهات **نبراس ERP**. أي مطوّر جديد يجب أن يبني شاشة
> بجودة بقية النظام اعتماداً على هذا المجلد وحده، دون سؤال تصميمي.

الحالة: **v2.0** — نضج وتوثيق كامل فوق أساس **v1.0** المُنفَّذ. لم تتغيّر الهوية:
نفس الألوان، نفس الخطّين، نفس الفلسفة. أُضيفت فقط الطبقات الناقصة (مقاييس، أنظمة،
مواصفات، حوكمة).

---

## المبدأ الحاكم (لا يتغيّر)

**أداة عمل محاسبية يومية — الأولوية للوضوح والكثافة والسرعة والثقة، لا الإبهار.**
الجداول هي البطل · لون هوية واحد · خطّان · بلا زخرفة · تباين دلالي فوري (لون + إشارة).

المرجع الجمالي: نضج **Stripe / Linear / Vercel / GitHub / Notion** — مطوّعاً لنظام ERP مالي
(كثافة أعلى، أرقام أدق، حياد أكبر).

---

## القاعدة الذهبية (اقرأها قبل أي شيء)

1. **لا قيمة hex خام في المكوّنات.** استخدم رموز Tailwind المربوطة بالمتغيّرات فقط.
2. **لون هوية واحد** (`primary`). الأخضر/الأحمر/البرتقالي **دلالية مالية فقط**، دائماً مع إشارة لا لون وحده.
3. **خطّان فقط:** IBM Plex Sans Arabic (نص) + IBM Plex Mono (أرقام/أكواد بـ `.num`).
4. **RTL أولاً:** خصائص منطقية حصراً (`start/end`, `ms/me`, `ps/pe`, `border-e`) — ممنوع `left/right`.
5. **المال بالهللات (`bigint`)** في المنطق، ويُعرض بالريال في طبقة العرض فقط.
6. **حلقة تركيز إلزامية** (`focus-visible:ring-2 ring-primary/40`) على كل عنصر تفاعلي.
7. **كل شاشة/جدول له ثلاث حالات صريحة:** فارغ · تحميل (Skeleton) · خطأ.

## المصدر الواحد للحقيقة (Source of Truth)

الرموز تُعرَّف مرة واحدة في الكود، وهذا المجلد **يوثّقها ويحكم استخدامها**:

- الألوان + الخطوط + `.num`: `web/src/app/globals.css`
- ربط الرموز بـ Tailwind: `web/tailwind.config.ts`
- الخطوط + الاتجاه: `web/src/app/layout.tsx`
- المزوّدات (ثيم/لغة/تنبيهات): `web/src/components/providers.tsx`
- المكوّنات: `web/src/components/ui/*` و`layout/*` و`data-table.tsx`

أي تغيير رمز يُحرَّر في `globals.css` و`tailwind.config.ts` معاً — ثم يُحدَّث توثيقه هنا.

## نظام الإصدارات

- **v1.0** = ما هو مُنفَّذ فعلاً في الكود اليوم (موثّق كما هو، As-Is).
- **v2.0** = هذا المرجع: يضيف المقاييس والأنظمة والمواصفات الغائبة دون كسر v1.0.
- تغييرات الهوية (لون/خط/فلسفة) تتطلّب إصدار **major** وقرار فريق موثّق هنا.
- الرموز الجديدة (ارتفاع/حركة/z-index) تُقترَح في `foundations/recommended-improvements.md`
  ثم تُرحَّل للكود عند الموافقة.
