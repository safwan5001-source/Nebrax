# مواصفة الرسوم (Charts Specification)

فلسفة نبراس: **الرسم يدعم الرقم، لا يستعرض.** بسيط، دلالي، مصحوب بالقيمة الصريحة.

## الحالة الفعلية (v1.0)
- **بلا مكتبة رسوم** (لا recharts). كلها SVG/CSS يدوية:
  - **Donut** (`components/charts/donut.tsx`): دائري مجوّف بـ SVG، `segments` بألوان CSS.
  - **Bar** (مضمّن في `dashboard/page.tsx`): شريط أفقي بـ `div` وعرض نسبي.
- **لا sparklines** رغم ذكرها في الوثيقة القديمة.

## المبادئ
1. **بلا مكتبة ثقيلة** ما دام SVG/CSS يكفي — يحافظ على خفّة الحزمة والتحكّم بالهوية.
2. **ألوان دلالية فقط:** إيراد/ربح `--positive`، مصروف/خسارة `--negative`، محايد `--primary`,
   خلفية المسار `--border`. لا لوحات ألوان متعدّدة عشوائية.
3. **القيمة الرقمية صريحة دائماً** بجانب الرسم (لا رسم بلا رقم).
4. **بلا زخرفة:** لا تدرّجات، لا ظلال، لا ثلاثي أبعاد، لا حركات دخول.
5. **وصولية:** لا تعتمد على اللون وحده — عنوان/تسمية/قيمة نصّية لكل جزء.

## أنواع مسموحة
| النوع | التنفيذ | الاستخدام |
|---|---|---|
| Donut | SVG (`Donut`) | توزيع/نسب (حالات سداد الفواتير) |
| Bar أفقي | `div` بعرض نسبي | مقارنة قيمتين/فئات قليلة (إيراد مقابل مصروف) |
| Sparkline (مقترح) | SVG `polyline` | اتجاه مصغّر داخل بطاقة KPI |
| Bar عمودي/خطّي (مقترح) | SVG | سلاسل زمنية أطول |

## قاعدة القرار
- فئات ≤ 5 وقيم بسيطة → SVG/CSS يدوي (الافتراضي).
- سلاسل زمنية معقّدة/تفاعل متقدّم مستقبلاً → مكتبة خفيفة تُقيَّم عند الحاجة (قرار موثّق)،
  مع الالتزام بألوان الرموز الدلالية.

## مثال (ألوان دلالية)
```tsx
<Donut segments={[
  { label: 'مسدّدة', value: paid,    color: 'var(--positive)' },
  { label: 'متأخّرة', value: overdue, color: 'var(--warning)' },
  { label: 'غير مسدّدة', value: due,  color: 'var(--border)' },
]} />
```
