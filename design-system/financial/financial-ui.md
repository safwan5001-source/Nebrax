# قواعد الواجهة المالية (Financial UI Rules)

هذا ما يميّز نبراس عن أي لوحة تحكّم عامة. **الأرقام المالية تُعامَل بقدسية.**

## 1. المال بالهللات (Minor Units)

- المنطق والتخزين والـ API: **`bigint` بالهللات** (100.50 ﷼ = 10050). ممنوع `float` في أي حساب.
- طبقة العرض فقط تحوّل: `formatRiyal` (هللات/ريال نصّي → «1,150.00 ﷼»).
- مدخلات المستخدم: `riyalToMinor` (ريال → هللات) — يرفض المشوّه بـ NaN (لا يحوّله 0 صمتاً).
- المصدر: `web/src/lib/money.ts`.

## 2. تنسيق العرض

| القاعدة | التفصيل |
|---|---|
| الخط | `.num` (IBM Plex Mono + `tabular-nums`) |
| المحاذاة | **يمين** دائماً (`text-end`) في الجداول والملخّصات |
| الفواصل | فواصل آلاف + **فاصلتان عشريتان** (`1,150.00`) |
| العملة | `﷼` (أو «ر.س») بعد الرقم |
| السالب | **أحمر `text-negative` + إشارة `-`** (لا لون وحده) |
| الصفر | يُعرَض `0.00` لا فارغاً (وضوح) |
| القيمة الشاذّة | `formatRiyal(NaN)` → «—» لا «NaN ﷼» |

## 3. الدلالة اللونية المالية

- **دائن/ربح/موجب** → `positive` (أخضر) + سياق.
- **مدين/خسارة/سالب** → `negative` (أحمر) + إشارة.
- **متأخّر/مستحق** → `warning` (برتقالي) + أيقونة.
- دائماً **لون + إشارة/نص** — لعمى الألوان.

## 4. حالات المستندات (Badge)

مسودة (`muted`) · مرحّلة (`positive`) · مسدّدة (`positive`) · جزئي (`warning`) ·
متأخّرة (`warning`) · ملغاة (`negative`). الحالة نصّ + لون، لا لون وحده.

## 5. سلامة الأرقام (ثقة)

1. **الإجماليات مشتقّة** من السطور، لا يكتبها المستخدم — تُعرَض للقراءة.
2. **لا تحريك للأرقام** (تظهر فوراً ثابتة). الحركة تُضعف الثقة في رقم مالي.
3. **دقّة ثابتة:** فاصلتان دائماً، حتى للأصفار.
4. **المستند المرحّل للقراءة فقط**؛ التصحيح بقيد عكسي (لا تعديل مباشر).

## 6. الرسوم المالية

انظر `financial/charts.md`. القاعدة: الرسوم تدعم الأرقام لا تحلّ محلّها؛ ألوانها دلالية
(`positive`/`negative`)، بسيطة، بلا زخرفة، ومصحوبة دائماً بالقيمة الرقمية الصريحة.

## أمثلة

```tsx
<TD className="num text-end">{formatRiyal(inv.total)}</TD>
<span className="num text-negative">-1,150.00 ﷼</span>
<Badge tone={inv.status === 'posted' ? 'positive' : 'muted'}>{label}</Badge>
```
