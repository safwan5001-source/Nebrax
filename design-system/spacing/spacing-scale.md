# التباعد — التطبيق (Spacing · Applied Rhythm)

> المقياس في `tokens/spacing.md`. هنا **الإيقاع** وقواعد الكثافة.

## الإيقاع القياسي (Vertical Rhythm)

- **بين الأقسام الكبيرة في الصفحة:** `space-y-5` أو `space-y-6`.
- **بين حقول النموذج:** `space-y-3` (كثيف) أو `space-y-4`.
- **داخل مجموعة عناصر متجاورة:** `gap-2`/`gap-3`.
- **بين البطاقات في شبكة:** `gap-4`/`gap-5`.

## الحشو القياسي (Padding) — لكل حاوية

| الحاوية | الحشو |
|---|---|
| منطقة المحتوى الرئيسية (`main`) | `p-4 sm:p-6` |
| بطاقة | رأس `p-4 pb-2` · محتوى `p-4 pt-2` |
| خلية جدول | `px-3 py-2` |
| حوار | رأس `px-4 py-3` · جسم `p-4` |
| شارة | `px-2 py-0.5` |
| زر | `px-3` (sm) / `px-4` (md) |
| حقل إدخال | `px-3` (ارتفاع `h-9`) |

## قواعد الكثافة (Density Rules)

1. **الكثافة قيمة.** فضّل الفجوات الأصغر داخل المكوّنات (`gap-2/3`) والأكبر بينها (`gap-4/5`).
2. **تسلسل لا توحيد.** الفجوة بين المجموعات > الفجوة داخلها (يخلق بنية بصرية مقروءة).
3. **درجات المقياس فقط.** لا `mt-[7px]`. إن لم تجد الدرجة المناسبة، أعد التفكير في البنية.
4. **صفوف الجداول مضغوطة:** `py-2` — تُظهر أكبر عدد صفوف دون ازدحام.
5. **لا فراغ زائد.** الفراغ الأبيض المفرط علامة «تصميم تسويقي»، لا أداة عمل.

## مثال (شاشة قائمة)

```tsx
<div className="space-y-5">                        {/* إيقاع الصفحة */}
  <div className="flex items-center justify-between">{/* رأس */}
    <h1 className="text-xl font-semibold">العملاء</h1>
    <Button>إضافة</Button>
  </div>
  <DataTable … />                                   {/* الجدول */}
</div>
```
