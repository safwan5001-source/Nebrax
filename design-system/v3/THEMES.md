# عقد السمات (Themes) — v3.0-draft

> `[APPROVED]` Default = Tinted Neutral · `[APPROVED]` الثيم الاختياري = **AWJ Ink** (قشرة داكنة / مساحة عمل فاتحة) ·
> `[REJECTED]` Exploration C (شريط علوي حبري + جانبي مصبوغ) خارج الاتجاه المعتمد.

## 1. المبدأ

**السمة = نبرة القشرة، لا أكثر.** السمة تُغيّر مظهر الشريط الجانبي والعلوي (وما يتبعهما: حقل البحث، حالة العنصر النشط، علامة المؤسسة).
مساحة العمل (Desk/Paper)، المكوّنات، التخطيط، دلالات الحالات، منطق التفاعل، سطح النتيجة — **كلها نواة واحدة**.

AWJ Ink **ليس Fork**. هو مجموعة قيم لـ13 توكناً فقط فوق نفس النظام ([`TOKEN_REFERENCE.md`](./TOKEN_REFERENCE.md) §4).
أي فرق بنيوي (ترتيب، حجم، مكوّن إضافي) بين السمتين **عيب** يُصلَح.

## 2. السمتان

| | **AWJ Default** | **AWJ Ink** |
|---|---|---|
| الاسم الداخلي | `default` | `ink` |
| القشرة | حياد مصبوغ (`#D5DFF0`) | حبر كحلي (`#0E1A31`) |
| العنصر النشط | لوح أبيض مرفوع + Apex `#1E40AF` | لوح `#1A2A4A` + إطار داخلي + Apex `#7FA8FF` |
| الشعور | هادئ، طويل الجلسة، يقرّب القشرة من الورق | أقوى هوية وتباين، بيانات أسطع |
| الافتراضي؟ | **نعم** | اختيار |
| المخاطرة | فاصل القشرة↔Desk ضعيف (1.09:1) يُراقَب | ثقل بصري/إجهاد جلسة طويلة غير مُختبَر `[EXPERIMENTAL]` |

سطح النتيجة (`surface-outcome`) **حبري في السمتين** ويعمل كمفتاح نغمي: في Default هو النقطة الداكنة الوحيدة في الصفحة، وفي Ink يتناغم مع القشرة. ([`SIGNATURE_LANGUAGE.md`](./SIGNATURE_LANGUAGE.md) §2)

## 3. ما يجوز للسمة تغييره

**13 توكناً فقط** (القائمة مغلقة): `shell-bg`, `shell-fg`, `shell-fg-muted`, `shell-line`, `shell-hover`, `shell-active-bg`,
`shell-active-fg`, `shell-active-shadow`, `shell-apex`, `shell-field-bg`, `shell-field-line`, `shell-focus-ring`, `shell-brandmark-bg`.

وتُغيَّر **قيمها**، لا أدوارها ولا أسماؤها.

## 4. ما لا يجوز للسمة تغييره (Forbidden)

| الممنوع | السبب |
|---|---|
| ألوان الدلالة المالية (`status-*`) | الأحمر خطر والأخضر نجاح في كل مكان. تغييرها يكسر ثقة المحاسب |
| Desk / Paper / Band / Sunken / الحدود / النصوص | مساحة العمل نواة مشتركة؛ بيانات المستخدم تُقرأ دائماً على السطح نفسه |
| `surface-outcome` | معناه «النتيجة النهائية» ثابت عبر السمات |
| `action-primary*` (الزر الأساسي، الروابط) | الفعل المقصود يجب أن يُعرف فوراً؛ لا لون زر مختلف لكل مستخدم |
| عقد التركيز (السماكة، الإزاحة، الحد الأدنى للتباين) | عقد وصولية |
| التباعد، الزوايا، الكثافة، الطباعة، الحركة | Postures وحدها تتحكم (لا السمات) |
| حجم/ترتيب/وجود أي مكوّن، أو نص | السمة لا تُغيّر التخطيط |
| معاني الأيقونات والحالات | |
| ما يخصّ الـPosture (لمس، وسائط، كثافة) | |

## 5. ما يتشاركانه حتماً

نفس المكوّنات والتخطيط · نفس **الدلالات المحاسبية** (مدين/دائن، مرحّل/مسوّدة، إلخ) · نفس معاني الحالات · نفس عقد التركيز · نفس منطق التفاعل
(hover/selected/editing) · نفس لغة الأرقام · نفس نصوص الواجهة · نفس اختبارات الوصولية (مصفوفة 2 سمة × الأوضاع).

## 6. السمة ≠ الوضع (Ink ≠ Dark Mode)

**تصحيح للمفهوم القائم:** الوضع الداكن **موجود اليوم** (`.dark` في `globals.css`، `next-themes` بـ`attribute="class"` و`defaultTheme="system"`، زر `theme-toggle`).
فالسؤال ليس «هل نبنيه» بل **كيف تتفاعل السمتان معه**.

| | **Theme** (Default / Ink) | **Mode** (Light / Dark) |
|---|---|---|
| ما يتغيّر | نبرة القشرة (13 توكناً) | **كل** الأسطح والنصوص والحدود والحالات |
| مساحة العمل | فاتحة دائماً | تتبع الوضع |
| ملكية الاختيار | تفضيل المستخدم (+ افتراضي المنشأة `[OPEN]`) | تفضيل المستخدم/النظام |
| الآلية المقترحة | سمة على الجذر `data-awj-theme="default\|ink"` | `class="dark"` (القائم، next-themes) |
| يُخزَّن | ملف المستخدم + `localStorage` كاحتياط | `next-themes` القائم |

**محورا تحكّم مستقلان — لا دمج في محوّل واحد.** (دمجهما في `next-themes` كقيم `ink`/`dark` سيجعل Ink والداكن يتنافسان.)

### مصفوفة Theme × Mode

| | Light | Dark |
|---|---|---|
| **Default** | مُواصَف هنا | Dark v3 (الشريحة 10): كل الأسطح الدلالية داكنة؛ القشرة نغمة حبرية أدكن من Desk |
| **Ink** | مُواصَف هنا | **= Default-Dark** `[DECIDED D-12]` |

**لماذا Ink-Dark = Default-Dark:** ما يميّز Ink هو **التباين بين قشرة داكنة ومساحة عمل فاتحة**. في الوضع الداكن هذا التباين غير موجود، فتصير السمتان بلا فرق حقيقي. إتاحتهما معاً تضاعف الاختبار (4 تركيبات × RTL/LTR × Posture) بلا قيمة. عند اختيار Dark يُعطَّل محدّد السمة (أو يُتجاهل) ويُوضَّح ذلك للمستخدم.

### متطلبات Dark v3 (معمارية فقط، لا تنفيذ)

1. الأسطح بالتدرّج النغمي (الارتفاع بالفاتحية لا بالظل): desk < paper < raised < float.
2. أزواج الدلالة: القيم الداكنة القائمة (`#16A34A`، `#F87171`، `#D97706`) **تجتاز** على `#181B20` اليوم (5.24 · 6.24 · 5.42)، لكنها تُعاد مراجعة على أسطح v3 الداكنة (bg/border/تراكب) قبل الاعتماد.
3. `surface-outcome` يبقى حبرياً لكن يُفصَل عن Desk الداكن بإطار `ink-600` وخط `brand-300`.
4. `action-primary` يستعمل `brand-500` (القائم `#4F8CFF`) أو الأفتح بحسب التباين.
5. الصور تُخفَّض سطوعاً قليلاً؛ الظلال تُلغى لصالح فروق السطح.
6. مصفوفة تباين خاصة بالداكن تُضاف إلى `TOKEN_REFERENCE.md` قبل أول سطر CSS.

## 7. الحماية: التباين والوصولية

1. **كل سمة تجتاز مصفوفة التباين** قبل القبول (§12 في [`TOKEN_REFERENCE.md`](./TOKEN_REFERENCE.md)): نص القشرة ≥ 4.5، Apex/تركيز/حقول ≥ 3.0.
2. **تحقق آلي:** اختبار وحدة يقرأ مصدر التوكنز ويحسب نسب كل زوج مسجَّل؛ فشله يمنع الدمج ([`GOVERNANCE.md`](./GOVERNANCE.md) §4).
3. **`prefers-contrast: more`** يرفع كل السمات: `shell-line` ← أقوى، `shell-fg-muted` ← `shell-fg`، ويُلغى `shell-cast`.
4. **`forced-colors`:** Apex والحدود التي تعتمد `background` تُكمَّل بـ`border`/`outline` بألوان النظام.
5. **شعار المؤسسة على Ink:** الشعار الداكن يختفي على الحبر؛ لذلك يُرسَم دائماً داخل **لوحة شعار** (`brandmark plate`: `surface-paper`، `radius.control`، حشوة 2px) في كلتا السمتين، فلا يتبدّل ظهوره بالسمة. ([`TENANT_BRANDING.md`](./TENANT_BRANDING.md))

## 8. التطبيق المقترح (للشريحة 7، دون تنفيذ الآن)

```
<html class="dark?" data-awj-theme="default|ink" data-awj-ui="3">
```

- `data-awj-ui="3"` **بوابة التفعيل** لكل v3 (الشريحة 2 فصاعداً): حذف الخاصية = رجوع كامل لما كان. ([`MIGRATION.md`](./MIGRATION.md))
- القيم تُعرَّف كمتغيرات CSS تحت `[data-awj-theme="ink"]` فوق قيم Default؛ لا CSS مكوّنات مخصّص لـInk.
- قراءة التفضيل **قبل الرسم** (سكربت مضمَّن صغير أو cookie) لتفادي وميض السمة.
- اختيار السمة لا يغيّر مسارات ولا صلاحيات ولا بيانات.

## 9. سمات إضافية (مستقبلاً)

سقف v3 **سمتان**. أي سمة جديدة (شريك، White-label، تباين مرتفع) تمرّ بالعملية في [`GOVERNANCE.md`](./GOVERNANCE.md) §6:
قيم للتوكنز الـ13، مصفوفة تباين ناجحة، لقطات بصرية لـ3 شاشات مرجعية، واعتماد مالك. لا سمة تُضيف توكناً خارج الـ13.

## 10. ما تفعله السمات مع الـPostures

| Posture | تأثير السمة |
|---|---|
| **Ledger** | كامل: الشريط الجانبي + العلوي بحسب السمة |
| **Floor (POS)** | القشرة مصغّرة (بلا قائمة جانبية). السمة تؤثر على الشريط العلوي فقط؛ لوحة السلة/الدفع **سطح نتيجة حبري** في السمتين. هل Ink أنسب لـFloor؟ `[OPEN]` — يُقرَّر باختبار مع كاشير (إضاءة، وهج) |
| **Studio** | **لا تتأثر**: أدوات الاستوديو بـ`awj-editor-*` graphite محايدة ثابتة كي لا يتلوّن إدراك ألوان التاجر |
| **Storefront** | **لا تتأثر** (نظام آخر — [`STOREFRONT_BOUNDARY.md`](./STOREFRONT_BOUNDARY.md)) |
