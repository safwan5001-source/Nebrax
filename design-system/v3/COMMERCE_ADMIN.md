# إدارة التجارة (Commerce Admin) — v3.0-draft

> **Commerce Admin جزء من نظام AWJ Admin.** وضعه **Ledger** بأنماط غنية بالوسائط. لا يتحوّل إلى تطبيق استهلاكي.
> **طاقته تأتي من المحتوى** (صور المنتجات، معاينات المتجر، حالات النشر، بطاقات القنوات، المحتوى التسويقي) **لا من ألوان أكثر.**

## 1. الواقع المُتحقَّق منه

| الجانب | ما هو موجود (`web/src`) |
|---|---|
| المسارات | `(commerce)/commerce`: الرئيسية، `stores`، `published-products`، `themes`، `appearance` (Studio)، `domains`، `delivery`، `integrations`؛ و`(commerce)/app-builder` |
| القشرة | `CommerceWorkspaceShell`: رأس أبيض 56px + محدّد متجر + قائمة `CommerceWorkspaceNav` (مجموعات: نظرة عامة · المتجر · القنوات). **تنسخ شكل رأس الـERP** |
| الثيمات | `THEME_REGISTRY`: `awj-modern` · `awj-market` (متاحتان) · `boutique-floral-01` (مخطَّطة)؛ فئات `general/retail/floral`؛ `official` |
| الإصدارات | `PresentationVersionState`: `draft` · `scheduled` · `published` |
| النطاقات | `verification_status`: `pending` · `verified` · `failed` |
| المتاجر | `CommerceStoreOption`، لغات، `viewStoreUrl` |
| المعاينة | `StorefrontPreviewCanvas`، إطار جهاز، معاينة على الهاتف |

**الخلاصة:** القشرة التجارية اليوم «ERP بمحدّد متجر». وهذا **صحيح معمارياً** (ليست تطبيقاً آخر)، لكنها تفتقر إلى **المحتوى الغني** وتتجاهل لغة v3 (سمة، Apex، سُلَّم أسطح). المطلوب: تبنّي النواة + إضافة أنماط محتوى، لا إضافة ألوان.

## 2. المبادئ

1. **نفس النواة:** سمة المستخدم نفسها، الأسطح، الحالات، التركيز، الأرقام، RTL. `data-posture="ledger"`.
2. **الطاقة من المحتوى** (انظر §3). الصور والمعاينات هي «اللون» في الصفحة.
3. **قشرة Commerce = قشرة Ledger + سياق المتجر** (شريحة محدّد المتجر بصورته واسمه). لا قشرة بصرية مختلفة.
4. **لا KPI-wall.** لا صفّ بطاقات مؤشرات يتصدّر كل صفحة (قاعدة V2: القائمة/الشبكة هي البطل).
5. **نصّ أولاً:** الصورة تُرافق الاسم ولا تحلّ محلّه.
6. **حالات النشر لها لغة موحّدة** مع حالات المحاسبة (نفس المعاني، لا ألوان جديدة).

## 3. مصادر الطاقة المسموحة

| المصدر | كيف |
|---|---|
| **وسائط المنتج** | صور مصغّرة في القوائم، معارض سريعة، بلاطات في المنتقيات |
| **معاينات المتجر** | إطار جهاز بمعاينة حيّة/لقطة، بحالة النشر |
| **حالات النشر** | glyph + نص بحسب لغة الحالات؛ شريط «ما يحتاج انتباهك» |
| **بطاقات القنوات** | بطاقة لكل قناة بشارة وحدة + حالة + 1–2 أرقام + فعل |
| **محتوى التسويق/الـMerchandising** | معاينة الأقسام والصور الرئيسية داخل Studio وبطاقات الثيمات |
| **حركة البيانات** | مخطط مبيعات واحد رئيسي (لا شبكة مخططات) |

**ما لا يُعدّ طاقة:** تدرّجات، خلفيات ملوّنة للقشرة، أيقونات ضخمة ملوّنة، رسوم توضيحية زخرفية في الـchrome.

## 4. شارات الوحدات (Module Marks)

**كائن لا زينة:** لوح مربّع يعرّف **كياناً قابلاً للاختيار** (تطبيق، قناة، ثيم) بصرياً دون قراءة.

### أين تُسمح
1. كتالوج التطبيقات (`/applications`).
2. بطاقات القنوات (متجر، نطاق، تطبيق جوال، POS…).
3. معرض الثيمات (`/commerce/themes`).
4. لوحة عناصر App Builder.
5. تهيئة المنصة/المستأجر (onboarding).

### أين لا تُسمح
التنقّل (الشريط الجانبي)، بطاقات KPI، الجداول، الأزرار، التنبيهات، رؤوس الصفحات. **لا «أيقونة في صندوق ملوّن» في أي موضع آخر.** (تُحدَّث قاعدة v2.0: [`RULES_DELTA.md`](./RULES_DELTA.md).)

### الهندسة
| العنصر | القيمة |
|---|---|
| الحجم | 32×32 (صغير 24، كبير 48) |
| الزاوية | `radius.control` (6) للـ24؛ `radius.surface` (8) للـ32/48 |
| الخلفية | تدرّج لوني واحد **فاتح** (tint) من اللون |
| الأيقونة | Lucide خطّية 18px (24px للكبير) بلون **الدرجة الداكنة** من اللون |
| **ممنوع** | تعبئة مشبعة، تدرّج، ظل، حدّ ملوّن، أكثر من أيقونة |

### لوحة ألوان الوحدات (6 — مستثناة عمداً من ألوان الدلالة)
لا تتضمن الأخضر/الأحمر/الكهرماني لأن هذه **دلالة مالية**؛ فلا يُلتبس شارة وحدة بحالة.

| اللون | أيقونة | خلفية | تباين الأيقونة/الخلفية |
|---|---|---|---|
| Blue | `#1E40AF` | `#EAF0FE` | 7.64 |
| Teal | `#0F766E` | `#E4F3F0` | 4.79 |
| Violet | `#6D28D9` | `#F0EAFD` | 6.05 |
| Cyan | `#0E7490` | `#E3F4F8` | 4.74 |
| Fuchsia | `#A21CAF` | `#F8E8FA` | 5.39 |
| Slate | `#334155` | `#ECEFF3` | 8.98 |

- كل وحدة تُسنَد **لوناً ثابتاً** (سجل ثابت)، لا يختاره المستخدم ولا يتغيّر بالسمة.
- اللوحة `[EXPERIMENTAL]` — تحتاج موافقة بصرية (الألوان نفسها اقتراح؛ الإلزام هو القواعد).

## 5. أنماط المحتوى

### 5.1 الرئيسية التجارية
- **شريط حالة المتاجر والقنوات** (بطاقات قنوات مضغوطة) + **«ما يحتاج انتباهك»** (قائمة: نطاق فاشل، إصدار مجدول، منتجات غير منشورة…) + **مخطط مبيعات واحد** اختياري.
- بلا صف مؤشرات رباعي. بلا تدرّجات.

### 5.2 قائمة المنتجات (والمنتجات المنشورة)
- عمود وسائط **40px** (compact 32)، **ارتفاع صف 56** (compact 48) — ارتفاع `grid-row-media`.
- **fallback**: بلاطة نصّية بأول حرف على `surface-sunken` (لا أيقونة صورة مكسورة).
- نسبة ثابتة 1:1 مع `object-fit: cover`؛ **حجز المساحة** قبل التحميل (لا CLS)؛ تحميل كسول؛ `alt` = اسم المنتج **إلا** إن كان الاسم ظاهراً بجواره (يُترك فارغاً).
- مؤشر **حالة النشر/المزامنة** كـglyph + نص في السطر الثانوي.
- مفتاح معاينة سريعة يفتح لوحة بمعرض الصور (لا تنقّل).

### 5.3 الفئات
بلاطة فئة 24–32 (صورة أو لون مُشتق من `category-accent.ts` القائم) بجانب الاسم؛ **لا** أكثر من لون ثانٍ للفئة. نص دائماً.

### 5.4 بطاقات القنوات
```
┌────────────────────────────────┐
│ [Module Mark]  اسم القناة   ● حالة │
│ رقم رئيسي · رقم ثانوي            │
│ [فعل]                            │
└────────────────────────────────┘
```
- ≤ 6 ظاهرة؛ حالة القناة: **متصلة (done) · قيد التحقق (progress) · فاشلة (danger) · غير مفعَّلة (neutral)**. مثال متحقَّق: `verification_status` للنطاق `pending/verified/failed`.
- بطاقة واحدة = قناة واحدة، **ليست مؤشراً**.

### 5.5 إطار معاينة المتجر
- إطار جهاز (`device-frame`)، ارتفاع `elevation-3`، `radius.canvas`.
- شارة الحالة بجانبه: **مسودة (neutral) · مجدولة (info) · منشورة (positive)** (من `PresentationVersionState`) + وقت الجدولة (المنطقة الزمنية للمنشأة).
- أفعال: «فتح الاستوديو»، «عرض المتجر» (`viewStoreUrl`).

### 5.6 معرض الثيمات
- بطاقة: **معاينة الثيم** (محتوى تاجر نموذجي بـ`--store-*` معزول) + اسم + شارة «رسمي» + فئة + حالة `متاح/قريباً`.
- «قريباً» غير قابل للاختيار (يطابق `THEME_REGISTRY`: لا `presetId` لمخطَّط).
- محيط البطاقة Admin (نواة)، ومحتواها المعاين Showcase (نظام آخر).

## 6. لغة الحالات في Commerce

| الحالة | المعنى | المرجع |
|---|---|---|
| مسودة | neutral | `draft` |
| مجدول | info | `scheduled` |
| منشور / متصل / متحقَّق | done | `published` / `verified` |
| قيد التحقق | progress | `pending` |
| فشل | danger | `failed` |
| يحتاج انتباهاً | attention | (مشتق) |

نفس الألوان والأشكال المستعملة في المحاسبة ([`SIGNATURE_LANGUAGE.md`](./SIGNATURE_LANGUAGE.md) §6): **لا لون ثانٍ للنشر**.

## 7. الصور الغنية — قواعد

| القاعدة | |
|---|---|
| مسموحة في | المنتجات، الفئات، معاينات المتجر، الثيمات، منتقيات المنتج |
| ممنوعة في | رؤوس الصفحات، القشرة، الحالات الفارغة (لا صور ستوك زخرفية)، الخلفيات |
| تدرّج على الصورة | **scrim وظيفي فقط** لقراءة نص فوق صورة (مستثنى من «لا تدرّجات») |
| الأداء | أحجام متعددة (`srcset`)، تحميل كسول، حجز المساحة |
| الوصولية | `alt` أو فراغ مقصود؛ لا نص داخل صورة ينقل معلومة حرجة |
| الداكن | تخفيض سطوع طفيف (≈ 90%) |
| الجودة | تحقّق دقة (موجود نظير في `pos/company-logo-quality`) |

## 8. ما يبقى نواة لا يتغيّر

الأسطح، الحدود، التركيز، الأرقام (أسعار/مبيعات بـAWJ numerals)، الحالات، الأزرار، الجداول، الوصولية، RTL. **Commerce لا يملك زراً أولياً بلون آخر ولا سمة خاصة.**
