## 1. مصدر الحقيقة (Source of Truth) — القرار `[DECIDED D-02]`

### الخيارات

| الخيار | التقييم |
|---|---|
| **A** `DESIGN_SYSTEM.md` يبقى المصدر | ❌ انجرف بالفعل عن `globals.css` (§2)؛ مستند نصّي لا يُحرَس بآلة |
| **A′** (القائم في `design-system/README.md`) الكود `globals.css` هو المصدر والوثائق «توثّقه» | ◑ صحيح كمبدأ لكنه **غير محروس**: الوثائق تكرّر القيم فانجرفت، والكود بلا مخطط ولا اختبار تباين، ولا يخدم حزمة `storefront/` |

### التفصيل

```
design-system/tokens/awj.tokens.json        ← المصدر الوحيد للقيم (صيغة DTCG-subset)
        │  (مولّد: Node بلا تبعيات إضافية)
        ├──► web/src/styles/tokens.generated.css      (يُستورد في globals.css: :root / [data-awj-theme] / .dark)
        ├──► web/src/design/tokens.generated.ts       (أسماء مُنمَّطة + سجل أزواج التباين للاختبارات)
        ├──► design-system/v3/generated/TOKENS.md      (الجداول المرجعية)
        └──► storefront `.awj-editor` (إصدار Tailwind 4 `@theme`) ← للشريحة 9
```

**لماذا JSON وليس TS كمصدر:** (1) لغة محايدة تقرؤها حزمتان منفصلتان (`web/` Tailwind 3، `storefront/` Tailwind 4) وأدوات التحقق؛ (2) قابلة لفحص المخطط (schema) وCI؛ (3) محاذية لصيغة DTCG فتبقى قابلة للتبنّي بأدوات مستقبلاً؛ (4) تتفادى ربط المصدر ببناء Next. تُولَّد غلافات TS.

**ما يبقى نصاً يدوياً:** القواعد والأنماط والأسباب (هذا المجلد). **يُمنع تكرار قيمة رقمية/hex** في أي وثيقة نصية؛ تُشير إلى المولَّد.

**من يملك:** مجلس التصميم (Design Systems Lead + مراجع وصولية). `CODEOWNERS` (غير موجود اليوم) للمسارات: `design-system/**`، `web/src/app/globals.css`، `web/tailwind.config.ts`، `web/src/styles/tokens.generated.css`.

**المرحلة الانتقالية (قبل وجود المولِّد):** الكود (`globals.css`) هو **الواقع**، وهذه الوثائق **المواصفة**؛ الاختلاف مسموح لأنه خطة، **لكنه معلن** في §2 وفي [`TOKEN_REFERENCE.md`](./TOKEN_REFERENCE.md).

## 3. المراجعة والعمليات

### 3.1 توكن دلالي جديد
نموذج طلب (RFC قصير) يتضمّن: الاسم والدور؛ ≥ استعمالان حقيقيان؛ القيم لكل سمة/وضع؛ **إثبات التباين**؛ خطة Aliases؛ أثر على الوثائق المولَّدة؛ موافقة مجلس التصميم. **لا قيمة تُضاف في `globals.css` مباشرة.**

### 3.2 تجاوز سمة (Theme override)
مسموح فقط لـ13 توكناً ([`THEMES.md`](./THEMES.md) §3). سمة جديدة تحتاج: قيم، مصفوفة تباين، 3 لقطات مرجعية، موافقة المالك. سقف v3 سمتان.

### 3.3 تجاوز Posture
مفتاح من العشرة فقط ([`WORKSPACE_POSTURES.md`](./WORKSPACE_POSTURES.md) §4). غيره = **سجل استثناء**.

### 3.4 سجل الاستثناء (Design Exception Record)
مبنيّ على قالب قصير: السياق · لماذا النواة لا تكفي · البديل المرفوض · النطاق · **تاريخ انتهاء/مراجعة** · موافق. يُحفَظ في `design-system/v3/exceptions/`. بلا تاريخ انتهاء لا يُقبَل.

### 3.5 الإهمال (Deprecation)
Alias جديد ← تحذير lint ← إزالة بعد دورة إصدارين موثَّقتين. لا إزالة صامتة.

### 3.6 الإصدارات
`tokens.version` (semver) + `CHANGELOG`: تغيير قيمة = minor؛ حذف/إعادة تسمية = major.

## 5. قائمة مراجعة PR الواجهة

> لا يوجد قالب PR في المستودع اليوم (`.github/` يحوي `workflows` فقط). يُقترح إضافة قالب بهذه البنود.

- [ ] لا hex/rgb/`rounded-[..]`/`shadow-[..]`/`text-[<12px]` جديد.
- [ ] كل لون/ظل/زاوية عبر توكن دلالي. لا قراءة Primitive.
- [ ] الدلالة المالية: لون + إشارة/نص، ولا تغيير لمعنى حالة.
- [ ] RTL وLTR: خصائص منطقية؛ أيقونات اتجاهية؛ أرقام معزولة.
- [ ] السمتان Default وInk (لقطات).
- [ ] 1280×720 و200% تكبير.
- [ ] لوحة المفاتيح: ترتيب Tab، حلقة التركيز، لا حجب بالأشرطة اللاصقة.
- [ ] الحالات: فارغ/تحميل/خطأ/للقراءة فقط/صلاحية.
- [ ] لا تغيير لناتج رقمي أو محاسبي أو API.
- [ ] نمط من هذا المجلد مُستعمل أو استثناء مسجَّل.
- [ ] Storefront/Studio: لا تسرّب بين `--awj-*` و`--store-*`.
