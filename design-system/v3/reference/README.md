`?solo=1&v=base|b|a|c&size=1440×900|1366×768|1280×720&tab=items|post`

## ما يجب الانتباه إليه

1. **البيانات خيالية بالكامل** (عميل، رقم ضريبي، أصناف). لا بيانات مستأجر.
2. **ليست كوداً إنتاجياً** ولا تُنسَخ: لا RTL منطقي كامل، لا ARIA كامل، لا حالات خطأ/تحميل.
3. **انحرافات معروفة عن المواصفة** (موثَّقة في [`../DECISIONS.md`](../DECISIONS.md) §4): مسار «صادرة»، حفظ تلقائي، زر منقسم + `Ctrl+↵`، `F2` لإضافة بند، زاوية 10px، حقول هادئة افتراضية، مقياس ائتمان محسوب محلياً، تحذير مخزون، قيد المسودة المحسوب، رمز الريال بـSVG تقريبي.
4. **Baseline** تقريب من قراءة `invoice-form.tsx` و`sidebar.tsx` و`globals.css`، **ليس لقطة من التطبيق الحيّ**.
5. **القيد المعروض** (بما فيه تكلفة البضاعة 72% افتراضاً) **ليس منطقاً محاسبياً**؛ مفهوم بصري فقط. ([`../POSTING_PREVIEW.md`](../POSTING_PREVIEW.md))
