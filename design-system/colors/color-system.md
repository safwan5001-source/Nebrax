# نظام الألوان — التطبيق (Color System · Usage)

> رموز الألوان في `tokens/color.md`. هذا الملف يحكم **كيف تُستخدَم** في الشاشات.

## خريطة الاستخدام (ماذا يلوَّن بماذا)

| العنصر | اللون |
|---|---|
| خلفية الصفحة | `bg-background` |
| بطاقة/جدول/حوار/شريط | `bg-surface` |
| نص أساسي / عنوان | `text-text` |
| تسمية / نص ثانوي / تلميح | `text-muted` |
| حدود وفواصل | `border-border` |
| زر أساسي، رابط، أيقونة نشطة، مؤشر نشط | `bg-primary` / `text-primary` |
| خلفية العنصر النشط في الشريط، تحويم خفيف | `bg-primary-soft` |
| حلقة تركيز | `ring-primary/40` |
| رقم/حالة دائنة أو موجبة | `text-positive` (+ إشارة) |
| رقم/حالة مدينة أو سالبة | `text-negative` (+ إشارة) |
| حالة متأخّرة/تنبيه | `text-warning` (+ أيقونة) |

## قواعد صارمة

1. **لون هوية واحد.** لا تُدخِل أزرق ثانياً أو لوناً «مرحاً». التفاعل كله `primary`.
2. **الدلالة مالية فقط.** `positive/negative/warning` للأرقام والحالات — لا لتلوين أزرار
   أو أيقونات زخرفية. ودائماً **لون + إشارة** (لعمى الألوان).
3. **الخلفيات الدلالية شفّافة:** `bg-positive/10`, `bg-warning/10`, `bg-negative/10` (شارات/تنبيهات).
4. **لا نص على لون بلا تباين.** كل نص فوق لون يجتاز AA (4.5:1).
5. **لا hex خام.** الرمز عبر Tailwind فقط.

## الوضع الداكن (Dark Mode)

- يُدار بـ next-themes (`attribute="class"`, `defaultTheme="light"`, `enableSystem={false}`).
- التبديل **يدوي** عبر `ThemeToggle` (لا اتّباع للنظام حالياً — قرار قائم).
- الرموز تتبدّل تلقائياً في `.dark`؛ **لا تكتب ألواناً خاصة بالوضع الداكن في المكوّنات** —
  إن احتجت، أضف الفرق في `.dark` داخل `globals.css`.
- الأزرق العميق `#1e40af` → `#4f8cff` (مقروء على داكن). الدلالية ثابتة عبر الوضعين.

## أمثلة صح/خطأ

```tsx
// ✅ صح
<button className="bg-primary text-white hover:bg-primary-hover">حفظ</button>
<span className="num text-negative">-1,150.00 ﷼</span>   // + الإشارة "-"
<Badge tone="positive">مسدّدة</Badge>

// ❌ خطأ
<button className="bg-blue-600">حفظ</button>              // لون Tailwind خام
<span className="text-red-500">1150</span>               // hex/لون خام + بلا إشارة
<div className="bg-gradient-to-r from-blue-500">…</div>   // تدرّج ممنوع
```
