# رموز التباعد (Spacing Tokens)

نبراس يعتمد **مقياس Tailwind ذا القاعدة 4px** (مُستخدَم فعلاً في v1.0). هذا الملف يوثّقه
كمقياس رسمي ويحدّد أين يُطبَّق كل مستوى — دون إدخال قيم خارج المقياس.

## المقياس (القاعدة = 4px)

| Tailwind | px | الاستخدام النموذجي |
|---|---|---|
| `0.5` | 2px | فواصل دقيقة، حدّ المؤشر النشط |
| `1` | 4px | فجوات أيقونة/نص صغيرة |
| `1.5` | 6px | حشو شارة رأسي، فجوات دقيقة |
| `2` | 8px | فجوة عناصر متجاورة صغيرة |
| `2.5` | 10px | حشو أفقي للشارات/الحقول الصغيرة |
| `3` | 12px | **حشو خلية الجدول** (`px-3`)، فجوة نموذج |
| `4` | 16px | **حشو البطاقة** (`p-4`)، فجوة أقسام، حشو المحتوى (جوال) |
| `5` | 20px | فجوة بين البطاقات، حشو بطاقة مصادقة |
| `6` | 24px | **حشو المحتوى (ديسكتوب)** (`sm:p-6`)، فجوة أقسام كبيرة |
| `8` | 32px | فراغ عمودي بين مجموعات، هوامش بطاقة مصادقة |
| `10`/`12` | 40/48px | فراغات شاشات المصادقة/الحالات الفارغة |

## قواعد التطبيق (Application Rules)

1. **درجات زوجية فقط** من المقياس أعلاه. لا `p-[13px]` ولا قيم عشوائية.
2. **إيقاع رأسي متّسق:** استخدم `space-y-*` بين عناصر النموذج (`space-y-3`/`space-y-4`)
   و`gap-*` في الشبكات (`gap-4`/`gap-5`).
3. **حشو قياسي حسب الحاوية:**
   - خلية جدول: `px-3 py-2`.
   - بطاقة: رأس `p-4 pb-2`، محتوى `p-4 pt-2`.
   - منطقة المحتوى الرئيسية: `p-4 sm:p-6`.
   - حوار: رأس `px-4 py-3`، جسم `p-4`.
4. **الكثافة أولاً:** فضّل `gap-2`/`gap-3` داخل المكوّنات، `gap-4`/`gap-5` بينها.
5. لا تباعد «موحّد ممل» — استخدم التسلسل (فجوة أكبر بين المجموعات، أصغر داخلها).

## رموز مقترحة (Recommended — للترحيل للكود)

لتثبيت المقياس كرموز صريحة (بدل الاعتماد الضمني على Tailwind):

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px;
--space-4: 16px; --space-5: 20px; --space-6: 24px; --space-8: 32px;
```

الفائدة: توثيق ذاتي + إمكانية تعديل الإيقاع مركزياً. حتى تُعتمَد، تُستخدم أدوات Tailwind
مباشرةً (وهي مكافئة). التفصيل في `foundations/recommended-improvements.md`.
