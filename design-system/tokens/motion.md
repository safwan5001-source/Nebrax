# رموز الحركة (Motion Tokens)

فلسفة نبراس: **الحركة وظيفية لا استعراضية.** تؤكّد تغيّر حالة أو انتقالاً، بسرعة وخفوت.
لا حركات دخول مبالغة، لا ارتدادات، لا تحوّلات طويلة.

## الحالة الفعلية (v1.0)

مُستخدَم فعلاً: `transition-colors` (تحويم الأزرار/الروابط)، `transition-transform duration-200`
(درج الشريط الجانبي)، `animate-pulse` (Skeleton). لا `keyframes` مخصّصة.

## المدد (Durations)

| الرمز المقترح | Tailwind | القيمة | الاستخدام |
|---|---|---|---|
| `--dur-fast` | `duration-150` | 150ms | تغيّرات اللون/التحويم (أزرار، روابط، صفوف) |
| `--dur-base` | `duration-200` | 200ms | انزلاق الدرج، فتح/إغلاق القوائم |
| `--dur-slow` | `duration-300` | 300ms | ظهور/اختفاء الحوار والطبقات (حدّ أقصى) |

**قاعدة:** لا تتجاوز 300ms لأي انتقال واجهة. الأسرع أفضل في أداة عمل.

## المنحنيات (Easing)

| الرمز المقترح | CSS | الاستخدام |
|---|---|---|
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | الافتراضي (دخول/خروج معظم العناصر) |
| `--ease-out` | `ease-out` | ظهور عنصر (يبدأ سريعاً ويهدأ) |
| `--ease-in` | `ease-in` | اختفاء عنصر |

الحالي يعتمد `transition` الافتراضي من Tailwind (ease). مقترح توحيده على `--ease-standard`.

## الأنماط المسموحة (Allowed Motions)

1. **تغيّر لون** (`transition-colors`) عند التحويم/التركيز — 150ms.
2. **انزلاق** (`translate`) للأدراج والقوائم — 200ms.
3. **تلاشٍ** (`opacity`) للحوار/الطبقات — 200–300ms.
4. **نبض** (`animate-pulse`) لهياكل التحميل فقط.

## الممنوع

- ارتدادات (bounce)، تكبير/تصغير استعراضي، دوران، حركات دخول متتابعة (stagger) للصفوف.
- تحريك الأرقام المالية (يجب أن تظهر فوراً وثابتة — الثقة).
- أي حركة > 300ms في التطبيق الداخلي.

## احترام تفضيل تقليل الحركة (إلزامي — مقترح للترحيل)

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

يجب إضافته إلى `globals.css` (وصولية). التفصيل في `accessibility/standards.md`.
