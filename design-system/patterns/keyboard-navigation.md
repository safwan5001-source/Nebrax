# تنقّل لوحة المفاتيح (Keyboard Navigation)

أداة عمل محاسبية تُستخدَم بكثافة → لوحة المفاتيح مواطن أول.

## الموجود (v1.0)
- **Escape** يغلق الحوار (`ui/dialog.tsx`).
- **Tab** يتنقّل بين العناصر (ترتيب DOM طبيعي).
- **حلقة تركيز مرئية** على كل عنصر تفاعلي (`ring-primary/40`).

## المعيار الملزِم
1. **كل شيء قابل للوصول بلوحة المفاتيح.** لا فعل يعتمد على الفأرة وحده.
2. **ترتيب Tab منطقي** يتبع تدفّق القراءة (RTL: يمين→يسار، أعلى→أسفل).
3. **حلقة تركيز واضحة دائماً** — ممنوع إزالة `outline` بلا بديل.
4. **Enter** يُرسِل النموذج/يُفعّل الزر المركَّز؛ **Space** يفعّل الأزرار/الاختيارات.
5. **Escape** يغلق أي طبقة (حوار، درج، لوحة أوامر).

## اختصارات مقترحة (v2.0 — للتنفيذ)
| الاختصار | الفعل |
|---|---|
| `Ctrl/⌘ + K` | لوحة الأوامر |
| `/` | التركيز على البحث في القائمة الحالية |
| `Ctrl/⌘ + S` | حفظ النموذج الحالي (منع سلوك المتصفّح) |
| `Esc` | إغلاق/إلغاء |
| `↑ / ↓` | التنقّل في القوائم/النتائج |
| `g ثم …` | انتقال سريع (مثل `g i` للفواتير) — على طراز GitHub |

## قواعد التنفيذ
- استمع للاختصارات على مستوى عالٍ (provider) مع تفادي التعارض مع الكتابة في الحقول.
- في القوائم/النتائج: `aria-activedescendant` + إدارة فهرس محدَّد.
- في الحوار/لوحة الأوامر: **حبس التركيز** (focus trap) وإعادته للمُطلِق عند الإغلاق (مقترح).

> التفصيل والأثر في `foundations/recommended-improvements.md`.
