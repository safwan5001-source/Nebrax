# أنماط UX والتصميم (UX & Design Patterns)

أنماط متكرّرة تُعاد كما هي لضمان الاتّساق.

## 1. شاشة قائمة (List Screen)
رأس (عنوان + زر إضافة) → `DataTable` (بحث/فرز/تصدير/حالات) → صفّ = رابط للتفاصيل.

## 2. شاشة تفاصيل (Detail Screen)
رأس (زر رجوع + اسم + شارات الحالة) → بطاقة/بطاقات معلومات → جداول فرعية (حركات/سطور).

## 3. شاشة نموذج (Form Screen)
رأس (رجوع + عنوان + حفظ/إلغاء) → بطاقات أقسام (`grid lg:grid-cols-2`) → تحقّق + Toast.

## 4. إنشاء سريع (Quick Create)
`Dialog` بنموذج مختصر (حوارات العميل/المنتج) — للحقول الأساسية؛ التفاصيل في شاشة كاملة.

## 5. المستند المالي (فاتورة/سند)
سطور (يمين) + **ملخّص لاصق** (يسار، `sticky`) يحسب الإجماليات لحظياً من السطور. الإجماليات
مشتقّة لا مُدخَلة. حفظ كمسودة / حفظ وترحيل.

## 6. تأكيد الأفعال الهدّامة
حذف/عكس → حوار تأكيد + زر `danger`. لا حذف مباشر لسجل ذي أثر مرحّل.

## 7. الأرقام كبطل
محاذاة يمين، `.num`، فواصل آلاف، فاصلتان، السالب أحمر + إشارة، العملة ﷼.

## 8. التنقّل والعودة
زر رجوع (`ArrowRight` في RTL) أعلى يسار شاشات التفاصيل/النماذج، يعيد للقائمة.

## 9. الوسم بالحالة
حالة كل مستند دائماً كـ Badge بلون دلالي + نص (مسودة/مرحّلة/مسدّدة/متأخّرة/ملغاة).

## 10. الكشف التدريجي (Progressive Disclosure)
ابدأ بالحقول المدعومة الأساسية؛ الحقول المتقدّمة تُضاف تباعاً. لا تُغرِق المستخدم دفعة واحدة.

## مبادئ عامة
- **اتّساق فوق الإبداع:** نفس النمط لنفس المشكلة في كل الشاشات.
- **أقل نقرات:** الإجراء الشائع في متناول اليد (رأس الشاشة، لوحة الأوامر مستقبلاً).
- **ردّ فعل فوري:** كل إجراء يُنتج تغيّراً مرئياً (Toast/تحديث/تحميل).
- **لا طرق مسدودة:** كل حالة فارغة/خطأ تقدّم الخطوة التالية.
