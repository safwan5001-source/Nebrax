# الشبكة والتخطيط (Grid System & Layout Rules)

## قشرة التطبيق (App Shell) — `web/src/app/(app)/layout.tsx`

```
┌─────────────────────────────────────────────┐
│ DemoBanner (شرطي)                            │
├──────────┬──────────────────────────────────┤
│          │ Topbar  (h-14)                    │
│ Sidebar  ├──────────────────────────────────┤
│ (w-72,   │ main                              │
│  lg+     │  (flex-1 overflow-auto p-4 sm:p-6)│
│  ثابت)   │  ← محتوى الشاشة هنا               │
└──────────┴──────────────────────────────────┘
```

- الحاوية: `flex min-h-screen flex-col`. داخلها صف `flex flex-1`: [Sidebar | عمود(Topbar + main)].
- الشريط الجانبي ثابت على `lg`، ودرج منزلق على أصغر منها.
- `main` هو منطقة التمرير الوحيدة (`overflow-auto`) — الرأس والشريط ثابتان.
- **مجموعة مسارات مستقلة:** `(pos)` لها تخطيط ملء الشاشة بلا شريط/رأس (نقطة البيع).

## الشبكة داخل الشاشة (Content Grid)

لا شبكة 12-عمود صارمة؛ نستخدم **Flex/Grid من Tailwind حسب الحاجة** بأنماط موحّدة:

| النمط | الأصناف | الاستخدام |
|---|---|---|
| عمود واحد كامل | `space-y-5` | قائمة/جدول |
| بطاقتان | `grid grid-cols-1 gap-5 lg:grid-cols-2` | نموذج بقسمين، لوحة |
| ثلاث بطاقات | `grid grid-cols-1 gap-4 sm:grid-cols-2 lg:grid-cols-3` | مؤشرات، بطاقات إعدادات |
| أربع بطاقات مؤشرات | `grid grid-cols-2 gap-4 lg:grid-cols-4` | صف KPI للوحة |
| نموذج داخلي | `grid grid-cols-1 gap-3 sm:grid-cols-2` | حقول متجاورة |
| رأس شاشة | `flex flex-wrap items-center gap-3` | عنوان + أزرار إجراء |
| قضبان جانبية | `lg:col-span-2` / عمود ملخّص لاصق | فاتورة (سطور + ملخّص) |

## قواعد التخطيط (Layout Rules)

1. **عرض أقصى للمحتوى النصّي/النماذج** عند اللزوم (`max-w-*`) لتجنّب أسطر طويلة؛
   الجداول تأخذ العرض الكامل.
2. **رأس الشاشة موحّد:** عنوان (`text-xl font-semibold`) على اليمين + أزرار الإجراء
   على اليسار (`ms-auto`)، ضمن `flex flex-wrap items-center gap-3`.
3. **البطاقة وحدة التجميع.** جمّع الحقول/الأقسام في `Card` بعنوان `CardTitle`.
4. **قسم ملخّص لاصق** (فاتورة/سلة): عمود جانبي `sticky top-*` يبقى مرئياً أثناء التمرير.
5. **لا تمركز عمودي لكل شيء.** المحتوى يبدأ من الأعلى؛ التمركز لشاشات المصادقة/الحالات الفارغة فقط.
6. **الجداول تتمدّد، النماذج تُقيَّد.** جدول = عرض كامل + تمرير أفقي داخلي؛ نموذج = عمودان كحدّ.

## قواعد التمرير (Overflow)

- التمرير العمودي في `main` فقط (الشريط/الرأس ثابتان).
- الجداول العريضة: تمرير أفقي **داخل حاوية الجدول** (`overflow-x-auto`) — لا يتمدّد جسم الصفحة أفقياً أبداً.
- أي محتوى عريض (رسم/كود) يوضع في حاوية `overflow-x-auto` خاصّة به.
